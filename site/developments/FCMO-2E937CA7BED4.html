NVIDIA released Nemotron 3.5 Lightning, an open 30B-parameter mixture-of-experts model with about 3B active parameters, a hybrid Mamba-2/MoE/attention architecture, baked-in multi-token prediction and an NVFP4 checkpoint.

Why it matters: It is an unusually direct systems reference for sparse active compute, agentic workloads, speculative decoding and quant-first deployment across consumer and datacenter NVIDIA hardware.

Technical record

Mechanism
30B-total/3B-active MoE using a Mamba-2 + MoE + attention hybrid, MTP during pretraining, speculative draft models and NVFP4 quantized deployment.
Demonstrated result
NVIDIA released model artifacts and an NVFP4 checkpoint; official model metadata lists up to 1M context and cross-generation NVIDIA GPU support for the quantized deployment path.
Publisher claim
NVIDIA positions the model as a highest-efficiency class model for long-running agentic workloads and specialized tasks inside multi-agent systems.
Strongest baseline
Nemotron 3 Nano and contemporary small-active-parameter agentic MoE models.
Regime
30B total, ~3B active per token, open model, long-context agentic inference; BF16 and NVFP4 distribution paths.
Implementation
Released with NeMo customization paths and serving support; NVFP4 kernels target Blackwell, Hopper and Ampere-class NVIDIA GPUs.
Compute / cost
Sparse 3B-active design and NVFP4 target low-latency/high-volume agent execution; matched independent cost curves remain needed.
Novelty
Tightly integrates sparse MoE, hybrid sequence layers, MTP/speculation and quant-first distribution for agentic use.
Reproducibility
Weights/model card are public; exact training economics and broad publisher performance claims need independent confirmation.
