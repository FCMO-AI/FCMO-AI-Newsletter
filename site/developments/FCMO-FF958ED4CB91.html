Agents & Memory

Recuris externalizes long-horizon agent improvement into verified working state and validation-gated experiential memory

Evidence Astrongly_supportedImpact 7/10 · Very majoractive

paper · development FCMO-FF958ED4CB91 · verified 2026-08-31T19:17:04Z

Importance: 7/10 — Very major. Importance measures consequence if true, not evidence quality.
Very major if the central claim holds in the stated long-horizon regime: a frozen-model agent that can turn execution evidence into validated, transferable improvements in an external memory/control layer would make persistent agent learning substantially more auditable, modular and deployment-friendly than continual weight updates. The consequence is larger than an ordinary benchmark gain because it changes where adaptation can live. It is not scored 8-10 because evidence remains benchmark-bounded, some individual deltas are unresolved, SkillFlow evolution has an in-family task-selection caveat, test-time adaptation is weak in the reported sample, and no independent reproduction is yet canonical.

Recuris keeps the downstream model frozen while a harness maintains verified working state, selects reusable skills against that state, records structured state-skill-action-outcome traces, and lets a fixed meta-agent propose localized memory edits that survive only if a deterministic held-out validation gate accepts them. Across four long-horizon benchmarks and ten models, the authors report improvement in 35 of 37 completed model-benchmark pairs, including statistically resolved +17.8 points for GPT-5.6 Sol and +15.6 for Claude Opus 5 on tau2-Retail. Released code, frozen splits and memory packages make the mechanism inspectable, while several controls show that neither a neutral harness nor indiscriminate skill injection explains the strongest gains.

Why it matters: If the result transfers beyond the reported task families, it is evidence that useful self-improvement can live in a bounded external memory/control layer rather than requiring continual weight updates. That would materially change how long-lived agents are engineered: current state, reusable experience, diagnosis and gated repair become persistent typed components whose evolution can be audited and rolled back independently of the base model.

Technical record

Mechanism
Working Memory tracks compact task progress and unresolved goals, commits state updates only when supported by environment/tool feedback, and uses that verified state to select skills from Experiential Memory. Execution emits structured traces linking state, selected skill, action and outcome. Across tasks, a fixed meta-agent attributes failures to specific memory components and proposes localized Skill Memory patches; a deterministic gate accepts patches only on paired held-out validation evidence. The downstream model and outer improvement procedure remain fixed.
Demonstrated result
The authors report positive task-success deltas in 35 of 37 completed model-benchmark pairs across tau2-Retail, tau2-Airline, SkillFlow and Terminal-Bench 2.1. Statistically resolved examples include GPT-5.6 Sol 58.3% to 76.1% on tau2-Retail (+17.8), Claude Opus 5 72.4% to 87.9% (+15.6), GPT-OSS-20B 50.6% to 60.8% (+10.2), and Qwen3.6-27B 42.2% to 58.7% on SkillFlow (+16.6). Structured-trace fault localization reaches 64.8% macro accuracy versus 13.0% from outcome alone and 37.0% from raw trajectory in the injected-fault study. In an identical ten-skill control, state-grounded invocation scores 83.6% on tau2-Retail versus 65.6% when the model controls injection of the same skill library.
Publisher claim
The authors argue recursively evolving external memory is a scalable foundation for recursive self-improvement in long-horizon agents and that evolved memory can transfer across model families without changing downstream weights.
Strongest baseline
The key controls are the same benchmark reference agent without Recuris; a neutral harness that preserves plumbing but contributes no task-specific memory; a model-controlled identical skill library that isolates skill availability from state-grounded invocation; raw-trajectory and outcome-only failure-localization baselines; and, for Terminal-Bench test-time adaptation, an m0 arm carrying the same initial memory package and the same retry budget without updating it.
Regime
Four long-horizon agent benchmarks spanning tool-use dialogue, lifelong skill reuse and terminal work; ten models from 3B open-weight systems to frontier APIs. Cross-task memory evolution uses benchmark-specific frozen splits and validation gates. SkillFlow's selected per-family template is in-sample with respect to tasks within that family, while transfer to other target models is out-of-sample. Terminal-Bench 2.1 adaptation is within-task across repeated attempts.
Implementation
Public paper and Apache-2.0 repository provide evaluation/evolution code, Skill Memory packages, frozen evaluation splits, integrity material and runnable comparison tooling.
Compute / cost
The method adds harness, retrieval, verification and meta-agent inference cost; the public materials expose the workflow but ARB has not yet normalized quality gains by total meta-agent/downstream token or GPU budget. Terminal-Bench controls match retry count across bare, fixed-memory and adaptive-memory arms.
Novelty
Moves the adaptive object from model weights or one monolithic prompt into typed external state: verified working memory for current progress plus experiential skill memory that can be locally diagnosed, patched and validation-gated.
Reproducibility
Code, benchmark wrappers, frozen splits and released memory packages materially improve reproducibility, but ARB has not located an independent reproduction and several evaluations require model/provider access and benchmark-specific simulators/judges.

Evidence claims

  • DEMONSTRATED — Recuris improves reported task success across most tested model-benchmark pairs, with several large paired-bootstrap-resolved gains on long-horizon tasks.
  • DEMONSTRATED — Verified state-grounded skill invocation contributes beyond merely exposing the same skill library to the model in the reported tau2-Retail control.
  • DEMONSTRATED — Structured state-skill-action-outcome traces improve component-level failure localization over outcome-only and raw-trajectory inputs in the authors' injected-fault experiment.
  • INFERRED — Validation-gated external memory evolution is a scalable general foundation for recursive self-improvement across long-lived agent domains.

Limitations / contrary evidence

  • Thirty-five positive deltas do not mean thirty-five independently significant wins; many individual paired intervals include zero.
  • No independent reproduction is yet canonical despite the public code and frozen splits.
  • SkillFlow memory evolution is in-sample with respect to tasks within a family for the selected routing/template configuration, limiting the strength of a pure held-out-learning interpretation there.
  • Terminal-Bench test-time adaptation is modest in the reported matched-retry comparison: 60.9% versus 58.6% for the fixed-memory m0 arm, not significant at the reported sample size.
  • A general-purpose memory package can transfer negatively; the repository reports a rebuilt GPT-OSS-20B package gaining +10.2 while a generic transferred package can regress, so cross-model portability is conditional rather than automatic.
  • The total inference/evolution cost and memory-growth/pruning behavior are not yet normalized against alternative ways of spending the same compute budget.
  • Gemini 3.7 Flash regresses 1.5 points on tau2-Airline in the reported table, and Granite-4.1-3B regresses 0.3 on SkillFlow, showing the method is not uniformly beneficial.
  • The small and unresolved Terminal-Bench adaptation delta weakens any claim that online memory rewriting itself is already a generally strong test-time learner.
  • Negative transfer from a general-purpose package shows that accumulated experience can become mismatched to a target model rather than acting as universally portable knowledge.

Open evidence gaps

  • open · reproduction_missing — No independent reproduction of the main paired benchmark gains or memory-evolution loop is yet canonical. — next: Reproduce a small frozen tau2-Retail split with one open-weight model using the released bare, neutral-harness and Recuris configurations.
  • open · other — The total meta-agent, judge, retrieval and validation cost has not been compared against equal-budget extra rollouts, larger-context inference or offline skill distillation. — next: Measure success per total model token/GPU-hour across Recuris, fixed memory, extra-rollout and offline-distillation controls.
  • open · other — Evidence is concentrated in benchmarked tool/terminal workflows; robustness to changing APIs, adversarial memory, coding projects and open-web research is unknown. — next: Evaluate on a held-out task family with different tools and explicit state/relevance drift plus memory poisoning controls.
