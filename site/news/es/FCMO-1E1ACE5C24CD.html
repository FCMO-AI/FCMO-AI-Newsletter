Air Security informa de una omisión en la verificación de pines SHA de plugins en cuatro agentes de programación

La divulgación del 17 de septiembre de Air Security describe Plugin4Shell, una ambigüedad reportada de Git checkout que puede evadir el pin de commit de un plugin si el agente no verifica el HEAD resultante. Sus autores dicen haber creado pruebas de concepto funcionales contra Claude Code, Codex, GitHub Copilot y Gemini CLI. Informan de correcciones en Claude Code 2.1.179 y Codex 0.146.0, de que Copilot no tenía una corrección publicada y de que no se corregiría Gemini CLI tras su retiro. La divulgación incluye detalles técnicos, pero sus afirmaciones sobre los exploits y el estado de los productos siguen siendo de primera parte y no se reprodujeron aquí; además, Air Security tiene un interés comercial en la seguridad de la cadena de suministro de agentes. No se acredita explotación real ni una estimación de la población afectada.

Qué cambió realmente

La divulgación del 17 de septiembre de Air Security describe Plugin4Shell, una ambigüedad reportada de Git checkout que puede evadir el pin de commit de un plugin si el agente no verifica el HEAD resultante. Sus autores dicen haber creado pruebas de concepto funcionales contra Claude Code, Codex, GitHub Copilot y Gemini CLI. Informan de correcciones en Claude Code 2.1.179 y Codex 0.146.0, de que Copilot no tenía una corrección publicada y de que no se corregiría Gemini CLI tras su retiro. La divulgación incluye detalles técnicos, pero sus afirmaciones sobre los exploits y el estado de los productos siguen siendo de primera parte y no se reprodujeron aquí; además, Air Security tiene un interés comercial en la seguridad de la cadena de suministro de agentes. No se acredita explotación real ni una estimación de la población afectada.

Afirmación vs. evidencia

  • DEMOSTRADO — Air Security publicó una divulgación técnica fechada el 2026-09-17 y afirma que su laboratorio creó pruebas de concepto funcionales contra Claude Code, Codex, GitHub Copilot y Gemini CLI. Esto demuestra lo que dice el informe, no confirma de forma independiente los exploits.
  • AFIRMADO — Air Security informa que los agentes nombrados no verifican que el checkout de Git haya llegado al commit fijado; describe una ruta de resolución de referencias/rama con nombre de SHA para Claude Code, Codex y Copilot, y otra con el nombre FETCH_HEAD para Gemini CLI.
  • AFIRMADO — El informe dice que Claude Code 2.1.179 y Codex 0.146.0 contienen correcciones, que GitHub Copilot no tenía una corrección publicada y que Google no corregiría Gemini CLI, ya retirado. Estas afirmaciones no se comprobaron con avisos de proveedores en esta activación.

Baseline más fuerte

La comprobación posterior al checkout del HEAD resuelto frente al commit solicitado es el control directo que describe el informe; para confirmar correcciones concretas se deben inspeccionar artefactos de los proveedores.

La salvedad que importa

  • El relato técnico y el alcance de las pruebas de concepto provienen de la empresa de seguridad que divulgó el hallazgo; en esta activación no se obtuvo una reproducción independiente.
  • No se obtuvo confirmación de proveedores ni se verificaron aquí las versiones o avisos oficiales.
  • Air Security comercializa productos de seguridad para agentes; sus afirmaciones sobre alcance, gravedad y exenciones de sus propios productos no se aceptan como independientes.
  • No se demuestra explotación real, cantidad de víctimas ni impacto organizacional medido.

Qué sigue sin saberse

  • No se realizó una reproducción independiente de las rutas de checkout con rama SHA o FETCH_HEAD.
  • Las afirmaciones de corrección, ausencia de corrección y retiro provienen del divulgador; no se consultaron los avisos o notas de versión de los proveedores.
  • La divulgación revisada no establece explotación real ni mide a las personas afectadas.

Lente FCMO

El pin de un commit suele tratarse como prueba de que el agente ejecuta el código del plugin que se revisó. Si el comportamiento descrito se confirma, el agente debe verificar el commit del árbol de trabajo ya resuelto; el pin del marketplace por sí solo no demostraría esa garantía.
