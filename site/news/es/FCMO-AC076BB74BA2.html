Evidencia

  • Afirmado — DeltaSelect ordena tareas por el percentil cinco de la correlación de Pearson en 10,000 remuestreos deterministas, calibra resultados fraccionarios del verificador a una escala común de puntuación completa y elige tareas dentro de un presupuesto. En el conjunto de datos DeepSWE, los autores informan que 22 de 113 tareas alcanzaron una correlación del percentil cinco de al menos 0.50.
  • Afirmado — En 13 evaluaciones con ocho tareas de un estudio de caso de Agent Layer con gpt-5.6-luna y razonamiento bajo, los autores informan una puntuación calibrada final de 42.36% con costo de $1.75, frente a 36.46% y $4.18 para el conjunto inicial de instrucciones y habilidades. Cada extremo tiene una ejecución por tarea y el análisis transfiere estimaciones de variación de ejecuciones publicadas de mini-swe-agent.
  • Afirmado — Para las mismas ocho tareas y configuración de gpt-5.6-luna, los costos del entorno Codex informados en el artículo fueron de 1.5 a 3.5 veces las estimaciones correspondientes de DeepSWE; las puntuaciones también difirieron. El artículo aclara que esto muestra una diferencia de planificación, no un efecto causal del entorno.
  • Demostrado — El artículo de arXiv enlaza un repositorio público de Agent Layer y una página de implementación de DeltaSelect. El README identifica el proyecto como una capa de orquestación de agentes de programación de código abierto; esta revisión no ejecutó el código.

Línea base más fuerte

En el estudio de caso de ocho tareas, el artículo compara las configuraciones inicial y adoptada de instrucciones y habilidades de Agent Layer con el mismo modelo, nivel de razonamiento, tareas, calibración y pesos declarados. El extremo adoptado registra $1.75 y 42.36% de puntuación calibrada, frente a $4.18 y 36.46% al inicio. Cada extremo tiene una ejecución por tarea y la incertidumbre se transfiere de datos repetidos de mini-swe-agent.

Limitaciones

  • No se demuestra que la selección de tareas y la calibración superen alternativas con el mismo presupuesto; el artículo plantea esas comparaciones como trabajo futuro.
  • El mismo conjunto DeepSWE se usa para construir la selección y evaluar el ejemplo con datos publicados, por lo que la evidencia es interna a ese conjunto.
  • El estudio de caso Agent Layer tiene una ejecución por tarea en cada extremo, transfiere la variación de mini-swe-agent y cambia varias instrucciones en algunas evaluaciones; no establece el efecto causal de un solo cambio.
  • Un conjunto fijo pequeño puede omitir capacidades, amplificar problemas de calidad de tareas y especializar el sistema; no reemplaza un benchmark amplio ni constituye una evaluación de seguridad.
  • La revisión solo inspeccionó el README del repositorio; no ejecutó código, datos ni evaluaciones.

Lo que aún no sabemos

  • En esta revisión ningún equipo independiente reprodujo el selector, los extremos del estudio de caso ni los costos informados.
  • El selector no se comparó con selección aleatoria, de menor costo o por correlación mediana con el mismo presupuesto; el ordenamiento y el ejemplo con datos publicados usan el mismo conjunto DeepSWE.
  • El estudio de caso cubre una familia de modelos, un entorno personalizado y un conjunto de instrucciones y habilidades; usa variación transferida y varias iteraciones cambiaron más de una instrucción.
  • El artículo enlaza código público, pero esta revisión no ejecutó ni auditó el código o los artefactos del estudio.

Por qué importa

Si se valida de forma independiente, seleccionar conjuntos pequeños y económicos de tareas podría facilitar comparaciones más frecuentes de cambios en agentes de programación. Los propios datos del artículo muestran que la fiabilidad varía entre tareas y que las puntuaciones y los precios de un entorno no se trasladaron directamente a otro. Se desconoce si el selector supera a otras alternativas y si funciona fuera de un benchmark, una familia de modelos y un entorno personalizado.
