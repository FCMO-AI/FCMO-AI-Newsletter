Anthropic publica FlashProve, un prototipo de pruebas de conocimiento cero para inferencias de modelos

Anthropic anunció FlashProve, un prototipo abierto de pruebas de conocimiento cero que busca permitir verificar que una inferencia usó un modelo comprometido sin revelar sus pesos. La nota del 2 de noviembre informa unos 110 tokens de prueba por segundo para Llama 4 Maverick cuantizado a 4 bits en una H100, con pruebas de unos 19 MB por solicitud de 1,024 tokens y un tiempo de GPU entre 70 y 95 veces el de la inferencia común con vLLM. El repositorio enlazado identifica la versión 0.16.0 como un artefacto de investigación sin mantenimiento; su README enumera requisitos considerables de hardware y memoria para probar el modelo completo. El desempeño y la seguridad siguen siendo afirmaciones de primera parte, y aquí no se auditaron de forma independiente el informe ni la implementación.

Evidencia

  • Demostrado — Anthropic publicó el 2 de noviembre de 2026 una nota de investigación que anuncia FlashProve, un prototipo de código abierto para probar inferencias mediante argumentos de conocimiento sucintos y de conocimiento cero (zkSNARK). La nota describe la publicación de un informe técnico, el protocolo, un generador y verificadores ejecutables, y pruebas en Lean bajo licencia Apache 2.0.
  • Afirmado — Anthropic informa que FlashProve genera pruebas de inferencia para Llama 4 Maverick cuantizado a 4 bits, un modelo de mezcla de expertos con 400B parámetros, a unos 110 tokens por segundo en una sola GPU H100. Cada solicitud de 1,024 tokens genera una prueba de unos 19 MB; el tiempo de GPU equivale a cerca de 70–95 veces el de la inferencia con vLLM para solicitudes de longitud comparable.
  • Afirmado — Anthropic afirma que la prueba vincula la respuesta de inferencia con un compromiso criptográfico sobre pesos de un modelo específico y oculta esos pesos; el sistema no busca ocultar la arquitectura del modelo.
  • No establecido — El anuncio público no demuestra una réplica independiente, rendimiento en producción, seguridad operativa integral ni que probar una inferencia permita demostrar que un proveedor no esté usando el mismo hardware también para entrenar.
  • Demostrado — El repositorio público de Anthropic en GitHub identifica la versión 0.16.0 como un artefacto de investigación que ya no recibe mantenimiento ni contribuciones.
  • Afirmado — El README del repositorio indica que generar pruebas con el modelo Llama 4 Maverick completo requiere una NVIDIA H100 de 80 GB, CUDA 13.2, 330 GB de RAM, 245 GB de disco y varias horas; presenta por separado una ruta de verificación de pruebas guardadas que requiere menos de 2 GB de RAM.

Por qué importa

Las pruebas de inferencia podrían ofrecer a usuarios y auditores una forma criptográfica de comprobar la identidad del modelo en servicios alojados o intermediados, y apoyar algunas verificaciones de cumplimiento. FlashProve aporta un prototipo público y artefactos de verificación formal, pero el costo computacional informado es considerable; el repositorio lo marca como no mantenido, y probar una inferencia no descarta entrenamiento simultáneo ni resuelve obligaciones regulatorias más amplias.
