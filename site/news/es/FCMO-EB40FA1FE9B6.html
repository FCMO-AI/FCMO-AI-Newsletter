NVIDIA y Oracle anuncian la disponibilidad de Vera Rubin en OCI y una expansión planificada a escala de varios gigavatios

NVIDIA y Oracle anunciaron que los sistemas Vera Rubin NVL72 y las CPU Vera tienen disponibilidad general en Oracle Cloud Infrastructure (OCI), junto con planes para ampliar los superclústeres OCI con sistemas Rubin hasta una escala de varios gigavatios. El comunicado presenta las GPU como recursos para entrenar y servir modelos, y las CPU para ejecutar herramientas, código y recuperación de datos entre llamadas de modelos. Oracle y NVIDIA dicen que sus clientes pueden escalar por separado los recursos de CPU y GPU, pero el anuncio no aporta mediciones de utilización, costos para clientes ni resultados comparables de cargas completas de agentes. Oracle señala que OpenAI está explorando el uso de CPU Vera en acceso anticipado y cita a OpenAI diciendo que las incorporará a producción; esas declaraciones de las empresas no establecen la escala de la flota entregada ni efectos medidos.
