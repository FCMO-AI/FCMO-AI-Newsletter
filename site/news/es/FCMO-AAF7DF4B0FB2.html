Unitree publica el checkpoint base WLA-1.0 y el código de ajuste fino

El repositorio oficial de UnifoLM-WLA de Unitree registra que el 28 de septiembre se publicaron el checkpoint base WLA-1.0 y el código de ajuste fino. El repositorio oficial del modelo lista actualmente un checkpoint safetensors de 12.5 GB con licencia Apache-2.0, y la guía oficial describe una ruta de evaluación con episodios locales. Estos artefactos permiten inspeccionar parte de la promesa de apertura anterior, pero no establecen el rendimiento comunicado en 64 tareas ni una generalización física amplia.

Qué cambió realmente

El repositorio oficial de UnifoLM-WLA de Unitree registra que el 28 de septiembre se publicaron el checkpoint base WLA-1.0 y el código de ajuste fino. El repositorio oficial del modelo lista actualmente un checkpoint safetensors de 12.5 GB con licencia Apache-2.0, y la guía oficial describe una ruta de evaluación con episodios locales. Estos artefactos permiten inspeccionar parte de la promesa de apertura anterior, pero no establecen el rendimiento comunicado en 64 tareas ni una generalización física amplia.

Afirmación vs. evidencia

  • DEMOSTRADO — El repositorio oficial de Unitree registra que el checkpoint base WLA-1.0 y el código de ajuste fino se publicaron el 28 de septiembre de 2026.
  • DEMOSTRADO — El repositorio oficial del modelo lista un checkpoint safetensors de 12.5 GB con licencia Apache-2.0, y la guía oficial describe una ruta de evaluación con episodios locales.
  • AFIRMADO — Unitree informa que una política de 6B parámetros, entrenada con aproximadamente 2,500 horas de datos, abarca 64 tareas con robots reales.

Baseline más fuerte

Esta revisión de la publicación de artefactos no evaluó una línea base equiparada.

La salvedad que importa

  • No se descargó ni ejecutó código; tampoco se realizó una evaluación física independiente.
  • No se completó una tabla integral de resultados por tarea, un protocolo de ensayos, una auditoría de integridad de los conjuntos de datos ni una reproducción entre efectores finales.
  • La guía de evaluación actual indica que el servidor del modelo admite Dex1, pero no WBT; publicar los artefactos no demuestra una cobertura amplia de despliegue.

Qué sigue sin saberse

  • En esta revisión no se encontraron resultados físicos independientes por tarea ni pruebas para las 64 tareas alegadas.
  • No se auditó que las colecciones de datos listadas cubran las tareas, ni su solapamiento o las particiones de evaluación reservadas.

Lente FCMO

Un checkpoint base público y una ruta de ajuste fino permiten inspeccionar y comenzar a probar una política humanoide de manipulación de cuerpo completo. Esto cambia el estado de publicación: pasa de un anuncio en una página del proyecto a un conjunto de artefactos reproducibles. La cuestión abierta es si la amplitud comunicada resiste evaluaciones controladas por tarea y una reproducción física independiente.
