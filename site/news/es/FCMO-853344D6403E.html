OpenAI publica las tarifas de la API de GPT-Rosalind y programa el inicio de cobro para el 5 de octubre

La página de precios de la API de OpenAI lista gpt-rosalind-research a $5 por 1 millón de tokens de entrada, $0.50 por 1 millón de tokens de entrada en caché y $25 por 1 millón de tokens de salida; la página indica que el cobro comienza el 5 de octubre de 2026. El registro de cambios de la API fecha el lanzamiento con acceso confiable y estas tarifas estándar el 8 de septiembre. Esto hace visible un precio marginal específico del modelo para investigación aprobada en ciencias de la vida, pero las fuentes consultadas documentan el calendario anunciado, no un cargo observado a un cliente ni el costo por resultado científico validado.

Afirmación vs. evidencia

  • DEMOSTRADO — La página actual de precios de la API de OpenAI lista gpt-rosalind-research a $5 por 1M de tokens de entrada, $0.50 por 1M de tokens de entrada en caché y $25 por 1M de tokens de salida, e indica que no se aplica un cargo por escritura en caché.
  • AFIRMADO — OpenAI afirma que el cobro de gpt-rosalind-research comienza el 5 de octubre de 2026; esta activación observó la fecha indicada, pero no revisó una factura ni una transacción que pruebe que se haya cobrado a un cliente.
  • DEMOSTRADO — OpenAI limita el acceso a la API de GPT-Rosalind a investigación interna aprobada mediante su programa de acceso confiable e indica que, por ahora, no está disponible para productos dirigidos a clientes ni para aplicaciones comerciales externas.

Baseline más fuerte

La misma página de precios de OpenAI lista tarifas de modelos de API cercanos, pero en este rastreo no se obtuvo ni construyó una comparación equivalente de flujos científicos.

La salvedad que importa

  • La fecha de inicio del cobro es un calendario publicado por OpenAI; no se contó con factura, registro de transacción ni cuenta independiente de un cliente elegible para confirmar que hoy se haya efectuado un cargo.
  • Las tarifas publicadas no determinan el costo por tarea: no se midieron la mezcla de tokens de entrada y salida, la tasa de aciertos de caché, las herramientas, los reintentos ni la revisión humana.
  • El acceso sigue restringido a investigación interna aprobada; según la documentación actual de acceso de OpenAI, la API no está disponible para productos dirigidos a clientes ni aplicaciones comerciales externas.
  • La página de precios no demuestra capacidad científica, productividad de investigación ni rentabilidad frente a otros modelos.
  • Las fuentes indican el día programado de inicio del cobro, pero no la hora ni la zona horaria; se desconoce el momento exacto de activación.

Qué sigue sin saberse

  • No hay un registro de uso atribuible de forma independiente que confirme que un cliente elegible recibió un cargo en la fecha de entrada en vigor programada.
  • No hay un costo comparable por flujo de trabajo científico validado; las tarifas por token no incluyen la mezcla de tokens, el costo de herramientas, los reintentos ni la supervisión humana.

Lente FCMO

Una tarifa publicada específica del modelo aporta un dato concreto para decidir si equipos de investigación calificados pueden operar flujos científicos especializados. La tarifa de salida listada es cinco veces la tarifa de entrada sin caché y cincuenta veces la tarifa de entrada en caché, por lo que la economía real depende de la mezcla de tokens, el uso de caché, las herramientas y la supervisión. La tarifa por sí sola no demuestra una relación entre benchmark y costo ni mayor productividad científica.
