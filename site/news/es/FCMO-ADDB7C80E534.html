Limitaciones

  • La declaración de que no hay sandbox predeterminado se limita al adaptador compartido de ejecución de Agent en NOTICE; no debe generalizarse a todas las herramientas o modos de ZCode.
  • El modo yolo predeterminado cuando se omite --mode aplica a llamadas independientes no interactivas del CLI con --prompt; no se extiende automáticamente a TUI, escritorio, tareas reanudadas, target ni ejecución controlada por el host.
  • El servicio de permisos conserva reglas separadas para interacción del usuario, always-ask, herramientas prohibidas y modo plan; yolo no implica que todos los controles se omitan.

Por qué importa

Al elegir un harness de agentes, los usuarios necesitan saber si las operaciones ordinarias de archivos, shell y red están aisladas por el sistema operativo, y si las llamadas desatendidas del CLI requieren aprobación explícita. La documentación y el código de ZCode muestran valores predeterminados distintos según el modo de ejecución, por lo que las aprobaciones del proyecto no deben tratarse como una frontera de seguridad uniforme.
