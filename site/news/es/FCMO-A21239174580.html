Qué cambió

El anuncio de Microsoft del 19 de octubre describe cómo aplicar Project Perception a agentes empresariales mediante identidad, permisos, evaluación de riesgos y Guardian Agents. La documentación posterior de Microsoft Learn ofrece un panorama de implementación más acotado: la protección en tiempo de ejecución de Defender for Endpoint está en vista previa limitada, con modos de auditoría y bloqueo para ciertas combinaciones de Windows y agentes; la disponibilidad de Entra Agent ID y las licencias de pago para protecciones ampliadas se describen por separado. Son afirmaciones de producto e instrucciones de configuración de primera parte, no evidencia de eficacia medida, despliegue amplio ni validación independiente.

Evidencia

  • Demostrado — Microsoft publicó el 19 de octubre de 2026 una entrada de Hayete Gallot, vicepresidenta ejecutiva de Microsoft Security, titulada «Cómo proteger al agente interno».
  • Afirmado — Microsoft afirma que Project Perception, anunciado anteriormente en julio, puede aplicarse a agentes empresariales para descubrirlos, asignarles identidad, contenedores y permisos, evaluar el riesgo de sus acciones y usar agentes guardianes para supervisarlas y responder en tiempo real.
  • Afirmado — Microsoft afirma que Project Perception está disponible para ayudar a las organizaciones a empezar a proteger sus agentes internos.
  • No establecido — La documentación pública de producto presenta instrucciones de configuración y un alcance limitado de vista previa, pero no establece la precisión de los controles, la cobertura de amenazas probada, la latencia, una evaluación independiente, la escala de despliegue ni resultados operativos de seguridad.
  • Afirmado — Microsoft Learn documenta la protección de agentes de IA de Defender for Endpoint como una función en vista previa para ciertas combinaciones de Windows y agentes, con modos de auditoría y bloqueo. La matriz separa el descubrimiento de la cobertura en tiempo de ejecución e indica que la inspección de red no cubre tráfico con fijación de certificados ni HTTP/3.
  • Afirmado — Microsoft Learn afirma que Entra Agent ID está disponible para clientes de Entra, mientras que las protecciones ampliadas de Entra y el acceso condicional para agentes requieren una licencia elegible de Agent 365.

Línea base más fuerte

No se informa una comparación de referencia ni un resultado de seguridad medido.

Limitaciones

  • El blog de Microsoft es un anuncio de producto de alto nivel. Los documentos vinculados de Microsoft Learn describen una vista previa limitada de protección en tiempo de ejecución de Defender y los requisitos de licencia de Entra, pero no ofrecen una evaluación independiente del rendimiento ni resultados cuantificados.
  • El descubrimiento documentado por Defender cubre más casos que la protección en tiempo de ejecución; esta última se limita a ciertas combinaciones de Windows y agentes, y la inspección de red excluye el tráfico con fijación de certificados y HTTP/3. La disponibilidad de identidades Agent ID no implica que todos los controles anunciados de Project Perception estén disponibles de forma general.
  • Los materiales de Microsoft no establecen precisión de detección, tasas de falsos positivos, cobertura efectiva de amenazas, latencia, escala de despliegue en clientes ni una reducción del uso indebido de agentes.

Lo que aún no sabemos

  • La documentación pública describe una disponibilidad limitada en vista previa y ciertas configuraciones de protección en tiempo de ejecución de Defender, pero sigue sin aclarar la disponibilidad, el alcance técnico ni el despliegue del sistema más amplio Project Perception/Guardian Agents.
  • En esta revisión no se encontró una evaluación independiente o de clientes sobre precisión de detección/respuesta, latencia, cobertura de amenazas o resultados de seguridad.

Por qué importa

Si se implementara como se describe, la supervisión continua basada en identidad, permisos y riesgo podría influir en la arquitectura de seguridad empresarial a medida que los agentes acceden a datos, herramientas y procesos críticos. El anuncio no establece qué tan bien los controles detectan o contienen el uso indebido, qué amenazas cubren ni si están desplegados a escala.
