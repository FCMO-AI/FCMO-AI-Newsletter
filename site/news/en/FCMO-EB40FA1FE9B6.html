NVIDIA and Oracle announce Vera Rubin OCI availability and a planned multi-gigawatt expansion

NVIDIA and Oracle announced that Vera Rubin NVL72 systems and Vera CPUs are generally available on Oracle Cloud Infrastructure (OCI), alongside plans to expand OCI Superclusters with Rubin systems to multi-gigawatt scale. The release frames GPUs as serving model training and inference and CPUs as handling agent tool execution, code execution and retrieval between model calls. Oracle and NVIDIA describe customers as able to scale CPU and GPU resources independently, but the announcement supplies no measured utilization, customer cost or matched end-to-end agent workload results. Oracle describes OpenAI as exploring Vera CPU use in early access and quotes OpenAI as saying it is bringing Vera into production; these company statements do not establish delivered fleet scale or measured effects.
