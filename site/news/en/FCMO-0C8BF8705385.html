In brief · Agents and memory

MM-ContextFold reports lower visual context use and higher accuracy across multimodal retrieval benchmarks

MM-ContextFold keeps a persistent text-only planning context and opens temporary multimodal branches when an agent needs to inspect raw images. It folds each branch's findings back as a concise text summary, then discards the images and local branch trace. The authors first analyze approximately 10,000 trajectories and report that raw images become redundant after visual evidence has been extracted into text. Across seven multimodal agentic retrieval benchmarks and five backbones, they report 27.5% shorter working context and 6.3 percentage points higher average accuracy than a standard ReAct baseline. The main table reports means and standard deviations over three independent runs. Methods use the same underlying retrieval tools and total call budget, but preserve different native prompts and action grammars. These remain paper-reported results; no independent reproduction or deployment-cost analysis was performed.

Evidence

  • Claimed — MM-ContextFold separates persistent text-only planning from temporary image-dependent branches, folds findings back into the main context as text and discards raw images and branch traces after each subtask.
  • Claimed — Across seven multimodal agentic retrieval benchmarks and five backbone models, the authors report 27.5% lower working-context length and 6.3 percentage points higher average accuracy than standard ReAct; Table 1 reports mean and standard deviation over three independent runs.
  • Claimed — The authors analyze approximately 10,000 trajectories and report that raw images become increasingly redundant after visual evidence is extracted into text; continued image retention can raise output entropy and degrade task accuracy in their experiments.

Strongest baseline

Standard ReAct on the same multimodal retrieval benchmark suite; authors report MM-ContextFold improves average accuracy by 6.3 percentage points and reduces working-context length by 27.5%.

Limitations

  • All benchmark results are author-reported; no independent reproduction was conducted.
  • The main evaluation covers seven multimodal agentic retrieval benchmarks and five backbone models; broader agent tasks are not established.
  • Comparison methods retain different native prompt and action grammars, although the authors unify underlying tools and total call budgets.
  • A 27.5% working-context reduction does not by itself establish lower total token use, latency, API cost or compute.
  • The paper reports three independent runs for the main accuracy table; this does not resolve transfer or protocol-comparability questions.

What we still don't know

  • The reported context-length reduction and accuracy improvement have not been independently reproduced.
  • The study preserves native prompt and action-call formats across comparison methods, so differences in action grammar may affect attribution despite unified tool implementations and call budgets.
  • The paper emphasizes working-context length but does not establish total token spend, latency, API cost or transfer to multimodal agent tasks beyond retrieval.

Why it matters

Multimodal agents can carry large raw images through long tool-use histories after relevant visual details have already been converted into text. Temporarily scoping images to visual-grounding tasks could reduce context use without sacrificing task accuracy. The reported result is promising within multimodal retrieval, while prompt/action-format differences, cost, latency and transfer to other agent tasks remain unresolved.
