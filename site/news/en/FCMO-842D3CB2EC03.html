A preregistered probe finds context truncation can erase unrecoverable state in a synthetic agent task

A preregistered preprint tests when agent context policies affect task success rather than only cost. In a synthetic PersistGym-lite probe, the author reports a 92.5-point difference between context-truncation penalties when a needed fact could not be re-observed versus when it could. A one-model-per-provider replication showed the same pattern but was non-confirmatory. The paper also decomposes an ARC-AGI-3 harness gap for one model on four games, with one counted run per configuration and game and post-result changes to some summary budgets. The results support a bounded author-reported case that losing unrecoverable state can matter; they do not establish general agent performance or portable harness rankings.

What changed

A preregistered preprint tests when agent context policies affect task success rather than only cost. In a synthetic PersistGym-lite probe, the author reports a 92.5-point difference between context-truncation penalties when a needed fact could not be re-observed versus when it could. A one-model-per-provider replication showed the same pattern but was non-confirmatory. The paper also decomposes an ARC-AGI-3 harness gap for one model on four games, with one counted run per configuration and game and post-result changes to some summary budgets. The results support a bounded author-reported case that losing unrecoverable state can matter; they do not establish general agent performance or portable harness rankings.

Evidence

  • Claimed — In a preregistered synthetic PersistGym-lite probe, the author reports that a 24,000-token sliding window scored 15/200 when a needed fact was lost and could not be looked up again, versus 200/200 when the fact was recoverable. The difference between the two context-truncation penalties was 92.5 percentage points (90% CI 89.5–95.5). These are author-reported results for one model in a generated task, not a measurement of real-world agent prevalence.
  • Claimed — A preregistered replication on one model from a second provider showed the same recoverability contrast, but the paper labels it non-confirmatory and reports only one model per provider; the agreement does not establish transfer across models or providers.
  • Claimed — For one model on four ARC-AGI-3 games, the author reports that summarizing old turns while retaining the Standard harness's note-taking prompt recovered 86% of a 63-point gap to the Provider Adapter. Results use one counted run per configuration and game; the paper says the replay share depends on a single run and describes an amendment to summary budgets after some results had been seen.
  • Not established — The study does not establish that context truncation causes comparable success losses in deployed agent work, that the reported ARC component shares are stable, or that any one harness policy is generally preferable across tasks and models.

Strongest baseline

The PersistGym probe compares full history with a truncated window on matched generated episodes; its key recoverable-versus-unrecoverable contrast is within the same model and task regime. The ARC component analysis compares successive configurations against the Standard and Provider Adapter harnesses, but is sparse and path-dependent.

Limitations

  • PersistGym-lite is a synthetic task. The reported effect does not establish its prevalence or magnitude in real agent work.
  • The confirmatory probe uses one model; the second-provider replication uses one model and is explicitly non-confirmatory.
  • The ARC-AGI-3 decomposition uses one model, four selected games and one counted run per configuration and game. Its component shares are point estimates and the replay share depends on a single run.
  • The paper reports amendments after some results had been seen, including a change to two ARC summary budgets; these deviations are disclosed in the paper.
  • No independent reproduction of the experiments or analyses was performed in this review.

What we still don't know

  • No independent reproduction of the PersistGym or ARC-AGI-3 results was inspected.
  • The strongest controlled result comes from a synthetic task, and the study does not estimate how often real agents encounter unrecoverable derived state.
  • ARC component shares rely on one counted run per configuration and game and are sensitive to a replacement run and summary-budget amendments.

Why it matters

Agent harnesses decide which earlier observations and derived facts remain available. If the reported synthetic result generalizes to tasks where an agent cannot reconstruct lost state, context-retention choices can affect success as well as cost. The current evidence is narrow: one synthetic probe, one model per provider, and a sparse ARC decomposition do not establish how often this matters in real work.
