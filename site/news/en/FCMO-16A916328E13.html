China Telecom team releases Xing4.0 MoE model trained on Ascend with MindSpore

China Telecom’s XingChen-AGI team released Xing4.0-29B-A4B on September 17, 2026. Its official repository describes a 29B-total, 4B-active mixture-of-experts model trained on Ascend 910C using MindSpore, with 256K native context. The developers report roughly 96% higher training throughput after several optimizations, measured against their own out-of-box Ascend baseline. The repository also lists benchmark results, but this activation found no independent reproduction; neither claim establishes parity with CUDA systems or broad agent capability.

What actually changed

China Telecom’s XingChen-AGI team released Xing4.0-29B-A4B on September 17, 2026. Its official repository describes a 29B-total, 4B-active mixture-of-experts model trained on Ascend 910C using MindSpore, with 256K native context. The developers report roughly 96% higher training throughput after several optimizations, measured against their own out-of-box Ascend baseline. The repository also lists benchmark results, but this activation found no independent reproduction; neither claim establishes parity with CUDA systems or broad agent capability.

Claim vs. evidence

  • DEMONSTRATED — The XingChen-AGI project published the Xing4.0-29B-A4B release entry dated 2026-09-17 and public model documentation.
  • CLAIMED — The project describes a 29B-total/4B-active model, 256K native context, and training on Ascend 910C with MindSpore/MindFormers.
  • CLAIMED — The developers report approximately 96% greater training throughput after co-optimization compared with their own out-of-box Ascend performance; this is not a comparison with CUDA/NVIDIA.
  • CLAIMED — The repository reports model benchmark scores including 75.0 on SWE-bench Verified and 57.5 on Terminal-Bench 2.1; this activation did not reproduce the scores or audit their full protocols.

Strongest baseline

For the throughput claim, the README names the developers’ out-of-box Ascend performance as baseline. No matched CUDA baseline was presented in the inspected material.

  • This source check did not establish original pretraining token count, cluster size, wall-clock, energy, achieved utilization, total cost or failures/restarts.
