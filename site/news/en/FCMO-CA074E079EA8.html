  • — The plan assigns four GenAI controls Profile Level 0 and four Profile Level 1. The official SSP overview defines Level 0 as cardinal and mandatory; Level 1 controls are risk-tailored basics. The plan says agencies may customize the template for system-specific use.
  • — The Level 0 profile limits overseas-hosted GenAI APIs to RESTRICTED and SENSITIVE NORMAL data, allows up to CONFIDENTIAL and SENSITIVE HIGH for Singapore-hosted APIs, requires a legally binding no-logging/no-retention/no-training commitment with prompt caching up to 24 hours exempted, and requires self-hosted models to run in an environment approved for the highest data classification present.

Why it matters

Public-sector AI adoption depends on rules for sensitive-data routing, vendor retention, model hosting and application safeguards. Singapore’s profile makes several such controls explicit and separates mandatory baseline requirements from risk-tailored controls.
