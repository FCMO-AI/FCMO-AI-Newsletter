Unitree releases UnifoLM-WLA-1.0 Base checkpoint and fine-tuning code

Unitree's official UnifoLM-WLA repository records a September 28 release of the WLA-1.0 Base checkpoint and fine-tuning code. The current official model repository lists a 12.5 GB safetensors checkpoint under Apache-2.0, while the official guide describes a local episode evaluation path. These artifacts make part of the earlier open-release promise inspectable; they do not establish the reported 64-task performance or broad physical generalization.

What actually changed

Unitree's official UnifoLM-WLA repository records a September 28 release of the WLA-1.0 Base checkpoint and fine-tuning code. The current official model repository lists a 12.5 GB safetensors checkpoint under Apache-2.0, while the official guide describes a local episode evaluation path. These artifacts make part of the earlier open-release promise inspectable; they do not establish the reported 64-task performance or broad physical generalization.

Claim vs. evidence

  • DEMONSTRATED — Unitree's official repository lists the WLA-1.0 Base checkpoint and fine-tuning code as released on September 28, 2026.
  • DEMONSTRATED — The official model repository lists a 12.5 GB safetensors checkpoint with an Apache-2.0 license, and the official guide describes a local episode evaluation path.
  • CLAIMED — Unitree reports a 6B policy trained on about 2,500 hours and spanning 64 real-robot tasks.

Strongest baseline

No matched baseline was assessed in this artifact-release review.

The caveat that matters

  • No code was downloaded or executed; no independent physical evaluation was performed.
  • No full per-task success table, trial protocol, dataset completeness audit or cross-end-effector reproduction was completed.
  • The current evaluation guide notes the model server supports Dex1, not WBT; artifact release does not establish broad deployment coverage.

What remains unknown

  • Independent task-level physical outcomes for the released checkpoint and evidence across the claimed 64 tasks remain unavailable in this review.
  • The listed dataset collections and reported task count were not audited for complete coverage, overlap or held-out evaluation.

FCMO Lens

A public base checkpoint and fine-tuning path let researchers inspect and begin testing a humanoid whole-body manipulation policy, changing the release state from a project-page announcement to a reproducible artifact surface. The important open question is whether the reported breadth survives task-level controlled evaluation and independent physical reproduction.
