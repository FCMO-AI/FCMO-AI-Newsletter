SPHQuant reports competitive 2–3-bit VLM accuracy with faster decode than QTIP on NVIDIA GPUs

SPHQuant represents each 8D weight vector using direction and radius, allocates additional quantization precision to the radius to handle outliers, and pairs a compact direction codebook with a rotation-free CUDA inference kernel. The authors report competitive 2–3-bit task accuracy against prior quantizers across several VLMs and a 30.3% decode-throughput gain over QTIP on RTX A6000. In an added RTX 4090 test with Qwen3-VL-8B-Instruct, batch size 1, 256 prefill tokens and 512 generated tokens, they report 288.63 tokens/s, 37.6% faster than QTIP, while using 5.35 GB GPU memory versus QTIP's 5.02 GB. These are paper-reported measurements; no independent reproduction or mobile/embedded evaluation was performed.

Evidence

  • Claimed — SPHQuant decomposes each 8D weight vector into direction and radius, assigns extra precision to radius values to reduce outlier-related degradation, and uses a rotation-free hardware-oriented inference kernel.
  • Claimed — The authors report competitive 2–3-bit VLM task accuracy and 30.3% higher decode throughput than QTIP on RTX A6000. On RTX 4090 with Qwen3-VL-8B-Instruct, batch size 1, 256 prefill tokens and 512 generated tokens, they report 288.63 tokens/s, 37.6% faster than QTIP.
  • Claimed — In the reported RTX 4090 configuration, SPHQuant uses 5.35 GB GPU memory versus 5.02 GB for QTIP; the paper does not establish lower total memory consumption or practical fit on mobile/embedded devices.

Strongest baseline

QTIP is the principal 2-bit baseline. On RTX 4090, the reported throughput is 288.63 tokens/s for SPHQuant, 37.6% above QTIP, with measured GPU memory 5.35 GB versus 5.02 GB.

Limitations

  • All benchmark and performance figures are author-reported; no independent reproduction was conducted.
  • Throughput evaluation covers RTX A6000 and RTX 4090; the authors state that embedded/mobile performance and broader batch/context settings remain untested.
  • For the reported RTX 4090 Qwen3-VL-8B-Instruct configuration, SPHQuant uses 5.35 GB GPU memory versus 5.02 GB for QTIP; encoded weight payload and total GPU memory are distinct.
  • The paper calls for more task-specific evaluation under realistic latency, input-resolution and generation-length constraints.

What we still don't know

  • Accuracy and throughput measurements have not been independently reproduced.
  • Performance is reported on RTX A6000 and RTX 4090, without mobile/embedded hardware or broader batch/context configurations.
  • The measured RTX 4090 GPU memory footprint is higher for SPHQuant than QTIP, and throughput depends on the tested implementation and configuration.

Why it matters

Two- and three-bit weights could reduce VLM storage and memory traffic where higher-precision models do not fit. SPHQuant reports combining outlier-aware spherical quantization and a hardware-oriented kernel, but its speed and accuracy tradeoffs are measured on two NVIDIA GPUs, with higher GPU memory than QTIP in the RTX 4090 configuration. Deployment on smaller devices remains an open question.
