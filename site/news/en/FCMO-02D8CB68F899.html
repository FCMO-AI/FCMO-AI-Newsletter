Four Gemini 4 Argon agents complete Minecraft’s main survival objective in one 27-hour run

An Oct 15 arXiv preprint reports that four Gemini 4 Argon coding agents completed Minecraft’s main survival objective by defeating the Ender Dragon in one randomly generated Java Edition 1.20.4 world on Easy difficulty. The agents coordinated through in-game chat and shared memory, wrote 2,783 programs, and reached the win 27 hours 14 minutes after the first program; the paper says no human intervened. The authors report that the server log recorded the final advancement, and describe 605 deaths and six server restarts. This is a single author-reported run, not a reliability result. Mineflayer exposed nearby world state, including information unavailable to a human player, and supplied pathfinding; prior knowledge of Minecraft was not removed.

Evidence

  • Claimed — The paper reports that four Gemini 4 Argon coding agents defeated the Ender Dragon in a single randomly generated Minecraft Java Edition 1.20.4 survival world on Easy difficulty after 27h14m, using the standard Mineflayer library and its pathfinding plugin; the authors report no human intervention.
  • Claimed — The paper reports 2,783 programs before the win, 605 player deaths, 229 chat messages and six server restarts. It states the final Free the End advancement appears in the recorded server log.
  • Claimed — The authors estimate about $520 at introductory public API list prices ($1,040 at standard list prices) for the four players through the win; these are token-counter/list-price estimates, not invoices or realized serving costs.
  • Not established — One successful Easy-mode run does not establish repeatability, performance on harder or unseen environments, pixel-based play, transfer to software engineering or enterprise work, or an independent reproduction.

Strongest baseline

No matched model or scaffold baseline was run. The related-work section distinguishes prior Ender Dragon completions that used a single agent with 37 high-level tools or a planner plus action-selection model on a fixed seed/Peaceful difficulty.

Limitations

  • The paper describes one run and cannot estimate success probability or run-to-run reliability.
  • Easy difficulty reduces damage and prevents hunger from killing players.
  • Mineflayer exposes nearby blocks and creatures, including hidden state unavailable to human vision, and includes pathfinding; pixel-based control is materially harder.
  • Gemini 4 Argon may have prior Minecraft and Mineflayer knowledge; the experiment does not test a novel game.
  • The world server restarted six times. The authors report 605 deaths and 22% of programs ending in errors.
  • Cost is estimated from token counters and public API list prices, not realized service cost, invoices or alternative-agent comparison.
  • No independent run, raw-log audit, harder difficulty, repeated seed, visual control, or real-world task transfer was assessed in this review.

What we still don't know

  • No independent replay or raw log audit was conducted by the research desk; the paper reports the final advancement in its server log.
  • The single Easy-mode code-interface run does not establish reliability or transfer to harder, pixel-based or real-world tasks.
  • The stated dollar amount uses public list prices and token counters, not measured serving cost or comparison with alternative agents and scaffolds.

Why it matters

The run is a bounded example of general-purpose coding agents sustaining a shared objective across more than a day, generating and correcting tools, dividing work, and recovering from failures. It adds a long-horizon coordination and coding observation to game-agent results, while the one-run design and privileged API limit what it implies about autonomous work elsewhere.
