CHOREO reports long-horizon composition of heterogeneous humanoid skills through a shared trajectory interface

A September 11, 2026 arXiv paper introduces CHOREO, which converts motion clips, pretrained RL rollouts and generated motions into a shared trajectory representation, then composes them with tracker-aware boundary matching and validated bridge motions. In a matched Unitree G1 MuJoCo benchmark of 130 fixed sequences, the authors report 124/130 successful sequences (95.4%), including 45/48 eight-action sequences (93.8%), compared with 20/48 (41.7%) for the strongest listed baseline. The paper reports one execution per task, no physical-robot tests, and closed-loop rollout for only 356 of 3,069 registered source assets. This is a potentially useful modular robotics result, not evidence of reliable real-world or open-ended humanoid autonomy.

In a matched Unitree G1 MuJoCo benchmark of 130 fixed sequences, the authors report 124/130 successful sequences (95.4%), including 45/48 eight-action sequences (93.8%), compared with 20/48 (41.7%) for the strongest listed baseline. The paper reports one execution per task, no physical-robot tests, and closed-loop rollout for only 356 of 3,069 registered source assets. Evidence

  • Claimed — The authors report that CHOREO, which normalizes heterogeneous humanoid skills into SkillMotion trajectories and selects tracker-aware transitions, completed 124/130 fixed Unitree G1 MuJoCo sequences (95.4%), including 45/48 eight-action sequences (93.8%). The strongest listed baseline completed 20/48 eight-action sequences (41.7%) on the same task sequences, motion assets, initial states and frozen GMT tracker. Each task ran once; the comparison is author-reported and has not been independently reproduced.

Strongest baseline

On the same 130 long-horizon sequences and task assets, fixed standing bridge reached 41.7% on eight-action sequences, while motion matching reached 31.2%; all methods used the same initial states and frozen GMT tracker.

Limitations

  • All reported experiments use Unitree G1 in MuJoCo; no physical robot result is reported.
  • The 130 fixed sequence tasks are each run once, so task-level variance and repeatability are not measured.
  • Tasks extend to at most eight actions; longer horizons and out-of-distribution task composition are not evaluated.
  • All 3,069 source instances pass registration, but only 356 receive closed-loop rollout; 353/356 execution success applies only to that subset.
  • Results come from the authors’ paper and have no independent reproduction in this record.
  • A common trajectory representation does not erase controller-specific robustness differences; the paper reports tracker success ranging from 46.7% to 100% on 30 approved trajectories.

What we still don't know

  • No independent reproduction of the reported 130-sequence results was inspected; public code and exact task manifest were not verified.
  • All experiments are in MuJoCo; fixed sequences run once and are limited to eight actions. Physical transfer, variance, longer horizons and unseen task distributions are not established.
  • Only 356 of 3,069 imported trajectories receive closed-loop rollout, so registration success should not be confused with execution reliability across the full library.

Why it matters

The paper explores a systems path for scaling humanoid behavior: reuse trajectories from different skill generators and controllers through an external common interface, avoiding joint retraining. If it generalizes, this could lower the cost of integrating new capabilities. Its evidence currently establishes only author-reported simulation performance on a fixed benchmark.
