Sage-A1.5 tests learned orchestration and verification in a 35B open-weight agent model

Shanghai AI Laboratory describes Sage-A1.5 as a Mixture-of-Experts agent model with 35B total and 3B active parameters whose paper describes learned task orchestration and iterative evidence checking for long-horizon work. The authors report that enabling orchestration raises BrowseComp from 81.7 to 82.8 and DeepResearch-Bench II from 43.7 to 47.5, while broader comparisons are mixed. Model weights are available under Apache-2.0. The results are author-reported, and independent reproduction, external deployment performance, and total inference cost remain open. In one scientist-guided computational-chemistry workflow, the authors report about 12 hours of agent execution versus an estimated human work-week; that human-time estimate is not a matched measurement. The paper depicts quantized local deployment, but reports no matched hardware speed or cost result.

Evidence

  • Demonstrated — Shanghai AI Laboratory’s Oct. 20 arXiv report introduces Sage-A1.5 as a 35B-parameter Mixture-of-Experts agent model trained for task orchestration and iterative evidence checking; its weights are publicly available under Apache-2.0.
  • Claimed — In the paper’s author-run ablation, enabling Sage-A1.5 orchestration changes BrowseComp from 81.7 to 82.8 and DeepResearch-Bench II from 43.7 to 47.5; the paper reports the teacher configuration at 81.6 and 53.6 respectively.
  • Claimed — The paper’s broader comparison table shows mixed results: Sage-A1.5 leads the listed larger models on some measures such as FrontierScience-Olympiad and IFBench, while trailing them on several coding, machine-learning, and research-report benchmarks.
  • Claimed — A preliminary pVisor static test reported about 80% lower resident memory after offload than its running baseline in one run per condition; the paper says savings depend on workload and management/restoration overhead.
  • Not established — The paper and model card do not establish independent replication, robust generalization to external deployments, or a net inference-cost advantage after subagent compute and runtime overhead.
  • Claimed — In one scientist-guided computational-chemistry workflow, the authors report about 12 hours of agent execution and estimate that a human researcher implementing the same workflow from scratch would need about one work-week; the human-time comparison is an estimate, not a measured matched benchmark.
  • Claimed — The paper depicts local quantized Sage-A1.5 variants as a 35B-total, 3B-active-parameter Mixture-of-Experts model and describes deployment across heterogeneous local hardware; it reports no hardware-matched throughput, quality or cost comparison for these configurations.

Strongest baseline

The paper’s own Sage-A1.5 no-orchestration condition is the relevant ablation baseline. For this condition the authors report 81.7 BrowseComp and 43.7 DeepResearch-Bench II versus 82.8 and 47.5 with orchestration. No independent matched reproduction or end-to-end cost comparison is available. The model card’s linked GitHub repository is for the earlier Agents-A1; no A1.5-specific evaluation implementation was identified at that destination.

Limitations

  • All performance comparisons in the report are author-reported; no independent reproduction was identified.
  • The orchestration ablation gains are benchmark-specific and do not establish improved capability across all long-horizon tasks.
  • The comparison table is mixed, with Sage-A1.5 trailing larger models on several coding, ML engineering, deep-research and scientific measures.
  • The preliminary pVisor memory result uses one run per condition and cannot establish general savings or improved inference economics.
  • The model card’s linked GitHub repository is for the earlier Agents-A1 model; an A1.5-specific training/evaluation implementation was not identified at that destination.
  • The paper’s scientific case studies are author-selected demonstrations: the neuroscience task reanalyzes existing data using another framework, chemistry is scientist-guided, and some analyses use simulated or synthetic inputs. They do not establish autonomous discovery of new scientific results. The ~12-hour agent versus estimated human work-week comparison is not a measured matched productivity study.
  • The paper’s 35B-total/3B-active parameter description and heterogeneous local-deployment claims do not establish memory requirements, hardware compatibility, throughput or cost under a matched workload.

What we still don't know

  • The benchmark results and orchestration ablation are author-reported; an independent reproduction under a pinned harness and matched compute has not been located.
  • The paper does not provide a matched end-to-end inference-cost comparison accounting for parallel subagents, token usage, latency and runtime overhead.
  • The approximately 80% resident-memory result is a preliminary static test with one run per condition; workload sensitivity and restoration costs remain unmeasured.
  • The model-card GitHub link resolves to the earlier Agents-A1 repository; the inspected repository does not identify Sage-A1.5 training or evaluation code. This does not establish that no A1.5-specific code is available elsewhere.
  • The paper’s case studies are author-selected workflow demonstrations; no independent review of their artifacts or measured human-versus-agent quality, labor, or cost comparison was identified. The ~12-hour versus estimated one-week chemistry comparison is an author estimate.

Why it matters

Sage-A1.5 makes orchestration and self-checking explicit targets of model training, rather than leaving all coordination to a fixed external scaffold. If independently reproduced, that approach could change how open models handle long-horizon research and engineering tasks. The paper reports modest, benchmark-specific orchestration gains and mixed broader results; it does not establish a general capability advantage or lower total inference cost. The report also describes a scientist-guided chemistry workflow completed in about 12 hours, compared with the authors’ estimate of a human work-week; this is a single, unmeasured time comparison rather than established productivity gain.
