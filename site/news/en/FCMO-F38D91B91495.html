DUMA-Bench reports higher agent attack success in dual-control tests, with a paper–artifact mismatch

DUMA-Bench introduces executable security scenarios in which an agent and user simulator can both shape a changing environment. The paper reports higher attack success under dual-control than solo evaluation (41.1% vs 26.9%), but the linked repository README currently displays 40.3% vs 25.4% over 1,960 trials per regime. That paper–artifact difference has not been reconciled. The comparison also changes multi-turn interaction, user activity and environment evolution together, so it is a regime-level robustness gap rather than an isolated causal estimate of user influence. State assertions are deterministic, while communication assertions use GPT-4o judging.

What changed

DUMA-Bench introduces executable security scenarios in which an agent and user simulator can both shape a changing environment. The paper reports higher attack success under dual-control than solo evaluation (41.1% vs 26.9%), but the linked repository README currently displays 40.3% vs 25.4% over 1,960 trials per regime. That paper–artifact difference has not been reconciled. The comparison also changes multi-turn interaction, user activity and environment evolution together, so it is a regime-level robustness gap rather than an isolated causal estimate of user influence. State assertions are deterministic, while communication assertions use GPT-4o judging.

Evidence

  • Demonstrated — The authors published DUMA-Bench, an executable dual-control security benchmark with eight vulnerability domains and task-level state and communication assertions; the paper reports evaluating 14 models from five model families.
  • Claimed — The arXiv abstract reports attack success rising from 26.9% in solo evaluation to 41.1% under dual-control interaction.
  • Disputed — The linked repository's current README instead reports 1,960 trials per regime with attack success rates of 25.4% solo and 40.3% dual-control; the discrepancy with the paper abstract is unresolved and may reflect a changed artifact or analysis version.
  • Demonstrated limitation — The paper states that solo-to-dual comparison changes multiple factors together and is not a factorial ablation; it does not isolate the causal effect of active user control alone.
  • Demonstrated limitation — The benchmark uses deterministic state assertions for environmental effects but natural-language communication assertions use GPT-4o as an LLM judge, so part of the score depends on a model-based evaluator.

Strongest baseline

The benchmark's solo/passive-user regime is compared with its dual-control regime using shared task definitions and tools. However, dual-control also adds multi-turn communication and interactive environment changes, so the comparison estimates a bundled regime gap.

Limitations

  • The paper's abstract and linked repository README display different aggregate solo and dual-control ASR values; the versions and denominators were not reconciled.
  • The solo-to-dual comparison bundles active user simulation, multiple turns and environment evolution, so it does not isolate one component's causal effect.
  • The user is an LLM-based simulator; the reported regime may not transfer to real human behavior or deployment incident rates.
  • Communication assertions are evaluated by GPT-4o, while only state assertions are deterministic; the aggregate includes judge-dependent outcomes.
  • No independent benchmark execution or audit of trial-level results occurred in this activation.
  • The linked repository README gives different solo and dual-control attack success totals from the arXiv abstract; neither was selected as authoritative without a version audit.

What we still don't know

  • The arXiv abstract reports 26.9% solo and 41.1% dual-control ASR, while the linked current README reports 25.4% and 40.3%, respectively.
  • Aggregate benchmark results have not been independently reproduced from trial-level outputs.
  • The bundled regime comparison does not identify whether user activity, additional turns or environment mutability drives the ASR gap.

Why it matters

Agent security can depend on interaction channels and mutable state that passive prompt tests omit. DUMA-Bench makes those pathways executable across several security domains, but its reported effect size needs reconciliation with the linked artifact and the evaluation regimes bundle several changes together. The evidence supports a benchmark and a paper-reported regime difference, not a causal estimate of user activity alone or a production incident rate.
