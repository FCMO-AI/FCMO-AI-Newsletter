DeepSeek documents public Search and Fetch APIs with per-request billing and account rate limits

DeepSeek’s Oct 17 documentation describes raw JSON Search and Fetch APIs for live web content, using the regular API bearer authentication. Search returns structured results from DeepSeek’s in-house engine; Fetch returns one page as Markdown. The guide lists $0.75 per 1,000 successful requests for each API, with 5 requests per second per account for both. It says server-side calls made through Codex, Claude Code or DeepSeek Harness are currently free, with per-request billing scheduled to start Nov 1, 2026, Beijing time. No API call or retrieval-quality evaluation was performed in this review.
