Qwen AI Platform lists Qwen-Audio-3.1-Realtime-Flash for duplex speech interactions

On October 27, the Chinese-language Qwen AI Platform model changelog listed qwen-audio-3.1-realtime-flash. The entry describes real-time duplex voice conversation, text and audio input/output, tool calling, web search and voice cloning, with a stated 262,144-token context. However, the official Realtime API model-access page currently names Qwen-Audio-3.1-Realtime-Plus, Qwen-Audio-3.0-Realtime-Plus and Qwen-Audio-3.0-Realtime-Flash, but omits the newly listed 3.1 Flash. This documentation gap does not establish that 3.1 Flash is unavailable; no performance, price or direct endpoint test was conducted.
