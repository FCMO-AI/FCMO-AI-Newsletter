What actually changed

Ma et al. introduce AgentMemoryBench, a benchmark for system and personal memory in continual agent use, and propose the MEMs coordination framework. Their paper and public repository describe six task datasets across code, embodied, web and dialogue environments, with offline, online, replay, transfer and repair modes. The paper’s comparison table and reported findings are author-reported; this review inspected indexed paper text and the official repository but did not reproduce results, audit data rights or establish that the benchmark is more valid or complete than prior work.

Claim vs. evidence

  • CLAIMED — The authors describe AgentMemoryBench as a benchmark for system and personal memory in continual agent use. The paper and repository specify six task datasets across code, embodied, web and dialogue environments, evaluated in offline, online, replay, transfer and repair modes.
  • CLAIMED — The authors propose MEMs, a multi-memory coordination framework that uses a trigger model to route retrieval and updates between specialized system- and personal-memory stores. This activation did not independently run the framework or benchmark.
  • DEMONSTRATED — The Lifelong Agents workshop page lists April 26, 2026 as its ICLR 2026 workshop date; the paper is identified as a workshop paper in the paper index.

Strongest baseline

The paper’s Table 1 compares benchmark feature coverage against LoCoMo, HaluMem, StreamBench, LifelongAgentBench, Evo-Memory, MemoryBench and Mem2ActBench. This is an author-defined feature map, not a matched empirical performance comparison.

The caveat that matters

  • The benchmark scope, comparison with prior work and MEMs description are author-reported; the comparison table is not an independent validation of coverage or superiority.
  • This review used the official repository README and indexed workshop-paper text; direct OpenReview PDF access was challenged.
  • No code, dataset, experimental output, judge agreement, data license or baseline result was independently audited or reproduced.
  • The paper’s reported results, if discussed later, remain author-reported and should retain workload- and metric-specific limits.

What remains unknown

  • The authors’ benchmark-coverage comparison and any reported task results were not independently checked; no full experiment, result table, or ablation was reproduced in this review.
  • Data provenance and redistribution/licensing conditions for all task datasets were not audited; the repository setup requires substantial external assets and API credentials for some methods.

FCMO Lens

Persistent agent memory is often evaluated through terminal task accuracy or dialogue recall alone. The paper offers a testbed that explicitly includes online updates, retention, transfer and repair while separating procedural from personal memory. If researchers adopt it, these regimes could expose failure modes missed by offline recall tests; adoption, validity and comparative advantage remain unestablished.
