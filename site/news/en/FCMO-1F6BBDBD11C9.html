PhysAI-Bench reports a 52% best score on trace-derived UAV decisions

The authors present PhysAI-Bench, a multiple-choice benchmark for foundation-model action selection from trace-derived autonomous UAV missions. Its repository describes 10,178 decisions with four candidate actions, a 35-instance human-verified development set and a 500-instance episode-disjoint held-out set. After selecting a model-specific prompt and temperature configuration, the authors report GPT-5.3 Chat at 52.00% held-out decision accuracy, the highest listed score. The reference answer is the action taken in the original mission, not necessarily the only valid or globally optimal action. The repository lists the full dataset, locked split manifests, evaluation code and model outputs as release-pending.

Evidence

  • Claimed — The authors describe PhysAI-Bench as 10,178 trace-derived UAV decision instances with four candidate actions each, a 35-instance human-verified development set and a 500-instance episode-disjoint held-out set.
  • Claimed — After model-specific selection among 12 prompting and temperature configurations, the authors report GPT-5.3 Chat at 52.00% held-out accuracy over three prespecified runs, the highest listed score. The reference action is what occurred in the source mission, not proof of a globally optimal action.
  • Not established — The benchmark result does not establish real-world UAV safety, low-level perception, end-to-end mission completion or that the trace-derived reference action is globally optimal.

Strongest baseline

The same protocol reports GPT-5.2 Chat at 49.40% and xAI Grok 4.5 at 49.07%; the top result is 52.00%. Scores measure trace-derived action choice, not real-world UAV operation.

Limitations

  • All reported performance is author-reported; the research desk did not run code or reproduce results.
  • The full dataset, locked development and held-out manifests, generation and evaluation code, and model outputs were listed as release-pending in the inspected repository.
  • The benchmark covers autonomous UAV missions and structured text contexts rather than raw images, video, LiDAR, audio or other sensor modalities.
  • Evaluation concerns high-level action selection rather than low-level perception or end-to-end task completion.
  • The recorded action is an operational reference from the source trace, not proof of global optimality or the only valid choice.

What we still don't know

  • The complete dataset, frozen split manifests, evaluation code and model outputs were not yet released in the inspected repository.
  • Trace-derived reference actions do not establish that the selected action is uniquely valid or globally optimal.
  • The benchmark does not evaluate real-world flights, raw multimodal perception or end-to-end task completion.

Why it matters

The benchmark targets decision-making where mission goals, physical state, tool use and network conditions interact. Its reported best score is modest, but it measures only trace-derived multiple-choice action selection. The result motivates closer evaluation of context-sensitive agent decisions while leaving real-world flight performance, safety and task completion untested.
