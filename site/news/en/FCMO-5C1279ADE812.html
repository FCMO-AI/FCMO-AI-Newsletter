A paper reports that stronger next-turn metrics did not transfer to customer-support workflow success

Laskar et al. compare gold-history next-action scoring with closed-loop execution on generated multi-turn customer-support workflows. Across Qwen3 4B/14B and Gemma 3 4B/12B, their paper reports that supervised fine-tuning increased average text-turn success by 25.2 percentage points, while tool-turn gains were smaller; the best fine-tuned model completed 8 of 77 tool workflows and no model passed the holistic workflow judge. The result is limited to the authors’ task generator, proprietary workflow dataset, and tested models; it does not establish that turn-level metrics are generally useless.

What actually changed

Laskar et al. compare gold-history next-action scoring with closed-loop execution on generated multi-turn customer-support workflows. Across Qwen3 4B/14B and Gemma 3 4B/12B, their paper reports that supervised fine-tuning increased average text-turn success by 25.2 percentage points, while tool-turn gains were smaller; the best fine-tuned model completed 8 of 77 tool workflows and no model passed the holistic workflow judge. The result is limited to the authors’ task generator, proprietary workflow dataset, and tested models; it does not establish that turn-level metrics are generally useless.

Claim vs. evidence

  • CLAIMED — The authors report that supervised fine-tuning increased average text-turn success from 33.2% to 58.4% across four Qwen3 and Gemma 3 model sizes when each turn was evaluated with gold history.
  • CLAIMED — The authors report smaller average gains on tool turns than text turns; exact tool-call accuracy and argument matching remained low and regressed for some Gemma 3 settings.
  • CLAIMED — In the paper’s table of 77 tool workflows, fine-tuned Qwen3-4B completed 3, Qwen3-14B completed 8, and neither Gemma 3 model completed any; the holistic judge marked 0 of 77 workflows successful for every model condition.

Strongest baseline

Each fine-tuned model is compared with its corresponding zero-shot/base setting using the same paper-defined training and held-out workflow setup; no independent benchmark or matched external method was compared.

The caveat that matters

  • One author-reported study; no independent reproduction was performed in this activation.
  • The workflows are generated from a proprietary customer-support dataset, with GPT-5 agents simulating users and workflow agents and separate model judges filtering/evaluating conversations.
  • The held-out evaluation contains 84 conversations; the results table reports 77 tool workflows. Conclusions apply to this study’s task and evaluation setup.
  • Closed-loop execution uses deterministic parsing, a deterministic user simulator and up to two retries after an invalid tool call; other tool interfaces or recovery policies may produce different results.
  • A 0/77 holistic-judge score is not evidence that these models cannot succeed on other workflow types.

What remains unknown

  • The reported differences have not been independently reproduced, and no public code or dataset artifact was located in the paper.

FCMO Lens

A model can become more likely to produce the expected next response without becoming more reliable at executing a multi-step task using its own prior outputs. If the reported pattern holds, tool-agent evaluation should report local action quality alongside closed-loop completion. The paper tests one customer-support setting and does not establish generality across workflow domains or agent architectures.
