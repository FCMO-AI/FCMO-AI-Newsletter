NVIDIA releases Nemotron Voice Agent v2.3.0 with streaming prefill and host-specific tradeoffs

NVIDIA AI Blueprints released Nemotron Voice Agent v2.3.0 on Oct 19, 2026. The official release adds Nemotron 3.5 Super VL to server and single-GPU recipes, streaming-input LLM prefill to the Generic Assistant, and updates several NIMs and Pipecat. It says DGX Spark serves Nemotron 3.5 Lightning without DSpark speculative decoding because of regressions with streaming prefill. The release documents an implementation and its reported configuration tradeoff; it supplies no measured regression magnitude, comparative voice-task quality, end-to-end latency, or customer adoption result.
