LLM-built simple baselines recover much of published deep-learning gains across 36 scientific prediction tasks

An October 28 arXiv preprint reports that one Claude Opus 5 workflow constructed supervised prediction baselines across 36 tasks reconstructed from selected open-access papers in Nature-, Science- and Cell-family journals. Evidence

  • Claimed — The authors report a median simple-baseline strength of 95.5% and mean of 85.7% across the 36 task medians; 12 task medians matched or exceeded the published deep-learning score.
  • Claimed — The task harness kept private test labels and grading data outside the agent container, while task documentation visible to the agent often stated the reported score.
  • Not established — The paper's results establish that simple baselines routinely invalidate deep-learning contributions across scientific fields or improve peer review outcomes.

Strongest baseline

The denominator compares an automatically built model with a paper-reported deep-learning score and a defined trivial predictor; the study did not rerun each published method under a matched budget, and the SBS value depends on the trivial predictor and task metric.

Limitations

  • Only 36 supervised tasks from a small, selected set of open-access journals were examined; the study used one model, Claude Opus 5.
  • Each task used one fold; for 13 multi-fold studies, comparison uses a single published reference score that may summarize several folds.
  • Task reconstruction may not perfectly match the source study due to unspecified splits, changes in code/data, or curator error.
  • The model may have seen source papers or datasets during pretraining; task documentation often revealed the published score; the study compares with reported results rather than matched reruns of the deep-learning methods.
  • SBS depends on the chosen trivial predictor and metric; equal SBS increments need not correspond to equal predictive utility or scientific value.
  • The linked repository page exposed only README/LICENSE and one commit during inspection; the paper's code-availability claim was not confirmed from visible repository contents.

What we still don't know

  • No independent reproduction of the reported 36-task result or a representative subset was found or run in this activation.
  • The arXiv paper says reproduction code is released, but its linked GitHub page showed only README/LICENSE and a single commit in the inspected rendering.
  • The paper does not establish how frequently these findings occur across scientific publications or whether automated baseline checks change peer-review outcomes.

Why it matters

If this approach generalizes, inexpensive, executable baseline checks could expose when reported predictive gains rely on weak comparisons and make a basic methodological audit more available to authors and reviewers. The study is bounded to 36 supervised tasks, one model, selected open-access journals, and comparisons against published scores rather than matched reruns, so it does not establish prevalence across science or effects on review outcomes.
