What changed

A new arXiv paper introduces WikiTrace, which links each agent-memory lesson to a diagnosis and the raw trajectory it came from, allowing an agent to revisit the source when a lesson is uncertain or conflicts with another. Across eight suites in five benchmarks, the authors report a mean score of 90.2, compared with 79.5 without memory and 87.0 for a matched baseline given the same insights without their source runs. Reported memory-induced Regression is 4.5% versus 6.5% for the matched baseline. These are author-run results under review, not an independent reproduction; most tests use simulated environments and the paper notes that source links do not themselves verify a lesson.

Evidence

  • Demonstrated — Lee, Choi, Baek and Hwang submitted arXiv:2611.14320 v1 on 2026-11-10; the paper and linked code repository are publicly accessible.
  • Claimed — Across eight suites in five agentic benchmarks, the authors report WikiTrace averaged 90.2, versus 79.5 without memory and 87.0 for an Insights Only baseline given the same insights but not source trajectories. The reported advantage over that matched-insight baseline is 3.2 points.
  • Claimed — The authors report memory-induced Regression of 4.5% for WikiTrace, 6.5% for Insights Only and 9.7% for a rerun baseline; the paper reports the WikiTrace confidence interval lies entirely below the rerun band.
  • Claimed — WikiTrace stores each lesson with links to a diagnosis and the source trajectory, which an agent can inspect when a lesson lacks details, conflicts with another, or came from a failed task. The main protocol uses three trials per suite and a Pi terminal agent backed by DeepSeek V4 Flash; the authors also report a smaller evaluation with GLM-5.3-flash.
  • Not established — the research desk did not independently rerun the experiments. These paper-reported benchmark results do not establish performance on production or physical-world agents. The authors state that a source link can help check a lesson but does not verify it, and that full insight injection may not scale to large memories.

Strongest baseline

Insights Only gives the same extracted insights but no source compilations/raw runs and omits the descent prompt; methods share the benchmark runs and test tasks. A no-memory baseline and other memory methods are also included.

Limitations

  • The result is author-reported, submitted to ACL Rolling Review, and not independently reproduced by the research desk.
  • The principal evaluation uses eight benchmark suites and a specific Pi/DeepSeek V4 Flash agent harness, not production agents.
  • A source link makes an insight inspectable but does not verify the insight; the paper says large memories may require an unresolved retrieval method.
  • The reported +3.2 point comparison is against the same insights without source access; the +10.7-point comparison is against no memory and should not be read as the isolated effect of source linkage.

What we still don't know

  • No independent reproduction of the reported per-suite results, regression rates or confidence intervals was performed.
  • Most evaluated environments are simulated; the paper does not establish performance in production or physical-world agents.
  • The paper injects all insights into the first message and notes that prompt growth may not scale to a memory too large for full injection.

Why it matters

Memory can hurt agents when a compact lesson is wrong or applied outside its scope. If the reported gains generalize, linking advice to the experience behind it gives an agent a way to inspect evidence before acting, with a measured 3.2-point average gain over an identical-insights baseline in the paper’s tested suites.
