Heads of Security reports learned attention gates that improve prompt-injection robustness in two open-weight models

The preprint introduces Heads of Security (HoS), which learns small per-head attention gates to separate trusted instructions from untrusted content while allowing the model to reason over that content. On Llama-3.3-70B-Instruct and GPT-OSS-20B, the authors report lower adaptive RL-Hammer attack success against HoS than against an undefended base model or SecAlign++, with means over five runs on 100 held-out InjecAgent goals where available. The official project page shows a mixed utility picture: Llama AgentDyn utility is 18.3% for HoS versus 33.7% for the base model, despite lower reported attack success, while Llama AgentDojo utility is 58.5% versus 53.7%. These remain author-reported results in two open-weight model settings, not independent replication or a deployment-safety result.

What changed

The preprint introduces Heads of Security (HoS), which learns small per-head attention gates to separate trusted instructions from untrusted content while allowing the model to reason over that content. On Llama-3.3-70B-Instruct and GPT-OSS-20B, the authors report lower adaptive RL-Hammer attack success against HoS than against an undefended base model or SecAlign++, with means over five runs on 100 held-out InjecAgent goals where available. Evidence

  • Demonstrated — Version 1 of the Heads of Security preprint was posted to arXiv on October 27, 2026.
  • Claimed — The authors report that learned per-head attention gates reduce adaptive prompt-injection attack success on Llama-3.3-70B-Instruct and GPT-OSS-20B while retaining utility on selected capability and agent benchmarks. On 100 held-out InjecAgent goals, their strongest displayed RL-Hammer attacks reached up to 10.0% ASR against HoS on GPT-OSS-20B (versus 85.2% for SecAlign and 97.2% for the undefended model) and 1.2% against HoS on Llama-3.3-70B (versus 81.6% for SecAlign and 99.4% undefended); where available, these are means over five runs. The official project table also reports uneven utility trade-offs: Llama AgentDyn utility is 18.3% with HoS versus 33.7% base alongside 1.4% ASR, while Llama AgentDojo utility is 58.5% versus 53.7% base alongside 0.9% ASR.
  • Not established — The preprint does not establish end-to-end prompt-injection security, robustness under all adaptive attackers, correct trust classification in deployment, generalization beyond the tested models/benchmarks/scoring protocols, or independently reproduced and deployed-system performance.

Strongest baseline

SecAlign++ (finetuning-based) and ASIDE (architectural instruction/data separation), plus each undefended base model.

Limitations

  • All performance figures are from one arXiv preprint and were not independently reproduced in this activation.
  • The authors state instruction-data separation is not end-to-end: the system does not decide which sources are trusted, and tasks may legitimately require following external instructions.
  • Results cover two open-weight model families and specific datasets, attack budgets, prompts, channels and scoring rules; no production deployment or broad transfer is established.
  • The attacker can adapt after deployment and no finite evaluation establishes security.
  • The linked code repository returned 404; a public GPT-OSS-20B gate artifact and model card are accessible, but this activation did not verify a revision-pinned training/evaluation code path or a Llama gate artifact.
  • The authors’ project table reports an AgentDyn clean-utility trade-off for Llama-3.3-70B: 18.3% for HoS versus 33.7% for the base model, despite a lower reported attack-success rate; utility varies by benchmark.

What we still don't know

  • No independent reproduction of HoS training, RL-Hammer or Claudini results was obtained. A public GPT-OSS-20B gate artifact is available, but the exact code path and revision-pinned evaluation materials were not verified.
  • The evaluation does not establish robustness in deployed agents, across trust-boundary assignments, broader tools or adaptive attacker budgets.

Why it matters

Prompt injection remains a barrier to tool-using agents. If the reported gains replicate, a small architectural intervention could improve the security–utility trade-off without full-model fine-tuning. The authors’ own project table also shows that the trade-off varies by benchmark, including lower Llama AgentDyn utility under HoS; trust labels are externally supplied, so this is one defense primitive rather than an end-to-end security system.
