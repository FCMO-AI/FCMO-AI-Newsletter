What changed

A paper introduces DeltaSelect, which ranks tasks using resampled one-run correlations with full-benchmark scores, calibrates fractional verifier results, then selects tasks under a cost budget for repeated baseline-versus-candidate comparisons. In one author-reported Agent Layer case study, 13 eight-task evaluations led to a configuration with a 58.1% lower recorded cost and a higher calibrated score than the initial custom skills/instructions. The paper also finds substantial mismatch between published DeepSWE estimates and a Codex target harness. These are bounded paper-reported results; the implementation was not run in this review.

Evidence

  • Claimed — DeltaSelect ranks tasks by the fifth-percentile Pearson correlation across 10,000 deterministic resamples, calibrates fractional verifier results to a common full-score scale, and greedily selects tasks within a configured budget. On the DeepSWE snapshot the authors report that 22 of 113 tasks reached a fifth-percentile correlation of at least 0.50.
  • Claimed — In 13 eight-task evaluations of one gpt-5.6-luna low-reasoning Agent Layer skills/instructions case study, the authors report a final configuration with a 42.36% calibrated score at $1.75, compared with the initial custom bundle at 36.46% and $4.18. The analysis uses one endpoint run per task and transfers variance estimates from published mini-swe-agent runs.
  • Claimed — For the same eight tasks and gpt-5.6-luna settings, paper-reported Codex-harness costs were 1.5 to 3.5 times the corresponding DeepSWE estimates; scores also differed. The paper cautions these comparisons establish a planning mismatch, not a causal estimate of the harness effect.
  • Demonstrated — The arXiv paper links a public Agent Layer repository and DeltaSelect implementation page. The repository README identifies itself as an open-source coding-agent orchestration project; this review did not run its code.

Strongest baseline

For the eight-task case study the paper compares initial and adopted Agent Layer skill/instruction configurations under the same stated model, reasoning level, tasks, calibration and weights. The adopted endpoint is $1.75 and 42.36% calibrated score versus $4.18 and 36.46% initially. Each endpoint has one run per task, and uncertainty is transferred from repeated mini-swe-agent data.

Limitations

  • The task selector and calibration choices are not shown to outperform alternative selectors at matched cost; the paper names those comparisons as future work.
  • The published-data projection uses the same DeepSWE snapshot to construct and assess selection, so the evidence is in-sample.
  • The Agent Layer case study has one run per endpoint task, transfers variance from mini-swe-agent, and changes more than one instruction in several evaluations; it does not establish a causal effect of a single edit.
  • A small fixed task set may omit capabilities, magnify task-quality problems and induce specialization; it is not a broad benchmark or safety evaluation.
  • The repository was inspected at README level only; no code, data, or evaluation was executed in this review.

What we still don't know

  • No independent team reproduced the selector, case-study endpoints or reported costs in this review.
  • The selector was not compared with random, cheapest-first or median-correlation selection at equal cost; ranking and published-data example use the same DeepSWE snapshot.
  • The case study covers one model family, one custom harness and one skill/instruction bundle; endpoint uncertainty uses transferred published variance and some iterations changed multiple instructions.
  • The paper links public code, but no repository code or study artifacts were run or independently audited in this review.

Why it matters

If independently validated, fixed low-cost task subsets could support more frequent coding-agent workflow comparisons. The paper's own data show that task reliability varies and that scores and prices from one harness did not transfer to another. The selector's advantage over alternatives and its usefulness beyond one benchmark, model family and custom harness remain unknown.
