llama.cpp v0.9.0 adds FP8 quantization and multi-sequence inference support

The ggml-org/llama.cpp project published v0.9.0 at commit cd959ba on 4 November. The release lists OCP FP8 E4M3 support, a multi-sequence attention operation for unified KV caches, batched tensor-copy APIs, four additional model architectures and audio and server API updates. Maintainers describe the attention change as more efficient, but the inspected release notes provide no quantified benchmark or independent validation.
