ERPBench: A State-Grounded Evaluation Paradigm for Computer-Use Agents in Enterprise Software

Bhagtani et al. report ERPBench, a benchmark that grades screenshot-only computer-use agents against ground-truth ERPNext database state and separately tracks navigation, interaction, commit and database correctness. In the paper’s tested tasks, screen/form progress does not reliably imply a correct stored record; its abstract reports that some agents save in up to 85% of runs but write the correct value in as few as 3%. The authors report five independent runs per task under each configuration. This is a paper-reported benchmark result, not an independent reproduction or a claim about all enterprise agents.
