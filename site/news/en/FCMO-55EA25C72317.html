What changed

OpenAI introduced LifeVal, an evaluation of AI performance on everyday-life tasks selected using American and multinational time-use datasets and supplemented by a demographically representative survey of 3,995 respondents. Its public page reports selected task scores of 90.4%–100% on illustrated workflows, but does not identify which model produced the examples or provide an overall aggregate result or detailed open protocol. The design and scores are first-party; independent replication and real-world user outcomes are not established.

Evidence

  • Demonstrated — OpenAI published LifeVal on 2 November 2026 as an evaluation intended to track model performance on everyday-life tasks involving personal-assistant workflows.
  • Claimed — OpenAI says it selected task areas using the American Time Use Survey and Multinational Time Use Study, then supplemented those sources with a demographically representative survey of 3,995 respondents about where people most want personal-assistant help.
  • Claimed — OpenAI reports selected LifeVal task scores between 90.4% and 100% across examples including kindergarten selection, flood-volunteer coordination, home search, remote game setup and diabetes-related meal planning; the inspected page does not identify which model produced these examples and does not present them as an overall aggregate score.
  • Not established — The inspected public release does not establish which model generated the selected examples, independent replication, broad task-set representativeness, comparative performance across providers or real-world user outcomes.

Limitations

  • All benchmark-design and performance claims are from OpenAI, the benchmark developer.
  • The public page shows selected task-level examples, not an aggregate benchmark result or a provider-matched comparison.
  • The evaluation page does not establish that the tasks, score construction or survey preferences generalize beyond the described population and workflows.
  • No independent reproduction or real-world user outcome evaluation was located in this bounded review.
  • The inspected LifeVal page does not identify which model produced the selected example scores.

What we still don't know

  • The inspected release does not expose the full task set, scoring protocol, task-level failure cases or implementation details needed for independent execution.
  • No independent evaluation or real-world user study was inspected to validate the reported task scores or whether they predict useful assistance.
  • The inspected public LifeVal page does not identify which model produced the selected task-example scores.

Why it matters

Agent evaluation often emphasizes academic or narrow task benchmarks. LifeVal makes everyday assistance, including multi-step administrative and household workflows, an explicit evaluation target. Its value depends on how representative and reproducible the private task set and scoring method prove to be.
