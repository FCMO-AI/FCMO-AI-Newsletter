Anthropic releases FlashProve, a zero-knowledge proof prototype for model inference

Anthropic released FlashProve, an open-source prototype for proving that an inference response matches a commitment to a model’s weights. It reports performance for a 4-bit Llama 4 Maverick model, with substantial proving overhead and a CPU-verifiable proof. Its linked technical report says it was AI-generated and not reviewed in detail; it also says batched zero-knowledge is not proved, executable C++ equivalence to Lean is unproved, and the verified statement concerns an integer-quantized model’s greedy output. The results remain first-party prototype claims, not independent validation or production evidence.

What changed

It reports performance for a 4-bit Llama 4 Maverick model, with substantial proving overhead and a CPU-verifiable proof. Its linked technical report says it was AI-generated and not reviewed in detail; it also says batched zero-knowledge is not proved, executable C++ equivalence to Lean is unproved, and the verified statement concerns an integer-quantized model’s greedy output. The results remain first-party prototype claims, not independent validation or production evidence.

Evidence

  • Demonstrated — Anthropic published a Nov 2, 2026 research post announcing FlashProve, an open-source prototype for zero-knowledge provable inference, with a technical report, protocol description, executable prover and verifiers, and Lean proof artifacts described as released under Apache 2.0.
  • Claimed — Anthropic reports that FlashProve generates inference proofs for 4-bit quantized Llama 4 Maverick, a 400B-parameter mixture-of-experts model, at about 110 tokens per second on one H100 GPU, with proof size around 19 MB per 1,024-token request and GPU time about 70–95 times the vLLM inference time for prompts of the same length.
  • Claimed — Anthropic says the proof binds an inference response to a commitment to particular model weights, while hiding those weights; it does not aim to hide the model architecture.
  • Not established — The public announcement does not establish independent replication, production serving performance, end-to-end operational security, or that proof of inference alone can show a provider is not also using hardware for training.
  • Demonstrated — The public anthropics/FlashProve GitHub repository identifies version 0.16.0 as a research artifact that is not maintained and is not accepting contributions.
  • Claimed — The repository README lists full Llama 4 Maverick proof generation as requiring a single NVIDIA H100 80 GB, CUDA 13.2, 330 GB RAM, 245 GB disk and hours of execution; its stored-proof verifier route is listed separately as requiring under 2 GB RAM.
  • Demonstrated — Anthropic’s technical report says it was AI-generated and had not been reviewed in detail.
  • Demonstrated — The report says the Lean formalization proves zero-knowledge only when requests are processed one at a time, not in batches, and that the executable C++ code is not formally proved equivalent to the Lean specification.
  • Not established — The reported protocol does not establish proof coverage for ordinary floating-point or sampled production replies; it proves an integer-quantized model’s greedy choice, and post-hoc proof generation detects a mismatch after the response rather than preventing delivery of an initially tampered response.

Strongest baseline

Anthropic compares proof-generation GPU time with vLLM inference GPU time for prompts of the same length; the post does not establish an independent matched performance study.

Limitations

  • Performance and cryptographic-security statements are first-party claims in the inspected official post.
  • The reported regime is specific to a single H100 and 4-bit Llama 4 Maverick; it does not establish general performance across architectures, hardware or quantization formats.
  • The cited 70–95x comparison indicates substantial proof-generation cost relative to ordinary vLLM inference.
  • Anthropic explicitly notes that proof of serving inference does not establish that the same hardware is not also training.
  • The official repository labels FlashProve version 0.16.0 a research artifact that is not maintained and is not accepting contributions.
  • The repository README lists full-size Llama 4 Maverick proving as requiring one H100 80 GB, CUDA 13.2, 330 GB RAM and 245 GB disk, with execution measured in hours; these are documented requirements, not independently tested here.
  • Anthropic’s technical report says it was AI-generated and not reviewed in detail; its technical analysis therefore remains first-party provisional material.
  • The report says formal zero-knowledge is proved for one-at-a-time requests, not batch proving, and the executable C++ code is not proved equivalent to the Lean specification.
  • The measured claim concerns the integer-quantized model and greedy-choice token, not exact equivalence to ordinary floating-point or sampled production responses.
  • Proofs are generated post-hoc: they can detect tampering after a reply is delivered, but cannot prevent the initial delivery of a tampered reply; the report treats this as defense in depth.

What we still don't know

  • Performance, proof validity and security are reported by the project authors; no independent benchmark or cryptographic audit was inspected.
  • The announcement explicitly says proof that hardware serves inference does not establish the absence of simultaneous training; production throughput, verification time, service overhead and scaling remain unestablished.
  • The technical report was inspected but says it was AI-generated and not reviewed in detail. The repository’s protocol source, GPU prover, C++ verifier and Lean theorem implementation have not been audited; the report explicitly says executable C++ equivalence to Lean is unproved and zero-knowledge for batched requests is not proved.

Why it matters

Provable inference could give users and auditors a cryptographic way to check model identity across hosted or routed services, and could support some compliance checks. FlashProve offers a public prototype and formal-verification artifacts, but the reported compute cost is substantial, the linked artifacts were not audited here, and proof of inference does not rule out simultaneous training or settle broader compliance.
