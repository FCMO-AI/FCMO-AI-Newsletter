OpenAI lists GPT-Rosalind research API rates and schedules billing from October 5

OpenAI’s API pricing page lists gpt-rosalind-research at $5 per 1 million input tokens, $0.50 per 1 million cached input tokens and $25 per 1 million output tokens; the page states billing begins October 5, 2026. The API changelog dates the trusted-access release and these standard rates to September 8. This makes a model-specific marginal API price visible for approved internal life-sciences research, but the sources reviewed establish the posted schedule rather than an observed customer charge or a cost per validated scientific result.

What actually changed

OpenAI’s API pricing page lists gpt-rosalind-research at $5 per 1 million input tokens, $0.50 per 1 million cached input tokens and $25 per 1 million output tokens; the page states billing begins October 5, 2026. The API changelog dates the trusted-access release and these standard rates to September 8. This makes a model-specific marginal API price visible for approved internal life-sciences research, but the sources reviewed establish the posted schedule rather than an observed customer charge or a cost per validated scientific result.

Claim vs. evidence

  • DEMONSTRATED — OpenAI’s current API pricing page lists gpt-rosalind-research at $5 per 1M input tokens, $0.50 per 1M cached input tokens and $25 per 1M output tokens, and says cache-write pricing does not apply.
  • CLAIMED — OpenAI states that billing for gpt-rosalind-research begins on October 5, 2026; this activation observed the listed date but did not inspect an invoice or transaction proving a customer was charged.

The caveat that matters

  • The billing start date is an OpenAI-published schedule; no invoice, transaction log or independent eligible-customer account was available to confirm that a charge occurred today.
  • The listed token rates do not determine cost per task: input/output token mix, cache hit rate, tool charges, retries and human review are unmeasured.
  • Access remains restricted to approved internal research; the API is not available for customer-facing or external commercial applications according to OpenAI’s current access documentation.
  • The price page alone does not establish scientific capability, research productivity, or cost-effectiveness relative to other models.
  • The sources specify a scheduled billing-start day without an hour or timezone; the exact activation time is unknown.

What remains unknown

  • No independently attributable usage record confirms that an eligible customer was billed on the scheduled effective date.
  • No matched cost per validated scientific workflow is available; token rates omit token mix, tool costs, retries and human supervision.
