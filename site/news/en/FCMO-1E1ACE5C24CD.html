Air Security reports a plugin SHA-pin checkout bypass in four coding agents

Air Security’s September 17 disclosure describes Plugin4Shell, a reported Git checkout ambiguity that can defeat plugin commit pinning if a coding agent does not verify the resulting HEAD. Its authors say they built working PoCs against Claude Code, Codex, GitHub Copilot and Gemini CLI. They report fixes in Claude Code 2.1.179 and Codex 0.146.0, no Copilot fix at disclosure, and no planned Gemini CLI fix after deprecation. The disclosure includes technical detail, but its exploit and product-status claims remain first-party and unreproduced here; it also has a commercial interest in agent supply-chain security. No real-world exploitation or affected-population estimate is established.

Claim vs. evidence

  • DEMONSTRATED — Air Security published a dated technical disclosure on 2026-09-17 and states that its lab built working proof-of-concept exploits against Claude Code, Codex, GitHub Copilot and Gemini CLI. This establishes what the report says, not independent confirmation of the exploits.
  • CLAIMED — Air Security reports that the named agents fail to verify that a Git checkout landed on the pinned commit; it describes a SHA-shaped branch/ref resolution path for Claude Code, Codex and Copilot, and a FETCH_HEAD name-resolution path for Gemini CLI.
  • CLAIMED — The report says Claude Code 2.1.179 and Codex 0.146.0 contain fixes, GitHub Copilot had no shipped fix at disclosure, and Google would not patch the deprecated Gemini CLI. These status statements were not independently checked against vendor advisories in this activation.

Strongest baseline

Post-checkout validation of resolved HEAD against the requested pinned commit is the direct control described by the report; exact product fixes require vendor artifact inspection.

FCMO Lens

Commit pinning is often treated as proof that reviewed plugin code is what an agent executes. If the reported checkout behavior holds, the agent must verify the resolved working-tree commit itself; a marketplace pin alone would not establish that guarantee.
