MLExpert 报告了长期机器学习工程任务中的后训练增益

10 月 15 日发布的 arXiv 论文介绍了 MLExpert：一个总参数量 35B、激活参数约 3B 的 MoE，基于 Qwen3.6-35B-A3B 初始化，并通过分层智能体监督微调和 Windowed Interaction RL 进行后训练，以执行长期机器学习工程任务。在 MLE-Bench Lite 的 22 项任务子集上，作者使用统一框架报告 MLExpert 的任意奖牌比例为 72.7%，基础模型为 37.9%；使用 Claude Code 时报告为 69.7% 对 42.4%。在十项 NatureBench Lite 任务上的对比也报告了相对基础模型的提升。这些是论文报告的基准结果，并非对自主 AI 研究或递归式自我改进的独立证明。

发生了什么变化

10 月 15 日发布的 arXiv 论文介绍了 MLExpert：一个总参数量 35B、激活参数约 3B 的 MoE，基于 Qwen3.6-35B-A3B 初始化，并通过分层智能体监督微调和 Windowed Interaction RL 进行后训练，以执行长期机器学习工程任务。在 MLE-Bench Lite 的 22 项任务子集上，作者使用统一框架报告 MLExpert 的任意奖牌比例为 72.7%，基础模型为 37.9%；使用 Claude Code 时报告为 69.7% 对 42.4%。在十项 NatureBench Lite 任务上的对比也报告了相对基础模型的提升。这些是论文报告的基准结果，并非对自主 AI 研究或递归式自我改进的独立证明。

证据

  • 声称 — 作者报告称，经过后训练的 MLExpert 是一个总参数量 35B、激活参数约 3B 的 MoE，基于 Qwen3.6-35B-A3B 初始化；在 22 项 MLE-Bench Lite 子集上，使用论文的统一评测框架时，获得任意奖牌的比例从 37.9% 提升至 72.7%。
  • 声称 — 在通用 Claude Code 框架下，论文报告 MLExpert 获得任意奖牌的比例为 69.7%，同规模基础模型为 42.4%。
  • 声称 — 论文报告称，在 Claude Code 下的 NatureBench Lite 评测中，MLExpert 有 5/10 项任务达到或超过当前最佳水平，而基础模型为 0/10；其他受测前沿系统在这个小规模子集上也取得较高分数。

最强基线

论文报告的相同评测框架下同规模 Qwen3.6-35B-A3B 基础模型；另行报告了通用 Claude Code 框架比较。

局限

  • 从 37.9% 到 72.7% 的对比是作者在仅有 22 项历史竞赛任务上的报告结果；逐项任务差异及向其他基准的迁移仍需独立检查。
  • Claude Code 与论文自有框架下的结果分别报告，不应混为一谈。
  • NatureBench Lite 只有 十项任务；报告的 5/10 结果不足以证明广泛的科学发现能力。
