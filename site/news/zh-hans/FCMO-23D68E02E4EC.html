一项涉及 66 种配置的研究报告称，智能体任务中的模型与 harness 排名会发生反转

Li 等人报告了 TUA-Bench、ALE-CLI 和 Terminal-Bench 4 中一个不含 H100 的 63 项任务子集上的 66 种模型与 harness 配置。排名会随 harness 改变：在论文的 Terminal-Bench 子集中，Claude 使用 OpenHands 时领先 GPT-6 Astra 7.94 个百分点，使用 PI 时则落后 30.16 个百分点。GPT-6 Astra 使用 PI 时得分为 60.32%，每项任务成本为 $4.66；使用 DeepSeek Harness 时得分为 52.38%，成本为 $19.94。作者发布了适配器、评测代码和 6,204 条评分轨迹。这些是作者报告的结果，每项任务只计入一次运行；不同 harness 的默认设置和实际推理预算并不相同，因此该比较没有隔离 harness 的因果效应，也没有证明排名稳定。

真正发生了什么变化

Li 等人报告了 TUA-Bench、ALE-CLI 和 Terminal-Bench 4 中一个不含 H100 的 63 项任务子集上的 66 种模型与 harness 配置。排名会随 harness 改变：在论文的 Terminal-Bench 子集中，Claude 使用 OpenHands 时领先 GPT-6 Astra 7.94 个百分点，使用 PI 时则落后 30.16 个百分点。GPT-6 Astra 使用 PI 时得分为 60.32%，每项任务成本为 $4.66；使用 DeepSeek Harness 时得分为 52.38%，成本为 $19.94。作者发布了适配器、评测代码和 6,204 条评分轨迹。这些是作者报告的结果，每项任务只计入一次运行；不同 harness 的默认设置和实际推理预算并不相同，因此该比较没有隔离 harness 的因果效应，也没有证明排名稳定。

主张与证据

  • 声称 — 作者在 TUA-Bench、ALE-CLI 和 Terminal-Bench 4 的一个不含 H100 的 63 项任务子集上评测了 66 种模型与 harness 配置，并报告模型排名会随 harness 和任务集变化。
  • 声称 — 在论文的 Terminal-Bench 4 子集中，Claude 使用 OpenHands 时领先 GPT-6 Astra 7.94 个百分点，使用 PI 时落后 30.16 个百分点；GPT-6 Astra 使用 PI 时得分为 60.32%，每项任务成本为 $4.66；使用 DeepSeek Harness 时得分为 52.38%，成本为 $19.94。
  • 声称 — 论文发布了适配器、评测代码和 6,204 条评分任务轨迹，因而可以检查这些工件，但这并不能独立验证报告的结果或账单。

最强基线

论文在给定模型的 harness 之间保留了相同任务标识；但没有统一所有 harness 默认设置或推理预算。

最重要的限制

  • 结果由作者报告；el equipo de investigación 未重新运行基准，也未核验服务商账单。
  • 每项任务在重试后只计入一次运行；研究没有证明运行间方差或排名稳定性。
  • 各 harness 的上下文管理、重试、压缩、轮数限制和实际推理预算不同；这不是一项能够隔离 harness 因果效应的匹配干预。
  • 任务子集和奖励定义属于本次评测活动，并非对上游基准排行榜的直接复现。

仍然未知的部分

  • 没有独立的多次运行匹配复现，也没有排名不确定性估计。
  • 论文采用不同的 harness 默认设置；“高”推理力度标签也未必代表相同推理预算。

FCMO 视角

报告中的排名反转表明，单看模型排名未必能预测部署后的智能体性能或 API 成本。结果支持针对预期任务同时评测模型与 harness，但在匹配预算下的因果效应和多次运行的不确定性仍未解决。
