Apple介绍五种基础模型组成的系列及设备端NAND驻留权重与按提示路由

在2026年六月8日发布的技术介绍中，Apple将第三代Apple Foundation Models描述为一个由五种模型组成的系列，涵盖设备端与Private Cloud Compute部署。Apple称，AFM 3 Core Advanced是一个总量为20十亿参数的稀疏模型，每次根据请求激活1至4十亿个参数；完整模型权重存放在NAND中，由稠密模块按提示选择专家，并在生成过程中定期重新选择。Apple将该设计归因于其指令跟随剪枝研究。该公司还称，AFM 3 Cloud Pro通过与Google和NVIDIA合作，将Private Cloud Compute扩展到Google Cloud中的NVIDIA GPU。这些是供应商对架构和部署的描述，不是独立性能测量或公开复现。

真正发生了什么变化

在2026年六月8日发布的技术介绍中，Apple将第三代Apple Foundation Models描述为一个由五种模型组成的系列，涵盖设备端与Private Cloud Compute部署。Apple称，AFM 3 Core Advanced是一个总量为20十亿参数的稀疏模型，每次根据请求激活1至4十亿个参数；完整模型权重存放在NAND中，由稠密模块按提示选择专家，并在生成过程中定期重新选择。Apple将该设计归因于其指令跟随剪枝研究。该公司还称，AFM 3 Cloud Pro通过与Google和NVIDIA合作，将Private Cloud Compute扩展到Google Cloud中的NVIDIA GPU。这些是供应商对架构和部署的描述，不是独立性能测量或公开复现。

主张与证据

  • 已证实 — Apple于2026年六月8日发布介绍，称第三代Apple Foundation Model系列由五种模型组成，覆盖设备端与Private Cloud Compute部署。
  • 声称 — Apple称AFM 3 Core Advanced是原生多模态的20B参数稀疏模型，会根据请求激活1到4十亿个参数，将完整权重存放在NAND中，并按提示选择专家。
  • 声称 — Apple称AFM 3 Cloud Pro通过与Google和NVIDIA合作，将Private Cloud Compute扩展到Google Cloud中的NVIDIA GPU，并维持Apple所述的隐私保障。本次审查没有独立审计这些保障。

最强基线

Apple将其方案与需要把所有权重放在活动DRAM中的传统稠密或稀疏模型作比较，并称标准的逐token MoE专家切换受NAND到DRAM带宽限制。公告没有给出匹配基线测量。

最重要的限制

  • 架构、性能和隐私内容来自Apple的第一方说法；本次没有进行独立评估。

  • 六月8日的公告早于36小时新鲜度窗口，本次激活没有确认由此产生的新事件。

仍然未知的部分
