置信度排序并行扩散中的条件独立性边界

作者分析了一类独立更新 sampler：它们依据逐位置分布选择并行 token 写入位置，并独立采样每个所选位置。作者称，只有当写入位置在给定已固定 token 的条件下相互独立时，单步结果才能匹配训练联合分布；仅凭逐位置边缘分布无法验证这一条件。在合成任务 ScanAndAdd 上，作者报告称，按置信度排序的写入具有完美的样本有效性指标，但生成 token 分布的总变差距离约为采样噪声基准的 29x。该定理以所定义的 sampler 类为前提；偏差测量来自单一合成任务，不能证明已部署模型存在同等幅度的问题。

真正发生了什么变化

作者分析了一类独立更新 sampler：它们依据逐位置分布选择并行 token 写入位置，并独立采样每个所选位置。作者称，只有当写入位置在给定已固定 token 的条件下相互独立时，单步结果才能匹配训练联合分布；仅凭逐位置边缘分布无法验证这一条件。在合成任务 ScanAndAdd 上，作者报告称，按置信度排序的写入具有完美的样本有效性指标，但生成 token 分布的总变差距离约为采样噪声基准的 29x。该定理以所定义的 sampler 类为前提；偏差测量来自单一合成任务，不能证明已部署模型存在同等幅度的问题。

主张与证据

  • 声称 — 对于一种独立更新 sampler，如果其并行写入集合仅依据逐位置分布（或与目标联合分布无关的随机性）来选择，论文称：只有当所选位置在给定已固定 token 的条件下相互独立时，乘积分布更新才与目标单步条件分布一致。依赖的位置组无法由该乘积分布精确表示。
  • 声称 — 在作者构造、联合分布具有闭式形式的合成任务 ScanAndAdd 上，作者报告称，按置信度排序的并行写入在格式有效性、正确性和唯一性指标上均达到完美结果，但生成 token 分布与训练分布之间的总变差距离约为采样噪声基准的 29x。
  • 声称 — 论文报告称，在测量所用的样本规模下，ScanAndAdd 中人工指定的写入顺序可生成无法与训练样本区分的 token 分布，同时保持 0.987–0.996 的正确率；这是该任务特定可达到的顺序，不是通用解码规则。

最强基线

在 ScanAndAdd 上，论文将按置信度 remasking 与根据任务结构人工指定的写入顺序比较。后者是该任务特定的可达上限，不是通用解码基线。论文还将 PUNT 的近似条件独立性检验列为相关方法。

最重要的限制

  • 29 倍总变差结果是在一个联合分布已知的合成任务上测得；论文指出，其实验并未复现产品模型的架构、解码策略或部署环境。
  • 定理只适用于论文定义的独立更新 sampler 类。若 scheduler 使用当前逐位置分布之外的额外领域信息，则不满足定理 4 的前提；该结果不是对所有并行解码方式的一般性不可能结论。
  • 样本在格式、正确性和唯一性上完美，并不意味着分布匹配；不过本研究只在 ScanAndAdd 上测量了这一差异。
  • 数学结果和实验由作者报告；研究团队没有独立审计证明、运行代码或复现实测结果。
  • 本文引用了 PUNT；该工作此前已报告使用近似条件独立性检验进行并行采样。不能把本文描述为首个考虑依赖关系的方法；其精确的新颖性边界是逐位置信息条件下的不可能性结果。
  • arXiv 上 PUNT 的 HTML 端点返回 404；本次只查看了其官方摘要和 API 元数据。

仍然未知的部分

  • ScanAndAdd 实验及定理与实现之间的对应关系尚未经过独立复现或审计。
  • 在 ScanAndAdd 之外（包括自然文本或图像任务以及新型学习式 scheduler）的分布保真效果仍未知。

FCMO 视角

并行解码可以减少生成步骤，但 token 级置信度高或单个样本有效，并不能单独证明输出联合分布匹配训练分布。论文为一类独立 sampler 给出了精确条件，并用合成示例展示正确性与分布保真度可能分离。这有助于 sampler 设计和评估，但其实用规模和迁移性仍待验证。
