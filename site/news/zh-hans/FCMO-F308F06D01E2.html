MechSparse 发现，在模式严格的抽取任务中，因果稀疏适配器选择不如激活范数

Xuan 等人测试激活修补分数能否比随机、权重幅值、激活范数和梯度/Fisher 启发式更好地选择 LoRA/QLoRA 位置。在 Ministral-8B/NF4 的三个任务单元中，他们提出的因果选择器没有赢得主要指标。在三随机种子的斯瓦希里语 span-JSON 抽取主任务中，MechSparse-C 的 span+type F1 比 activation-norm 低 0.028（按汇总预测计算的 95% bootstrap 置信区间 [-0.048,-0.007]），与幅值方法没有明确统计差异，并优于随机和梯度/Fisher。单随机种子的英语到斯瓦希里语翻译单元中，所有成对比较均在 0.30 BLEU 以内且无可靠差异。作者认为选择器效果取决于任务，但“在内容主导任务中使用因果选择”的建议仍未得到证明：所有测试单元都没有给出多随机种子的正向结果。研究只测试了一个模型和三个有限任务单元；在复用掩码前，基于探针的选择每单元约需 1.7 个 L40S GPU 小时。

真正发生了什么变化

Xuan 等人测试激活修补分数能否比随机、权重幅值、激活范数和梯度/Fisher 启发式更好地选择 LoRA/QLoRA 位置。在 Ministral-8B/NF4 的三个任务单元中，他们提出的因果选择器没有赢得主要指标。在三随机种子的斯瓦希里语 span-JSON 抽取主任务中，MechSparse-C 的 span+type F1 比 activation-norm 低 0.028（按汇总预测计算的 95% bootstrap 置信区间 [-0.048,-0.007]），与幅值方法没有明确统计差异，并优于随机和梯度/Fisher。单随机种子的英语到斯瓦希里语翻译单元中，所有成对比较均在 0.30 BLEU 以内且无可靠差异。作者认为选择器效果取决于任务，但“在内容主导任务中使用因果选择”的建议仍未得到证明：所有测试单元都没有给出多随机种子的正向结果。研究只测试了一个模型和三个有限任务单元；在复用掩码前，基于探针的选择每单元约需 1.7 个 L40S GPU 小时。

主张与证据

  • 已证实 — Xuan 等人介绍了一种稀疏 PEFT 选择器：根据干净/受损激活修补恢复率对注意力头和 MLP 块排序，并且只在选定位置训练适配器；MechSparse-C 还为层内有界联合子集增加了贡献分数。
  • 声称 — 在三随机种子的斯瓦希里语 span-JSON 抽取主任务中，作者报告 MechSparse-C 的 span+type F1 比 activation-norm 低 0.028，按汇总预测计算的成对 95% bootstrap 置信区间为 [-0.048,-0.007]；与幅值方法没有明确统计差异；相对随机和梯度/Fisher 分别高 0.079 和 0.174。
  • 声称 — 在单随机种子的英语到斯瓦希里语翻译任务单元中，作者报告四种选择器均处于 0.30 BLEU 以内，且所有成对 bootstrap 置信区间都包含零。
  • 推测 — 当瓶颈是内容敏感性而不是输出格式时，因果或 probe-delta 选择器能改善稀疏适配。

最强基线

在主要 span+type F1 指标上，activation-norm 领先（0.539，对比 MechSparse-C 的 0.511）。报告的汇总预测比较无法确定幅值方法与 MechSparse-C 的差异是否显著。单随机种子的翻译结果没有确立胜者。

最重要的限制

  • 所有实验结果均为作者报告。此次审查无法访问论文链接的匿名材料端点，也没有复现结果。
  • 研究只测试了一个基础模型和三个有限任务单元。论文作者指出，内容主导任务中的因果选择分支没有任何主要指标上的正向证据。
  • 主分析的 bootstrap 汇总了三个随机种子的 600 个样本并重采样样本；作者指出，按随机种子进行的检验统计功效不足，按样本计算的区间可能低估种子间不确定性。
  • 斯瓦希里语抽取和英语到斯瓦希里语翻译的补充单元都只有一个随机种子；BLEU 约为 11 的翻译结果可能受到地板效应影响，所有成对区间均包含零。
  • 在复用掩码前，每个任务单元的修补评分约需 1.7 个 L40S GPU 小时，而激活范数和幅值选择器只需数秒。
  • 作者报告了不对称的任务信息暴露：activation-norm 和因果选择器都能看到 64 条任务提示，而随机选择器看不到。AdaLoRA 和 Taylor-importance 对比留待后续工作。
  • 该研究没有证明广泛的多语言迁移、优于秩分配方法，或一条普遍适用的因果选择规则。
  • 论文的主结果显示，在主要 span+type F1 指标上 activation-norm 优于 MechSparse-C；这与“因果定位普遍改善稀疏 PEFT 选择”的说法相矛盾。
  • 所有测试任务单元中，所提出的因果选择器都没有赢得主要指标；作者明确称内容主导任务分支尚未得到确认。

仍然未知的部分

  • 论文称已发布掩码、分数、预测和按随机种子划分的评估文件，但此次审查无法通过可用网页工具访问链接的匿名材料端点；尚未进行独立复现。
  • 在论文测试的三个单元中，内容主导任务使用因果/probe-delta 选择器的建议没有任何多随机种子的主要指标正向结果。

FCMO 视角

这一负面结果提醒我们，不能假定机制定位会改善稀疏微调：在该论文以输出模式为主的核心指标上，低成本的激活范数启发式胜出，而成本更高的因果方法没有赢得任何主要指标。如果这一结果能够泛化，它会改变局部适配器位置选择，并影响可解释性引导 PEFT 的成本核算。作者提出的任务相关规则仍属初步结论。
