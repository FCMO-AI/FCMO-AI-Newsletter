Qwen 报告称其多语言实时口译模型的延迟有所降低

Qwen 于 2026 年九月 18 日发布 Qwen3.8-LiveTranslate，将其介绍为实时口译产品。团队报告称，平均滞后时间（LAAL）从上一代的 2.8 秒降至 2.3 秒，并介绍了说话人分离、双语同步显示和长上下文消歧功能。Alibaba Cloud Model Studio 列出了该实时模型 API，支持音频和图像输入、文本和音频输出、60 种源语言及 29 种语音输出语言。延迟和质量说法由供应商报告；本次审查未获得完整评测协议或匹配条件下的独立结果。

真正发生了什么变化

Qwen 于 2026 年九月 18 日发布 Qwen3.8-LiveTranslate，将其介绍为实时口译产品。团队报告称，平均滞后时间（LAAL）从上一代的 2.8 秒降至 2.3 秒，并介绍了说话人分离、双语同步显示和长上下文消歧功能。Alibaba Cloud Model Studio 列出了该实时模型 API，支持音频和图像输入、文本和音频输出、60 种源语言及 29 种语音输出语言。延迟和质量说法由供应商报告；本次审查未获得完整评测协议或匹配条件下的独立结果。

主张与证据

  • 已证实 — Qwen 于 2026-09-18 发布了 Qwen3.8-LiveTranslate；Alibaba Cloud Model Studio 列出了实时 API 模型 `qwen3.8-livetranslate-flash-realtime`，支持音频和图像输入，以及文本和音频输出。
  • 声称 — Qwen 报告称，新系统将平均滞后时间（LAAL）从上一代的 2.8 秒降至 2.3 秒。本次检查的公告没有提供完整测试协议、按语言对划分的结果或独立评估，因此这项比较仍是供应商报告。
  • 声称 — Qwen 介绍了实时说话人分离、原文与译文同步显示以及长上下文消歧；Alibaba Cloud 文档列出 60 种源语言和 29 种语音输出语言。本次未独立评估翻译质量或说话人归属。

最强基线

Qwen 将新系统与平均 LAAL 为 2.8 秒的上一代产品比较；本次未检查到匹配条件下的独立比较或第三方基线。

最重要的限制

  • 延迟和质量比较由 Qwen 报告；本次没有独立复现。
  • 检查到的公告未提供完整评测协议、置信区间、语言对细分或音频条件分析。
  • LAAL 数值更低本身不能证明总体翻译质量或实用性更好；延迟和内容保真度可能存在取舍。
  • 该系统通过 API 提供；本记录未证明其权重可下载、可本地推理或可开放复现。
  • Alibaba Cloud 文档列出产品能力和语言覆盖范围，但不构成独立性能评估。

仍然未知的部分

  • 从 2.8 秒降至 2.3 秒的平均滞后比较以及翻译质量说法均来自第一方。检查到的公告没有公开完整测试条件、语言对细分、音频条件、样本量或独立结果。
  • 可用性和性能可能因 API 区域、协议、语言对及输入模态而异；本次没有采集跨区域或生产环境测量。
