Arm 发布 Neoverse CSS N4：面向 AI 和云基础设施、可高度配置的 8–128 核子系统

Arm 推出 Neoverse CSS N4，这是围绕 Neoverse N4 CPU 核构建、以 RTL 交付的可配置计算子系统，面向云、网络和 AI 基础设施。合作伙伴可配置每个 die 的 8–128 个核心、缓存、内存、I/O、加速器连接和 chiplet 互连；Arm 列出最高 3.8 GHz、LPDDR6 和 PCIe Gen 7 支持。Arm 声称相较 CSS N3，每 socket 性能最高 2x、每瓦性能最高 1.25x、内存带宽最高 1.75x。这些比较数字都是供应商声明，本次运行未找到独立匹配基准，而且可能包含配置/工艺/平台变化，不一定仅代表核心层改进。

为何重要

AI 系统越来越多的非加速器工作花在编排、检索、网络、存储、工具执行和喂给加速器上。一个预集成、高度可配置、具现代内存、I/O 和 chiplet 接口的 CPU 子系统，可以缩短为这类工作负载构建定制 host/control 芯片的路径。这项发展应被视为使能基础设施，而不是新 AI 加速器或模型训练突破的证据。
