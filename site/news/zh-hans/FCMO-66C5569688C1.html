预印本报告称，答案对齐记忆嵌入可降低长上下文推理成本

2026年九月22日的一篇 arXiv 预印本提出 Context-to-Answer-Aligned Memory Compression（CMC）：将文档片段压缩为解码器嵌入空间中的记忆表示，按问题选择相关表示，并与局部完整文本窗口组合进有界 KV 缓存，同时保持解码器权重不变。在 A100 GPU 上使用 Llama-3 8B、Mistral-7B 和 Gemma-2 9B 对四个抽取式问答基准进行测试，作者报告生成 3,000 个 token 时推理时间最多降低 20.0%、能耗降低 20.3%，峰值预留 GPU 内存也有所降低。结果并不一致：在全量数据设置下，Mistral 的 SQuAD 精确匹配（EM）低 14.7 个百分点，在 HotpotQA 上也出现退步。这篇预印本尚未经过独立复现；主要实验使用标注答案偏移来定位局部窗口，另有附录测试 BM25、CME 引导和中点等替代方案。

证据

  • 已展示 — 2026年九月22日的 arXiv 预印本提出 CMC：将上下文压缩成解码器空间的记忆表示，通过问题引导选择并与局部窗口共同放入有界 KV 缓存，同时冻结解码器权重。
  • 声称 — 作者报告了基于 A100 GPU、九种编码器—解码器组合和四个问答基准的实验。在 1,000 条 SQuAD 样本、生成 3,000 个 token 时，报告的推理总时间最多降低 20.0%、能耗降低 20.3%；Llama-3 8B 和 Mistral-7B 的峰值预留 GPU 内存也降低。这些是论文报告的结果，尚未独立复现。
  • 声称 — 在全量数据设置下，Mistral 方案的 SQuAD 精确匹配（EM）比基线低 14.7 个百分点，在 HotpotQA 上也低于未压缩的局部窗口基线；因此，测试结果并非在所有模型和任务条件下都为正。
  • 声称 — 主要基准比较使用标注中的答案偏移来确定局部上下文窗口的中心。附录 A.8 报告了三种数据集上的无标注定位测试，包括 BM25、CME 引导和中点方法；在所测条件下保留了参照 EM 的 78–99%。这尚不能证明结果可迁移到未见工作负载或生产环境。
  • 尚未确立 — 本次审查未能确认独立复现、部署工作负载评估或完整的生产成本比较。

最强基线

主要受控基线使用相同解码器、训练数据、评估划分和推理设置，但直接输入局部窗口而不压缩。已发表的提示压缩基线使用不同解码器架构，可比性较弱。

局限

  • 只有一篇尚未独立复现的 arXiv 预印本；所报结果均由作者完成。
  • 实验使用 NVIDIA A100 80 GB GPU、4-bit 量化的冻结解码器和抽取式问答任务；能耗按时间比例分摊。
  • 效率测量主要针对 GPT2-Large 上的 SQuAD；峰值内存测试覆盖 Llama 和 Mistral。
  • 全量数据设置下，Mistral 在 SQuAD 上明显低于基线，在 HotpotQA 上也退步；作者将其归因于训练步数不平衡，但该解释未经过独立检验。
