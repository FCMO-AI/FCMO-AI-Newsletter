发生了什么变化

论文分析了使用采样 token 的 on-policy 蒸馏（OPD），并为固定前缀处反向 KL 梯度估计的可靠性定义了信息效率比（IER）。作者在有限的 top-K 候选集上近似 IER，并将其排序与现有的效用分数结合。在部分数学和医学推理设置中，作者报告称，组合选择器可在 0.1%–1% token 预算下接近或超过完整 OPD，但不同设置的结果并不一致。该方法选择的是用于损失计算的 token：学生完整回答仍会生成，教师监督仍会计算，因此尚未证明端到端算力按比例节省。

证据

  • 声称 — 作者基于学生生成前缀处采样反向 KL 梯度的信号-噪声分解，定义了信息效率比（IER），并使用最优标量基线；其倒数对应于该基线下的相对均方估计误差。
  • 声称 — 作者报告称，在部分数学和医学推理设置中，将 IER 与现有的效用型 token 选择器结合后，可在 0.1%–1% token 预算下达到或超过完整 on-policy 蒸馏的结果；不同选择器、模型和任务的结果有所差异。
  • 声称 — IER 使用学生与教师各自 top-K token 的有限并集，再加上采样 token 进行近似；缺失的对数概率以较小值填充，对数比值则为数值稳定性而截断。

最强基线

论文相同任务和模型对设置下，不做 token 选择的完整 OPD，以及现有的效用型选择器。

局限

  • IER 估计采用有限的 top-K 候选并集，而不是完整词表；缺失对数概率填充值和截断都可能改变近似结果。
  • 低 token 预算下的结果因任务、模型和选择器而异；论文包含性能下降的情况，也有其他选择器更优的案例。
  • 只选择一小部分 token 不会省去完整学生回答生成或教师监督计算，因此论文未能证明端到端算力按比例节省。
  • 本次激活未进行独立复现或匹配的性能剖析。

尚不清楚的问题

  • 尚无匹配的独立复现来测量 IER 增益对候选集覆盖范围、缺失概率填充值和比值截断的敏感性。
  • 较低的 token 预算本身并不能证明端到端算力节省，因为仍需生成完整学生回答并计算教师监督。

为何重要

稀疏 OPD 方法能够挑选有用的监督，却可能忽视单样本梯度估计是否可靠。IER 提供了不同的选择依据，论文报告的实验中，它改善了部分低 token 预算对比。这是一项范围有限的后训练方法结果；实现敏感性和端到端算力节省仍有待查明。
