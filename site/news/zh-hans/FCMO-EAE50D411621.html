发生了什么变化

27 日十月的一篇 arXiv 预印本提出杠杆指标：权重更新的 Fisher 二次型除以同一检查点上等长随机方向的二次型。在已发布的 Olmo-3、Tülu-3、Zephyr 和 OLMo-2 检查点中，作者报告两个预训练窗口在 51,167 个 token 的混合语料上杠杆接近 1，SFT 约为 5，RL-Zero/RLVR 为数百至低数千，DPO 则从数百到数万。受控训练和一项 OLMo-2 DPO 配方复跑支持其中部分对比。论文还称，在已测试情形中，一个符号结构项可以预测随机稀疏化权重差值造成的损伤。这些是作者报告的研究结果。该指标测量下一个 token 分布的局部变化，而非任务能力；结果受限于研究使用的语料和训练条件，本次未进行独立复现。

证据

  • 声称 — 作者将杠杆定义为更新方向的 Fisher 二次型除以同一检查点上等长随机方向的平均二次型，使用精确的前向模式 Jacobian-向量积，而非有限差分近似。它衡量每单位权重位移带来的局部下一个 token 分布变化，并不衡量任务能力。
  • 声称 — 在已发布检查点中，论文报告：Olmo-3 的两个预训练窗口在包含四个领域、51,167 个 token 的语料上杠杆接近 1；SFT 约为 5；RL-Zero/RLVR 约为 388–1,508；DPO 约为 378–22,570。这些是作者在所选模型、权重差值和语料上计算的数值。
  • 声称 — 在受控实验中，作者报告，SFT 或 DPO 轨迹推进时，0.5B 和 7B 模型的更新杠杆会下降；对一项已发布的 OLMo-2-1B DPO 配方进行两次复跑，其权重位移和杠杆分别与原结果相差不超过 1% 和 4%。许多比较使用两到三种随机种子；7B 受控组只用一种。
  • 声称 — 对于预测损伤低于约 0.5 的已测试权重差值，论文报告，其符号翻转基准对随机丢弃并重缩放造成的稀疏化损伤预测误差在 2.1 倍以内。当预测损伤较大时，该关系不再成立；研究测试了六个权重差值和三种保留比例。
  • 尚未确立 — 预印本没有证明杠杆能够衡量任务能力、较高杠杆会带来更好的下游表现、局部排序能在更长或任务专用数据上保持，也没有证明结论可推广到其他训练系统和模型系列。文中所述外推测试结果不明确。

最强基线

在作者的 51,167-token 混合语料上，两个 Olmo-3 预训练窗口的杠杆分别为 0.78 和 0.95，匹配各向同性随机方向的基准值为 1；若干训练后权重差值的数值高得多。论文评估的是输出分布的局部曲率，而非任务表现。

局限

  • 所有量化发现均由作者报告，本次未进行独立复现。
  • 主语料包含四个领域的 51,167 个 token；其结论能否迁移至更长或任务专用语料尚未确定。
  • 许多受控比较使用两到三种随机种子；7B 受控组只使用一种，OLMo-2 复现仅涉及一个已发布的 DPO 阶段。
  • 杠杆是下一个 token 分布的局部 Fisher 曲率，并不直接衡量任务能力或效用。
  • 论文报告外推测试结果不明确。
  • bf16 存储会将部分坐标置零，并可能扭曲一些对齐指标。

尚不清楚的问题

  • 本次审查未独立复现精确 Fisher 测量、随机基准抽样和检查点比较；论文称将发布代码和语料。
  • 主要指标基于 51,167 个 token 的四领域语料和少量已发布权重差值平均得出；它在更长或任务专用评测数据上的有效性尚未确立。
  • 论文预注册的外推预测，在 GSM8K 和 MATH-500 中少量可评分权重差值上的结果不明确。

为何重要

如果经过复现并与任务结果建立联系，匹配随机方向的 Fisher 指标或可用于比较训练阶段如何改变模型输出，并估计稀疏化权重差值何时会造成损伤。论文没有证明杠杆较高就代表能力更强，也没有证明结论适用于其他模型、任务或训练流程。
