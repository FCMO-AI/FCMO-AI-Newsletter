发生了什么变化

一篇预印本提出 Latent Sparse Attention（LSA）：它在学习得到的潜在空间中聚类键，使查询搜索簇摘要，而不是逐个为所有键打分。作者测试显示，其蒸馏版本在最长 10M token 的上下文中接近所测模型基线，并在两类特定模型和 H200/B300 硬件上显著缩短了单层注意力的预填充与解码时间。论文报告的端到端服务提升小于单层 headline 数值；100M token 结果是外推值。本次审查无法访问论文链接的实现，也未进行独立复现。

证据

  • 已展示 — 作者于 2026-10-30 发布 arXiv:2610.42147v1，介绍 Latent Sparse Attention，其中包括面向预训练模型的蒸馏版本和原生训练版本。
  • 声称 — 作者报告，在测试中，GLM-5.3-Flash 上的 D-LSA 在最长 10M token 的上下文中保持了与所测基线相近的精度；与该模型的稀疏注意力基线相比，单层注意力预填充和解码分别加速 22.7x 和 4.6x。对于 Qwen-3.8-27B，作者报告在 10M token 时相对完整注意力分别加速 72.4x 和 42.5x。端到端首 token 时间分别提升 2.2x 和 9.2x。这些结果使用作者选定的硬件、基准设置和模型配置。
  • 尚未确立 — 该预印本尚未证明存在独立复现、在其他模型系列或服务负载下取得相近提升、广泛的经济节省，或在 100M token 下实测精度与速度；这一规模的结果是外推值。审查时，论文链接的代码仓库返回 404。
