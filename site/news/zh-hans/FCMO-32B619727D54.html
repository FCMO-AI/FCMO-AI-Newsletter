一篇预印本提出以黑盒审计检测大模型服务未披露的输出词元膨胀

Chen 等人将提供方词元膨胀攻击定义为服务提供方未披露且可控的改动：在基本保留任务效用的同时，增加返回且计费的输出。他们构造了五种攻击路径，并报告输出长度超过干净基线的10.2 倍。其基于饱和效应的探测方法在四个开放权重模型上取得85.1%的宏平均 q-AUC，误报率低于2%。对15个 API 服务进行黑盒审计时，他们标记了其中七个存在与该攻击一致的行为。这些是作者报告的预印本结果：标记并不能证明服务被操纵或提供方有不诚实意图，整体发生率也未知。

真正发生了什么变化

Chen 等人将提供方词元膨胀攻击定义为服务提供方未披露且可控的改动：在基本保留任务效用的同时，增加返回且计费的输出。他们构造了五种攻击路径，并报告输出长度超过干净基线的10.2 倍。其基于饱和效应的探测方法在四个开放权重模型上取得85.1%的宏平均 q-AUC，误报率低于2%。对15个 API 服务进行黑盒审计时，他们标记了其中七个存在与该攻击一致的行为。这些是作者报告的预印本结果：标记并不能证明服务被操纵或提供方有不诚实意图，整体发生率也未知。

主张与证据

  • 声称 — 作者构造了五种提供方词元膨胀攻击，并报告每种攻击都使平均输出长度超过干净基线的10.2x倍，同时基本保留任务准确率；平均准确率下降1.88个百分点。
  • 声称 — 基于饱和效应的单探测审计在四个开放权重模型上取得85.1%的宏平均 q-AUC，误报率低于2%；测试包含三种无害的系统提示设置。
  • 声称 — 作者报告其审计在15个真实 API 服务中标记了7个存在与 PTIA 一致的行为；黑盒结果无法确定服务提供方的意图，也不能证明发生了操纵。
  • 已证实 — 本次检查的 v1 预印本定义了威胁模型并报告了上述实验；本次激活未运行代码或复现结果。

最强基线

论文将审计与 RUT 和历史 KS 控制比较，其中包括需要可信本地模型的基线；对服务的审计没有把提供方的内部行为作为已知真值。

最重要的限制

  • 所有测量结果来自一篇 v1 预印本，本次激活未独立复现。
  • 四个开放权重模型的评估采用了特定设置；对其他模型家族、语言、工作负载和服务更新的迁移情况未知。
  • 15个服务的审计样本较小，不能估计服务总体中的发生率。
  • 被标记为行为符合 PTIA 的服务可能存在其他解释；黑盒行为不能证明提供方意图、欺骗或违反政策。
  • 论文假设所有计费输出词元都会返回给用户且计数准确；审计未检测计费仪表的完整性，也未测试隐藏推理词元的收费。

仍然未知的部分

  • 未检查攻击构造或检测性能的独立复现。
  • 15个服务的样本不能说明不同提供方、模型、地区或时间段的普遍程度和持续性。
  • 仅凭黑盒标记无法区分蓄意膨胀与模型、路由或服务的正常变化，仍需其他证据。

FCMO 视角

如果得到独立复现，一种能够识别超出正常服务变化的输出长度审计方法，可能帮助用户评估按词元计费的不透明 API。15个服务中有7个被标记，值得进一步核查，但不能据此认定提供方有不当行为；这项工作只有一篇预印本，其样本也不能估算普遍程度。
