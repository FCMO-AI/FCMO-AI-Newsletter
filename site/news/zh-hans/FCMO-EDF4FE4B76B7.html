证据

  • 声称 — 作者报告称，他们分析了45次单名开发者在VS Code Copilot代理模式下进行的真实会话，时间范围为23 April至5 October 2026，其中包含102,233条转录记录和20,577次工具执行。原始语料为私有数据，本次审查未查看。
  • 声称 — 使用最终版经审计的规则分类器，作者报告经偏差校正后，23.4%的代码编辑事件在最后一次修改后未记录到独立检查（95%置信区间为17.1–35.7）。这描述的是论文语料及其分类器，不是总体发生率。
  • 声称 — 作者报告称，已标记完成且与编辑相关的待办事项中，有186/322（57.8%）在最后一次代码修改与完成状态之间没有记录到验证。其验证定义还包括运行检查和界面检查，不仅限于正式测试。
  • 声称 — 在同一语料上，作者报告称，不含内容的本地哈希链日志大小约为原始转录的20%，可确定性重放，并能检测篡改测试。本次审查未独立复现其实现或性能。
  • 尚未确立 — 该论文未证明所报比例可推广到其他开发者、代理产品或工作领域；也未证明验证标签意味着结果正确，或显示所提界面能够改变监督决策。私有语料未公开。

最强基线

在论文内部，作者比较了四个连续分类器版本，并报告对每个抽样标签盲审30个事件；无验证比例从v1的42.1%降到v4的25.1%，再经审计校正为23.4%。本次未查看独立团队的基准结果。

局限

  • 语料包含一名开发者使用单一产品（VS Code Copilot代理模式）的45次会话；研究未能确定总体发生率。
  • 验证分类器基于规则。最终精度审计每个标签仅抽样30个事件；报告估计受到分类器版本和验证定义的影响。
  • 作者将验证定义为最后一次修改后运行独立检查；这不能证明代码修改正确。
  • 会话语料为私有数据且未公开；本次审查未独立复现实证结果或原型。

尚不清楚的问题

  • 研究使用单名开发者的VS Code Copilot会话历史。未发现多名开发者参与的独立复现；作者将其定位为试点，而非总体估计。
  • 论文介绍了原型脚本和冻结的汇总结果，但本次审查未运行原型，也未复现日志大小、吞吐量、分类或篡改检测结果。
  • 记录到独立检查并不等同于结果正确；论文也未测量所提界面能否改善监督决策。

为何重要

如果能在不同开发者和代理产品中复现，将检查证据关联到具体工件版本，可能帮助监督者区分代理的完成声明与实际执行过的检查。该研究在一名开发者的工作流中提供了具体测量和原型，但无法据此确定团队层面的普遍程度，也未证明所提系统能改善人工决策。
