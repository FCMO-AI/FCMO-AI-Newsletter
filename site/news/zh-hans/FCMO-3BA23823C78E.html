SPHQuant 报告称，在 NVIDIA GPU 上实现有竞争力的 2–3 位 VLM 精度和比 QTIP 更快的解码

SPHQuant 用方向和半径表示每个 8D 权重向量，将更多量化精度分配给半径以处理离群值，并结合紧凑方向码本与无旋转 CUDA 推理内核。作者报告称，在多个 VLM 上进行 2–3 位量化时，任务精度具有竞争力；在 RTX A6000 上，解码吞吐量比 QTIP 高 30.3%。另一项 RTX 4090 测试使用 Qwen3-VL-8B-Instruct、批量大小 1、256 个预填充 token 和 512 个生成 token，报告吞吐量为 288.63 token/s，比 QTIP 快 37.6%，但 GPU 内存占用为 5.35 GB，高于 QTIP 的 5.02 GB。这些测量来自论文；未进行独立复现，也未评估移动或嵌入式设备。

SPHQuant 用方向和半径表示每个 8D 权重向量，将更多量化精度分配给半径以处理离群值，并结合紧凑方向码本与无旋转 CUDA 推理内核。作者报告称，在多个 VLM 上进行 2–3 位量化时，任务精度具有竞争力；在 RTX A6000 上，解码吞吐量比 QTIP 高 30.3%。另一项 RTX 4090 测试使用 Qwen3-VL-8B-Instruct、批量大小 1、256 个预填充 token 和 512 个生成 token，报告吞吐量为 288.63 token/s，比 QTIP 快 37.6%，但 GPU 内存占用为 5.35 GB，高于 QTIP 的 5.02 GB。这些测量来自论文；未进行独立复现，也未评估移动或嵌入式设备。

证据

  • 声称 — SPHQuant 将每个 8D 权重向量拆分为方向和半径，为半径值分配额外精度以减轻离群值导致的精度损失，并使用无旋转、面向硬件的推理内核。
  • 声称 — 作者报告称，SPHQuant 在 2–3 位 VLM 量化下取得有竞争力的任务精度，在 RTX A6000 上的解码吞吐量比 QTIP 高 30.3%。RTX 4090 测试使用 Qwen3-VL-8B-Instruct、批量 1、256 个预填充 token 和 512 个生成 token，报告为 288.63 token/s，比 QTIP 快 37.6%。
  • 声称 — 论文报告的 RTX 4090 配置中，SPHQuant 使用 5.35 GB GPU 内存，QTIP 使用 5.02 GB；论文没有证明总内存更低或可在移动/嵌入式设备上运行。

最强基线

QTIP 是主要的 2 位基线。RTX 4090 上 SPHQuant 报告吞吐量为 288.63 token/s，比 QTIP 高 37.6%；GPU 内存占用为 5.35 GB，对比 QTIP 的 5.02 GB。

局限

  • 所有基准与性能数据均由作者报告；未进行独立复现。
  • 吞吐量评测覆盖 RTX A6000 和 RTX 4090；作者指出，移动/嵌入式设备表现以及更广泛的批量和上下文设置仍未测试。

  • 论文提出，仍需在真实延迟、输入分辨率和生成长度限制下进行更多任务专项评估。

尚不清楚的问题

  • 精度和吞吐量测量尚未经过独立复现。
  • 速度测试仅覆盖 RTX A6000 和 RTX 4090，没有移动或嵌入式硬件，也未覆盖更广泛的批量大小与上下文配置。
  • RTX 4090 测得 SPHQuant 的 GPU 内存占用高于 QTIP；吞吐量也取决于所测试的实现与配置。

为何重要

二位和三位权重可能减少 VLM 存储和内存流量，使无法容纳更高精度模型的设备受益。SPHQuant 报告将处理离群值的球面量化与面向硬件的内核结合，但速度和精度权衡只在两种 NVIDIA GPU 上测量。RTX 4090 配置下其 GPU 内存使用高于 QTIP；移动和嵌入式设备的收益仍未证实。
