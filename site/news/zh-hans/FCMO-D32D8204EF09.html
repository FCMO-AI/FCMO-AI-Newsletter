OpenAI 在 ChatGPT 全球推出 GPT-6 和模型生成的交互界面

OpenAI 宣布，带 Intelligent UI 的 GPT-6 正在全球 ChatGPT 中推出：付费计划于 十月7日 首先获得，Free 和 Go 于 十月8日 开始推出。公司称 GPT-6 可以用文本、视觉内容和图表、按钮、表单等交互组件组合回答，并逐步呈现这些界面。此次 ChatGPT 更新不改变 Codex 或 ChatGPT Work 使用的模型。OpenAI 十月系统卡报告部分评测表现有所提升，同时在自伤和青少年安全的选定测试中出现显著退步；这些是提供方的评测结果，而非独立评估。

真正发生了什么变化

OpenAI 宣布，带 Intelligent UI 的 GPT-6 正在全球 ChatGPT 中推出：付费计划于 十月7日 首先获得，Free 和 Go 于 十月8日 开始推出。公司称 GPT-6 可以用文本、视觉内容和图表、按钮、表单等交互组件组合回答，并逐步呈现这些界面。此次 ChatGPT 更新不改变 Codex 或 ChatGPT Work 使用的模型。OpenAI 十月系统卡报告部分评测表现有所提升，同时在自伤和青少年安全的选定测试中出现显著退步；这些是提供方的评测结果，而非独立评估。

主张与证据

  • 声称 — OpenAI 表示，带 Intelligent UI 的 GPT-6 于 十月7日 开始在 ChatGPT Plus、Pro、Business 和 Enterprise 计划中全球推出，Free 和 Go 将于 十月8日 开始推出；Enterprise 可用性取决于管理员设置。公告称 Codex 和 ChatGPT Work 仍使用先前发布的版本。
  • 声称 — OpenAI 将 Intelligent UI 描述为一项功能，可让 GPT-6 用文本、视觉内容和交互组件组合回答，包括图表、按钮、表单和面向任务的体验，并在生成过程中逐步呈现界面。
  • 声称 — OpenAI 十月系统卡报告称，与对应 GPT-5.6 版本相比，GPT-6 Sol 在标准自伤评测中显著退步；GPT-6 Luna 在标准自伤、血腥内容和色情内容评测中显著退步。卡片还报告了部分未满 18 岁评测的退步；公司称额外的分类器拦截未计入这些分数。
  • 声称 — 系统卡将 十月版 GPT-6 Sol 和 Luna 在网络安全及生物/化学领域归为 High 能力但低于 Critical，并称其在 AI 自我改进方面低于 High 门槛。这些是 OpenAI 内部的评估和门槛。

最强基线

OpenAI 在内部时延、任务和安全评测中，将 十月 GPT-6 与 GPT-5.6 进行比较。产品公告称 GPT-6 Instant 开始回答网页搜索问题的平均时间比 GPT-5.6 Instant 快 44%；系统卡同时列出部分安全退步和提升。这些是提供方在不断变化的评测中所作的比较，并非独立的匹配结果。

最重要的限制

  • 部署、界面功能、时间比较和安全发现均由 OpenAI 披露；本次未独立测试，也未测量用户采用情况。
  • 系统卡中的高难度类生产评测是刻意挑选的，不代表平均生产行为；大多数底层模型安全结果未纳入系统级防护。
  • 系统卡报告部分自伤、血腥内容、色情内容和未满 18 岁评测出现显著退步，同时其他方面有所改善。卡片称额外的青少年分类器防护未反映在分数中。
  • ChatGPT 中的 十月 GPT-6 模型不同于仍用于 Codex 和 ChatGPT Work 的 九月 GPT-6 Sol/Luna 版本；不要把某一版本的评测或可用性结论转用于另一版本。
  • 公告描述了组件生成和渐进式呈现，但没有提供对界面正确性、可访问性、可靠性或用户比较结果的独立评估。

仍然未知的部分

  • 本次未独立评估生成界面的任务完成情况、正确性、可访问性或用户比较结果。
  • 系统卡中的安全和能力评测由 OpenAI 运行；本次评估未确立其外部有效性或部署后的实际发生率。
  • 公告给出了全球推出时间表，但本次未独立核验覆盖范围、可用性或采用率分母。

FCMO 视角

全球推出、能生成任务专属界面的助手可能改变人们使用软件的方式；系统卡也显示，模型更新可能改善部分安全指标，同时使另一些指标退步。公告说明了 OpenAI 声称已推出的内容和时间表，但没有独立证明界面质量、用户收益、采用情况或现实世界安全发生率。
