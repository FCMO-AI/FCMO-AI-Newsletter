发生了什么变化

Microsoft 十月 19 日的公告介绍了如何通过身份、权限、风险评估和 Guardian Agents 将 Project Perception 应用于企业智能体。后续 Microsoft Learn 文档给出了范围更窄的实现说明：Defender for Endpoint 运行时保护仍处于有限预览阶段，仅面向部分 Windows 与智能体组合提供审计/阻止模式；Entra Agent ID 的可用性与扩展保护所需的付费许可则分别说明。这些是一手产品声明和配置说明，并非效果测量、广泛部署或独立验证的证据。

证据

  • 有公开成果为证 — Microsoft 于 2026 年 十月 19 日发布了 Microsoft Security 执行副总裁 Hayete Gallot 撰写的文章《保护智能体内部人员》。
  • 声称 — Microsoft 表示，此前于 七月公布的 Project Perception 可用于企业智能体：发现智能体、分配身份、容器和权限、评估行动风险，并使用守护智能体实时监督和响应行动。
  • 声称 — Microsoft 表示，Project Perception 已可供组织开始保护内部智能体。
  • 尚未确立 — 公开产品文档提供了配置说明和有限的预览范围，但没有证明控制措施的准确性、经过测试的威胁覆盖范围、延迟、独立评估、部署规模或实际安全结果。
  • 声称 — Microsoft Learn 将 Defender for Endpoint 的 AI 智能体运行时保护描述为面向部分 Windows 与智能体组合的预览功能，并提供审计和阻止模式。支持矩阵区分了智能体发现与运行时保护范围，并指出网络检查不覆盖证书固定流量或 HTTP/3。
  • 声称 — Microsoft Learn 称 Entra Agent ID 已向 Entra 客户提供，而扩展 Entra 安全保护和面向智能体的条件访问则需要符合条件的 Agent 365 许可。

为何重要

如果按所述方式实施，持续进行身份、权限和风险感知的监督可能影响企业安全架构，因为智能体正获得对数据、工具和关键流程的访问权。该公告没有说明这些控制措施在发现或遏制滥用方面的效果、覆盖哪些威胁，或是否已大规模部署。
