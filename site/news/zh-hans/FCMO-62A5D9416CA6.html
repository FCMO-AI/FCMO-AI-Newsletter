论文推出五平台混合式计算机使用代理基准，并报告总体分数与完整行为测试之间存在显著差距

作者推出 RecreationWorld，用于训练和评估能够在 Ubuntu、macOS、Windows、Android 与 Web 上交替浏览运行中的应用界面、编写代码重现应用并执行检查结果的代理。其留出 RecreationBench 含 250 项任务和依据可运行参考实现构建的隐藏测试。作者对十个模型进行评测时，GPT-6 Astra 的总体得分为 58.06%，但只有 2.8% 的任务通过了全部程序化测试；论文报告代理更可靠地复现界面静态结构，而非交互行为和计算结果。这些是新基准中的作者报告结果，并非独立能力对比，也不能代表一般计算机使用能力。

发生了什么变化

作者推出 RecreationWorld，用于训练和评估能够在 Ubuntu、macOS、Windows、Android 与 Web 上交替浏览运行中的应用界面、编写代码重现应用并执行检查结果的代理。其留出 RecreationBench 含 250 项任务和依据可运行参考实现构建的隐藏测试。作者对十个模型进行评测时，GPT-6 Astra 的总体得分为 58.06%，但只有 2.8% 的任务通过了全部程序化测试；论文报告代理更可靠地复现界面静态结构，而非交互行为和计算结果。这些是新基准中的作者报告结果，并非独立能力对比，也不能代表一般计算机使用能力。

证据

  • 声称 — 作者提出一个框架，在 Ubuntu、macOS、Windows、Android 和 Web 的可复现环境中结合图形界面探索、编程以及运行后的视觉验证。
  • 声称 — 在含 250 项任务的 RecreationBench 上，作者报告 GPT-6 Astra 总体得分为 58.06%，高于得分为 44.16% 的 Claude Opus 5；GPT-6 Astra 完整通过全部程序化测试的任务仅占 2.8%。
  • 声称 — 作者报告，在其基准中，代理复现界面静态结构比复现交互行为和计算结果更可靠。

最强基线

报告的比较包括十个前沿系统；GPT-6 Astra 与 Claude Opus 5、GPT-5.6 Sol 按论文的基准配置进行比较。这不是对所有推理栈进行的独立配对评测。

局限

  • 结果由论文作者报告，本次激活未独立复现。
  • RecreationBench 含 250 项参考应用重现任务；其能否代表真实计算机使用工作，以及能否迁移到其他任务形式，尚不明确。
  • 总体分数不等于任务完全正确；2.8% 是论文按其评分协议报告的 GPT-6 Astra 全部程序化测试通过率。
  • 该模型对比基于论文指定的推理配置；它不能确立不同工作负载、提示词、模型或 harness 下的一般排名。
  • 更广泛探索与更高分数之间的关系是描述性的，不能证明探索导致了性能差异。

尚不清楚的问题

  • 尚无独立团队重新运行 RecreationBench 或检验其隐藏测试和分数能否推广到其他计算机使用任务。
  • 目前尚未证明该结果能够推广到基于参考应用重现以外的任务、五个支持平台以外的环境或论文采用的模型与 harness 配置之外。

为何重要

计算机使用代理通常需要把界面探索、代码修改和运行结果验证结合起来。RecreationWorld 提供了一种训练这一闭环并以可执行参考实现评分的方法。作者报告的结果也说明，总体分数可能高估完整行为保真度：领先模型得分为 58.06%，但在该基准中仅有 2.8% 的任务完整通过程序化测试。其能否独立复现以及能否迁移到作者任务集以外仍待验证。
