Zyphra 报告了最高至 256K 上下文的层级稀疏注意力结果

证据

  • 已展示 — 作者于 2026-10-30 发布 arXiv:2610.42112v1，介绍了 Zyphra Hierarchical Attention，即一种采用树状路由的稀疏注意力方法。
  • 声称 — 在 Qwen3.6-35B-A3B 上，作者报告称，推理和智能体编程得分接近密集注意力基线；六层路由器在 RULER-13 上得分为 93.3%，密集注意力为 96.0%，同时只访问原始 KV 缓存的 1%–6%。在 LongBench v2 比较中，作者报告称其比 Minimax Sparse Attention 高 14 分，访问的解码键比例相近（1.1%），而训练 token 数只有对方的十分之一。
  • 尚未确立 — 该预印本尚未证明存在独立复现、经过优化的 GPU kernel 延迟，或超过 256K token 的实测性能；数百万至数十亿 token 的速度估计来自 roofline 性能模型外推，作者也说明这些长度下的评测质量尚未验证。

论文报告了相对于密集注意力和同一 Qwen3.6 主干上的 Minimax Sparse Attention 的比较；MSA 索引器用 40B token 训练。尚未建立对其他模型系列或生产服务的比较。

局限

  • 所有评测结果均由作者报告；本次未进行独立复现。
