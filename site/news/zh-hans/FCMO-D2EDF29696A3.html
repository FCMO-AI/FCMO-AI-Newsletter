自适应攻击者搜索使提示注入成功率随计算预算上升：两个合成智能体测试套件的结果

一篇九月3日发布的预印本将间接提示注入建模为攻击者搜索问题，并评估了一个具备环境侦察、显式策略与历史状态以及受害智能体反馈探测能力的 GLM-5.2 攻击者。在合成的 Workspace 和 Retail 测试套件中，作者报告称，攻击成功率会随攻击者推理 token 预算增加：在 Workspace 中，GPT-5.5 于100,000个攻击者 token 时的 ASR 达到52.1%；在 Retail 中，Claude Opus 4.8 于500,000个 token 时达到20.6%。移除搜索工具后，约100,000个 token 之后的增益趋于停滞；移除策略工具后，侦察与攻击模式会重复。该研究采用白盒设定、合成任务和一个攻击者对两个受害模型；它未证明向黑盒环境迁移，也没有独立复现。
