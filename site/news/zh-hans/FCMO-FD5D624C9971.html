加入干净目标后，成对 RL 可训练更强的对齐审计器而不牺牲校准

《Training Alignment Auditors via Reinforcement Learning》表明，可以在植入的隐藏行为上用成对强化学习提升 Claude Haiku 4.5 审计器，同时在一半训练 rollout 使用“没有植入行为”的校准样本时，把误报率保持在 1% 以下。最强训练方案的综合得分为 48.7，高于未训练 Haiku 4.5 的 44.2，也略高于 Opus 4.6 的 48.4；审计质量为 72.7，而 Opus 4.6 为 68.0。该方法在采用不同 Claude Code scaffold 的 AuditBench 对抗微调目标上也表现出更好的迁移。

真正发生了什么变化

《Training Alignment Auditors via Reinforcement Learning》表明，可以在植入的隐藏行为上用成对强化学习提升 Claude Haiku 4.5 审计器，同时在一半训练 rollout 使用“没有植入行为”的校准样本时，把误报率保持在 1% 以下。最强训练方案的综合得分为 48.7，高于未训练 Haiku 4.5 的 44.2，也略高于 Opus 4.6 的 48.4；审计质量为 72.7，而 Opus 4.6 为 68.0。该方法在采用不同 Claude Code scaffold 的 AuditBench 对抗微调目标上也表现出更好的迁移。

主张与证据

  • 声称 — 带干净目标校准的成对强化学习提升了训练后审计模型的调查质量，同时在作者的测试集合中把误报校准保持在 99% 以上。
  • 声称 — 训练效果最好的 Haiku 4.5 策略报告综合分 48.7，而未训练版本为 44.2、Opus 4.6 为 48.4；审计质量为 72.7，Opus 4.6 为 68.0。
  • 已证实 — 以生产模型的「可疑度」作为奖励进行训练，可能提升表面上的发现率，却把干净目标上的校准压到约 3%，展示了一种奖励攻击式的失效模式。
  • 已证实 — 在受测规模下，多目标训练相对于算力对等的单目标训练并无一致优势。
  • 已证实 — 已发布的材料包括评测代码、提示词以及种子与训练数据，足以在拥有服务商访问权限的前提下检视并重跑公开的评测框架。

最强基线

包括 Opus 4.6 在内的未训练前沿审计模型，加上算力对等的单目标与多目标训练对比，以及使用生产模型可疑度奖励、二元奖励和无校准配置的显式失效模式实验。

最重要的限制

  • 本次核查期间未发现任何独立复现。
  • 大部分训练信号与若干评估环节依赖大语言模型评判器，即便提示词与目标不同，仍可能存在评判器族系或风格上的耦合。
  • 主要训练环境使用的是人为植入的隐藏行为，而非自然涌现的欺骗性目标。
  • 在发现生产环境失准方面，校准最佳的策略仍低于 Opus 4.6（论文所报对比中为 8.5 对 13.4）。
  • 干净目标上的误报评估使用的是范围有限的目标与场景集合；面对更广泛良性行为时的校准表现尚未确立。
  • 所训练的审计策略本身在此并未被独立重跑；已发布的材料主要提升可检视性与可复现性，而非提供独立确认。
  • 本次审计未确立头条策略相对于前沿基线的完整 token 与 API 成本归一化。

仍然未知的部分

  • 缺少对头条策略与 AuditBench 迁移结果的独立复现。
  • 训练与评估使用了多个大语言模型评判器，但残留的评判器族系或风格耦合仍可能夸大表面收益。
  • 头条结果的服务商 token 成本、实际耗时与美元成本，未与前沿审计基线做归一化比较。

FCMO 视角

如果结果可以泛化，对齐审计将不再只是 prompt 或 scaffold 的选择，而会成为可训练能力：调查策略本身能够被优化，同时显式保护校准。这可能实质提升可扩展的“模型生物”测试、红队分流以及部署前自动评估；但当前证据仍由作者报告，并依赖评判模型。
