证据

  • 声称 — 论文将 Loopjacking 定义为：产品逻辑把人员理解为对操作 A 的批准用于授权或释放实质不同的操作 B，并区分审批前展示不完整与审批后状态替换两种情形。
  • 声称 — 作者报告在抽样的 七个 Agno AgentOS 版本（2.5.6、2.9.0、3.0.1、3.0.2、3.0.3、3.0.6、3.0.9）以及 12 个抽样的 LangGraph Agent Server 版本（0.7.5 至 0.14.0）中复现了审批后替换；后者使用指定的内存组合和自定义授权策略。
  • 声称 — 作者报告称，OpenClaw 2026.2.23 释放了一个命令向量，其审批界面遗漏了实质不同的参数，而 2026.2.24 拒绝了所测不匹配；OpenAI Agents SDK 0.22.0 和 0.22.2 阴性对照拒绝了相同调用标识下的变更，并执行未改动的已批准调用。
  • 声称 — 在所测轨迹中，使用时精确比对，或拒绝未授权的待审批状态更新，可以阻止被替换的操作，同时保留对未变更已批准操作的执行。

最强基线

未变更的已批准 A 执行；未经批准直接执行 B 时被拒绝；主体与会话边界控制；OpenAI Agents SDK 阴性对照；OpenClaw 2026.2.24 的修复行为；以及研究用精确操作比对或拒绝更新策略。
