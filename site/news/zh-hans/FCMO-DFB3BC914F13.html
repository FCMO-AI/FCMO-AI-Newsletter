反馈编码在有限的大语言模型测试中实现了更可靠的黑箱隐蔽消息传递

论文提出 Burnashev Adaptive Posterior Matching（BAM），通过利用文本反馈、后验匹配和确认阶段，把消息嵌入生成文本；接收方无需获得模型权重或提示词。在 C4 RealNews 上，作者报告称，三种开放模型对8位载荷的消息错误率约为0–0.1%，平均约需46–50个词元，实验共1,000次；对照中最强的黑箱基线 ArcMark 在50个词元时约为10.5–16.8%。在另一组对话实验中，错误率因模型和任务而异：Llama-3.1 和 Phi-4 的消息错误率低于3%，而 Qwen3-A3B-30B 的对话错误率为19–22%。这些结果来自一篇预印本；尚未找到独立复现。该实现存在计算成本，而且论文的安全模型不涵盖对话文本被修改的情况。

证据

  • 声称 — 在 C4 RealNews 的三种开放模型上，作者报告 BAM 对8位载荷的实测消息错误率约为0–0.1%，平均使用46–50个词元，共进行1,000次试验；所列最强黑箱方法 ArcMark 在50个词元时约为10.5–16.8%。
  • 声称 — 在作者进行的对话实验中，每种条件包含100段对话，错误率因模型和载荷而异：Llama-3.1 和 Phi-4 在三项任务中的消息错误率低于3%，而 Qwen3-A3B-30B 的对话错误率为19–22%。
  • 已证实的局限 — 论文的安全分析采用特定的共享密钥和 API 威胁模型，不包括编辑、删除或改写对话文本的对手；作者没有声称该大语言模型通道达到经典渐近最优。

最强基线

局限

  • 所有性能结果均来自一篇预印本；本次审查没有独立复现。
  • 8位载荷的结果来自 C4 RealNews、作者进行的1,000次试验以及三种指定开放模型；这不能证明专有模型或实际部署对话也有相同性能。
  • 对话测试每个条件包含100段对话，结果随模型和任务有明显差异；Qwen3-A3B-30B 的对话错误率为19–22%。
  • 安全分析依赖特定的共享密钥和 API 威胁模型；文本被编辑、删除或改写的情况不在范围内。
  • 消息越长，解码成本呈指数增长；论文关于24位载荷的扩展性附录将其列为实际限制。

  • 分析不包括文本修改，也没有证明系统能在改写、截断或平台转换后检测或恢复消息。

为何重要

如果反馈编码能在所测试的黑箱场景中大幅降低解码错误，就可能改变研究人员评估模型生成对话中隐蔽通信的方式。论文也显示结果受模型熵、任务和文本完整性影响，因此更适合推动针对特定威胁模型的测试，不能据此笼统断言已部署的代理都能可靠传递隐蔽消息。
