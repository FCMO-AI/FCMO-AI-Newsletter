Anthropic 报告科学家使用 Claude 的任务分布

Anthropic 于2026年十一月5日发布报告，分析了八月2日至九月30日期间被归类为科研工作的207,049次 Claude 与 Claude Code 消费者套餐会话。报告称，数据分析和写作较常见，而数据收集和构想生成所占比例低于其估算的研究时间占比。基于语言模型的任务能力指标与更高使用量相关：得分最高的五分之一任务获得的使用量约为按研究人员时间预期值的两至四倍。另一项针对528名人工智能活跃使用者的科学家调查，大体呈现相似的任务分布。这些是基于分类器的第一方使用测量，原始对话无法供独立审查。报告没有测量研究质量、因果生产率或实际科学发现，关于未来产出的情景也只是模型假设。这项528人调查招募对象来自 Anthropic 在美国和加拿大的资助项目申请者，他们可能比典型科学家更频繁地使用人工智能；任务能力评分由语言模型推导，因此评分与产品使用量的关系并非对能力的独立验证。附录使用5,000条合成会话记录评估领域和任务分类器：任务分类准确率为69%，任务与子领域组合的准确率为58%；排除仍保留标签相关措辞的约一半记录后，准确率分别降至64%和54%。高置信度及高 Claude 贡献子样本中的总体模式仍然稳定，但附录指出真实会话缺少用于评估分类准确度的基准标签；这些检验并不能确立真实会话的分类准确度。

证据

  • 已展示 — Anthropic 于2026年十一月5日发布报告，称其分析了从2日（八月）至30日（九月）2026年期间被归类为科研工作的207,049次消费者套餐会话。
  • 声称 — Anthropic 报告称，数据分析占 Claude 科研会话的33.7%、占 Claude Code 科研会话的48.1%，而研究人员估计用于该类任务的时间为27.6%。数据收集分别占会话的11.5%和11.9%，而研究时间估计占28.6%；构想与假设生成分别占4.2%和2.1%，而研究时间估计占7.1%。
  • 声称 — Anthropic 报告称，按其语言模型推导的任务能力指标衡量，任务相对研究时间的使用比例随能力得分上升：得分最高的五分之一任务在 Claude 中的使用量约为预期的两倍，在 Claude Code 中约为四倍。报告还介绍了一项针对528名科学家的调查；受访者自述的人工智能使用情况总体上与观察到的任务分布相符。
  • 尚未确立 — 报告提出的情景——广泛采用现有能力可能使某些领域的产出翻倍，或完全自动化所有非体力研究工作可能使某些领域的产出提高至15倍——属于模型假设，并非报告证实的实际效果。
  • 尚未确立 — 报告并未证明 Claude 或 Claude Science 使研究质量提高、科研产出增加或发现数量上升。
  • 声称 — 附录报告，在5,000条合成会话记录中，任务分类准确率为69%，任务与子领域组合分类准确率为58%。排除仍保留标签相关措辞的约一半记录后，准确率降至64%和54%。附录还称，在选出的高置信度和高 Claude 贡献子样本中总体模式保持稳定，但真实会话没有可用于分类的基准标签。

最强基线

报告将不同任务的使用占比与 SciNet 估算的研究人员时间进行比较；528名人工智能活跃使用科学家的调查提供了另一项自述数据对照。

局限

  • 所有使用数据均由 Anthropic 根据自有消费者套餐会话和专有分类器报告；本次未检查原始对话，也未独立审计分类结果。
  • 调查包含528名科学家，且主要是已经使用人工智能的生命科学与健康科学研究人员；样本不代表所有科学家。
  • 任务理论能力评分与使用情况的相关性不能证明前者导致后者，也不能证明使用人工智能改善了科研结果。
  • 科研产出加速估算属于情景分析，不是实测生产率效果。
  • 这项528人调查招募对象来自 Anthropic“人工智能与科学”及相关资助项目的申请者，覆盖美国和加拿大；Anthropic 指出，他们可能比典型科学家更频繁地使用人工智能。
  • 任务能力评分由语言模型对任务步骤进行成对判断，再通过 Bradley–Terry 模型汇总得出；它是语言模型推导的理论指标，其与使用量的相关性本身不能独立验证任务能力。
  • Claude Science 中的任务差异可能部分来自用户选择：有专业或高难度需求的人更可能使用该工具。Anthropic 明确将其描述为使用模式。
  • 附录使用5,000条合成会话记录评估领域和任务分类器，而不是用带有独立基准标签的真实会话：任务分类准确率为69%，任务与子领域组合为58%；排除仍保留标签相关措辞的记录后，准确率分别为64%和54%。选出的高置信度和高 Claude 贡献子样本中的总体模式仍然稳定，但这并不能确立真实会话中的分类准确度；每次会话只被分配一个任务。

尚不清楚的问题

  • 207,049次会话的分类、任务能力标签和研究时间估算均未经过独立审计；原始对话不公开。附录报告，合成会话记录中的任务分类准确率为69%，任务与子领域组合为58%；排除仍带有标签相关措辞的记录后，准确率分别降至64%和54%。稳健性子样本保留了总体模式，但没有提供真实会话的基准标签分类评估。配套的528人调查招募对象来自 Anthropic 在美国和加拿大的相关项目申请者，可能过度代表人工智能高频用户。
  • 报告测量了使用模式并建立情景模型，但没有测量研究质量、耗时或产出是否发生因果变化。
  • 配套调查招募对象来自 Anthropic“人工智能与科学”及美国、加拿大相关资助项目的申请者，他们可能是人工智能高频用户；不同工具之间的比较也可能受到用户自我选择的影响。

为何重要

大规模使用行为数据可帮助研究人工智能在科学领域的采用方式及其瓶颈。报告显示，当前使用集中在其能力指标得分较高的任务，而数据收集与假设构想所占比例较低。这些证据描述的是报告中的使用模式，并未证明科研生产率有所提高，也不能推导出普遍的科研加速率。
