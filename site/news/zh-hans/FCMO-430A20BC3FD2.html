OpenAI 将 GPT-6 Astra 权重以 GPT-Rosalind-6 形式用于受控访问的生命科学研究

OpenAI 十月30日发布的系统卡补充文件称，GPT-Rosalind-6 使用 GPT-6 Astra 的权重，本次发布没有增加训练数据或额外后训练。OpenAI 的发布说明和访问指南称，GPT-6 Rosalind Research 正逐步向少数获批 Research 机构开放，可在 Work 和 Codex 中使用，也可通过单独获批的 API 访问；Chat 标签页不可用。Enterprise 工作区先进入为期两周的管理员预览，且默认关闭访问。在测试的最高推理预算下，OpenAI 报告称 GPT-Rosalind-6 在三组共享基准中的得分高于 GPT-Rosalind-5.5：MedChemBench v7 为49.6% 对28.9%（99道题）；GeneBench Pro v13 单次成功率为37.7% 对16.7%（129道题）；LifeSciBench Gold 为61.3% 对44.0%（100道题中保留94道，另有六道因可能的问题而排除）。OpenAI 根据其选定的准备度评测，将生物能力归为高于高能力门槛、低于关键能力门槛。上述均为第一方结果；GeneBench 配置与生产环境不同，关键能力门槛仍属初步设定，尚无独立复现或现实生产力、安全结果的证据。

证据

  • 已展示 — OpenAI 十月30日发布的系统卡补充文件称，GPT-Rosalind-6 与 GPT-6 Astra 使用相同权重，本次发布未增加训练数据或额外后训练。
  • 声称 — 在测试的最高推理预算下，OpenAI 报告称 GPT-Rosalind-6 在三组共享基准中得分高于 GPT-Rosalind-5.5：MedChemBench v7 为49.6% 对28.9%（99道题）；GeneBench Pro v13 单次成功率为37.7% 对16.7%（129道题）；LifeSciBench Gold 为61.3% 对44.0%（100道题中保留94道，另有六道因可能的任务或环境问题而排除）。这些均为第一方对比；GeneBench 的配置不同于生产环境。

  • 已展示 — OpenAI 的系统卡介绍了可信访问，以及对任务、用途、治理和访问控制能力的审核。其十月30日发布说明和配置指南称，GPT-6 Rosalind Research 正向少数获批 Research 机构开放，可在 Work 和 Codex 中使用，也可通过单独获批的 API 访问，但不能在 Chat 中使用；Enterprise 工作区先进入为期两周的管理员预览，且默认关闭。获批的企业用户必须采用最小权限控制，并在模型输出用于实验、发表或重大决策前安排合格人员审核。
  • 尚未确立 — 系统卡未能证明存在独立复现、前瞻性的现实实验室生产力、全面的生物风险评估，或在所有部署情境中的安全性。

最强基线

OpenAI 在三项能力评测中使用相同基准版本和题集比较两个模型。这些是第一方对比，采用测试中的最高推理预算；GeneBench 配置不同于生产环境，LifeSciBench 排除了六道可能存在问题的题目。

局限

  • 所有生物能力与保障措施的描述均由 OpenAI 撰写；该系统卡是 OpenAI 所做评估和部署情况的一手证据，但不能独立确认分数或保障措施的有效性。
  • 系统卡称，四项关键能力评测是基于专家判断的初步代理指标，随着评测完善，其门槛可能变化。
  • 系统卡称四项关键能力评测均未达到指示性门槛；这不能证明不存在生物风险。
  • 本次激活没有运行这些基准、查阅保密评测材料，也没有测量实验室生产力或现实中的滥用结果。
  • 三项有益能力基准对比均为 OpenAI 在测试的最高推理预算下报告的结果，并非独立或前瞻性的工作流结果。GeneBench 的配置不同于生产环境；LifeSciBench Gold 有六道题因可能存在任务或环境问题而被排除。

尚不清楚的问题

  • 生物能力评分和门槛来自第一方评测；本次激活未独立复现相关基准，也未审计完整评分方案。
  • 已发布基准的能力分类没有衡量前瞻性科研生产力，也没有衡量真实用户工作流中的部署安全。

为何重要

系统卡描述了通用前沿模型在经过筛选的访问机制下用于更多具有双重用途的生命科学研究，并提供了与 GPT-Rosalind-5.5 的公司自报对比结果。这些分数差异可能影响科研系统选择，但它们来自选定基准和测试中的最高推理预算，并非独立或前瞻性的实验室结果。相同权重的说明也表明，这次发布改变的是部署与评估方式，而非重新训练模型。
