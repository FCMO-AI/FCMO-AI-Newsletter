SwarmEvolve 报告称潜在智能体群组可加快程序搜索

Qile Jiang 与 George Em Karniadakis 提出 SwarmEvolve。该方法每轮运行 10 个 Qwen3 智能体群组，每组 45 个智能体进行 40 步潜在空间推理，经筛选后将 KV 缓存交给解码摘要器以生成程序。在 21 项由评估器驱动的数学和科学计算任务中，作者报告称，与 OpenEvolve、ShinkaEvolve 和 CodeEvolve 相比，SwarmEvolve 在 Qwen3 8B、14B 和 32B-FP8 下均获得最高平均分；每项结果使用 三个随机种子，每种模型配置使用 一块 GPU 和 八个 CPU 核心。作者还报告称，在 三项任务上，Qwen3 8B 的结果优于 AlphaEvolve 的构造。这些仍是论文作者报告的结果，本次未独立复现。实验范围限于选定任务和算力配置。论文所链接的 GitHub 仓库现已可访问，其中包含基准任务、评估器、基线副本和分析材料；但 README 表示 SwarmEvolve 核心代码即将发布，因此目前仍无法独立运行该方法。
