前沿语言模型对小分子构象的排序优于 UFF，但低于 MMFF94

Semakin 等人评估语言模型能否根据 3D 坐标和相对能量标签对分子构象排序。基准测试涵盖 27 个小分子的 810 个几何构型。表 1 报告，GPT-6 Astra 的可靠构象对平均 Kendall τ 为 0.67，Claude Opus 5 为 0.61，高于 UFF（0.23），但低于 MMFF94（0.93）和 GFN-FF（0.72）。这是作者在预印本中开展的有限基准测试，并不能证明语言模型可以取代分子力学或泛化到整个化学空间。

真正发生了什么变化

Semakin 等人评估语言模型能否根据 3D 坐标和相对能量标签对分子构象排序。基准测试涵盖 27 个小分子的 810 个几何构型。表 1 报告，GPT-6 Astra 的可靠构象对平均 Kendall τ 为 0.67，Claude Opus 5 为 0.61，高于 UFF（0.23），但低于 MMFF94（0.93）和 GFN-FF（0.72）。这是作者在预印本中开展的有限基准测试，并不能证明语言模型可以取代分子力学或泛化到整个化学空间。

主张与证据

  • 声称 — 作者使用 27 个小型有机分子的 810 个构象几何，评估前沿语言模型；相对能量标签来自 DFT 计算，并采用三种打乱后的提示顺序。评分集保留能量差至少为 2 kcal/mol 的可靠构象对。
  • 声称 — 表 1 中，可靠构象对的平均 Kendall τ 为：GPT-6 Astra 0.67、Claude Opus 5 0.61，高于 UFF 的 0.23，但低于 MMFF94 的 0.93；GFN-FF 为 0.72。这些是作者在所述基准测试中报告的结果。
  • 声称 — 作者报告，模型在具有明确氢键相互作用的结构上表现较好，在许多由环张力和扭转主导的案例上仍有困难；该结果不能证明模型具备通用的 3D 物理理解能力，也不能证明其对实验分子设计有用。
  • 已证实 — 作者公开提供基准数据、原始输入、预计算响应以及绘图和复现代码；重新调用模型需要文档所述依赖项和相关模型 API 的访问权限。

最强基线

论文报告了 API 实验成本及其与分数的相关性，但本次审查未审计账单或重新计算成本。跨模型比较属于描述性分析，模型家族的观测并不独立。

最重要的限制

  • 这是作者开展的预印本基准测试；本次审查未找到或执行独立复现。
  • 样本仅含 27 个分子，多数为小型 QM9 结构，任务也仅限构象排序；尚未测量其在更广泛化学空间中的泛化能力。
  • 报告仅使用三种提示顺序和每个模型每个分子一次响应；不同供应商的 API 采样设置并不相同。
  • Kendall τ 排序一致性并非能量误差指标，也不能证明其对分子设计或实验有用。
  • 模型表现与发布日期、API 成本之间的相关性仅具描述性；模型家族及基准观测并非独立样本。

仍然未知的部分

  • 本次未找到或执行对所报告构象排序结果的独立复现。
  • 基准测试仅包含 27 个分子，且大多较小，尚未证明可迁移到更大或化学多样性更高的结构。
  • 每个模型与分子仅使用一次响应，且 API 和模型的采样设置各异，因此不确定性估计和严格的跨模型比较受到限制。
  • 排序任务不能证明能量准确、结构经实验验证或分子设计具有实际效用。

FCMO 视角

语言模型根据坐标对部分小分子构象排序的能力，可能为混合式 AI 化学工作流提供参考。该比较也界定了能力范围：在此基准测试中，表现最好的受测模型仍低于成熟的力场基线，而 27 个分子的测试范围无法检验广泛的化学泛化能力。
