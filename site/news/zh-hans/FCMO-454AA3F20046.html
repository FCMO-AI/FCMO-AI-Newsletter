ProgramDistill 报告称，随着 Web 应用恢复深度增加，参考引导基准中的编程智能体成功率会下降

arXiv v1 论文提出 ProgramDistill，这是一个基于 26 个交互式 Web 应用构建的基准。其自动化流水线报告生成了 1,975 个经回放验证的行为和 4,063 项修复任务。在九种智能体的部分应用重建评估中，随着恢复深度从 1 增至 8，两种表现较强的智能体成功率下降：GPT-6 Astra 从 100% 降至 64.0%，Claude Opus 5 从 96% 降至 32%。作者报告称，提示词长度相近时这种下降仍然存在。以上是论文报告的基准结果；本次未独立复现，作者仍在准备公开发布基准。

真正发生了什么变化

arXiv v1 论文提出 ProgramDistill，这是一个基于 26 个交互式 Web 应用构建的基准。其自动化流水线报告生成了 1,975 个经回放验证的行为和 4,063 项修复任务。在九种智能体的部分应用重建评估中，随着恢复深度从 1 增至 8，两种表现较强的智能体成功率下降：GPT-6 Astra 从 100% 降至 64.0%，Claude Opus 5 从 96% 降至 32%。作者报告称，提示词长度相近时这种下降仍然存在。以上是论文报告的基准结果；本次未独立复现，作者仍在准备公开发布基准。

主张与证据

  • 声称 — 作者提出 ProgramDistill：从交互式参考应用中挖掘行为、屏蔽其实现，并衡量智能体能否恢复这些行为，由此构造可复现的软件工程任务。
  • 声称 — 作者报告称，mine–craft–patch 在 26 个 Web 应用中生成了 1,975 个经回放验证的行为和 4,063 项任务；他们表示公开发布该基准仍在准备中。
  • 声称 — 在部分应用重建中，论文报告 GPT-6 Astra 的成功率随恢复深度从 1 增至 8 而由 100% 降至 64.0%，Claude Opus 5 则由 96% 降至 32%。作者报告称，在提示词长度相近的运行中也观察到这一下降。
  • 声称 — 在完整应用重建中，作者报告在 12 个应用的评估里，GPT-6 Astra、Claude Opus 5 和 GPT-5.6 Sol 的累积工作流平均恢复率分别为 49.15%、28.81% 和 21.07%。
  • NOT_ESTABLISHED — 预印本没有证明结果可被独立复现，也未证明结果能迁移到其他应用类别、生产编程任务或不同智能体 harness。

最强基线

在基准任务中，智能体使用相同的回放验证行为，以及相同的参考应用和当前应用设置进行比较。本次未检查独立基准或其他 harness 的匹配复现。

最重要的限制

  • 这是一篇 arXiv v1 预印本；本次未进行独立复现。
  • 语料包含 26 个 Web 应用，其中有源自 OSWorld 的应用以及开源项目或 SaaS 克隆；它并不代表全部软件工程任务。
  • 基准构建流水线使用 GPT-5.6 Sol；构建模型的选择可能影响任务分布。
  • 论文报告了九种选定的智能体配置；工具、观察预算或模型版本变化可能改变结果。
  • 作者表示公开发布基准仍在准备中。
  • 指标是通过回放验证的行为恢复，不直接衡量代码质量、可维护性、用户价值或生产安全性。

仍然未知的部分

  • 本次没有独立复现基准构建过程或模型评估。
  • 语料包含 26 个 Web 应用和选定的 harness；对其他软件领域及生产工作流的迁移情况未知。
  • 论文比较了部分前沿编程智能体，但尚未证明恢复深度效应不受 harness 选择或观察预算影响。

FCMO 视角

该基准测试了 issue 类任务通常未涵盖的编程需求：从可运行应用中推断行为，并在不完整实现中恢复这些行为。如果其回放验证和深度控制可以泛化，它有助于区分智能体的信息搜集能力和多步修复能力。现有证据仅限于论文中的 Web 应用和实验 harness。
