MeshKV 报告 FPGA 解码器片上流量下降、多流吞吐量提升

一篇获 IEEE ICCD 2026 接收的论文提出 MeshKV，这是一种在平铺式加速器间传输 Transformer KV 缓存块的片上网络。在 8×8 Alveo U280 FPGA 实现上，使用 LLaMA-2-7B 和 Mistral-7B、8K–32K 上下文时，作者报告片上互连流量最高降低 58%，相较共享基线 KV 带宽利用率提高 2.1×，在 32K 上下文和八路并发流下，相较集中式基线吞吐量达到 1.9×。论文报告了五次硬件测量及消融实验；每 token 能耗降低 17% 是基于活动量的估算，并非整机功耗的直接测量。独立复现以及向商用加速器的迁移仍待验证。

发生了什么变化

一篇获 IEEE ICCD 2026 接收的论文提出 MeshKV，这是一种在平铺式加速器间传输 Transformer KV 缓存块的片上网络。在 8×8 Alveo U280 FPGA 实现上，使用 LLaMA-2-7B 和 Mistral-7B、8K–32K 上下文时，作者报告片上互连流量最高降低 58%，相较共享基线 KV 带宽利用率提高 2.1×，在 32K 上下文和八路并发流下，相较集中式基线吞吐量达到 1.9×。论文报告了五次硬件测量及消融实验；每 token 能耗降低 17% 是基于活动量的估算，并非整机功耗的直接测量。独立复现以及向商用加速器的迁移仍待验证。

证据

  • 声称 — 在 8×8 FPGA 上使用 LLaMA-2-7B 和 Mistral-7B、8K–32K 上下文时，作者报告互连流量最高降低 58%，KV 带宽利用率较 Shared 提高 2.1×，多流吞吐量最高提高到 1.9×。
  • 声称 — 在 LLaMA-2-7B、32K 上下文和八路并发流下，论文报告解码吞吐量是集中式路由的 1.90×；五次硬件测量的吞吐量置信区间低于 3%。
  • 声称 — 在 32K 上下文时，论文根据活动量估算每 token 净能耗降低 17%；链路能耗降低 48%，而 SRAM 能耗增加 7%。这不是整机功耗的直接测量。
  • 尚未确立 — 论文评测一种 FPGA 实现、两款 7B 模型和匹配的实现/模拟配置；并未证明其在商用 GPU/ASIC 服务系统或独立工作负载部署中的性能。

最强基线

同一 FPGA 上的集中式 (Cent) 和分布式 round-robin (Shared) 配置；最近的架构消融是未启用完整多播/流水线的 TaKV-only。

局限

  • 所有结果均由作者报告；本次审查没有复现该设计。
  • 测量实现使用一台 Alveo U280 FPGA 平台及 LLaMA-2-7B/Mistral-7B；吞吐量和延迟不能据此推断到 GPU 或 ASIC 服务系统。
  • 每 token 净能耗下降是基于活动量的估算；链路能耗下降而 SRAM 能耗上升。
  • 测量数据通路实现的是注意力/KV 传输，并非完整的生产解码器栈。
  • 对比对象是同一平台上的集中式/共享基线，不能直接与无关加速器论文比较。

尚不清楚的问题

  • 本次未审查 RTL、可执行评测工具或独立工件审计；论文报告了 Alveo U280 FPGA 实现和五次测量。
  • 每 token 能耗降低 17% 是活动量估算，而非整机能耗直接测量；向 GPU/ASIC 生产服务的迁移情况未知。

为何重要

即使算力和内存容量充足，长上下文解码吞吐量仍可能受限于 KV 状态在片上网络中的传输。MeshKV 的 FPGA 匹配测量表明，缓存放置、多播和流水重叠可能共同改善并发能力。结果仅对应一种 FPGA 设计和两款较小模型；直接能耗测量以及向商用服务的迁移尚未验证。
