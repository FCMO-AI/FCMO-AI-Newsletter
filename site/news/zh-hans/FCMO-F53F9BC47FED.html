OpenAI 的 V7 客户案例介绍了面向长期运行智能体、关联来源的 Context Graph

在一篇日期为2026年九月21日的客户案例中，OpenAI 将 V7 Go 的 Context Graph 描述为一种持久存储：从企业文件中提取实体、关系和事实，并保留来源链接；查询图谱时，如果上下文不足，则回退到文档搜索。OpenAI 报告称，V7 的纯检索系统比 HERB 官方基线高 69%，并将无法回答查询中的幻觉减少 38%；V7 还报告称，使用 GPT-5.6 Luna 时每份文档成本比 GPT-5.4 mini 低 78%，而在其最难的图查询集合上，GPT-6 Astra 的准确率为 89%，GPT-5.6 Sol 为 78%。HERB 论文确认了企业数据基准的背景和 39,190 个材料组成的语料池，但没有找到 V7 的运行配置、绝对分数或独立复现。这些是公司发布的客户案例结果，并非知识图谱普遍收益的实证证明。

真正发生了什么变化

在一篇日期为2026年九月21日的客户案例中，OpenAI 将 V7 Go 的 Context Graph 描述为一种持久存储：从企业文件中提取实体、关系和事实，并保留来源链接；查询图谱时，如果上下文不足，则回退到文档搜索。OpenAI 报告称，V7 的纯检索系统比 HERB 官方基线高 69%，并将无法回答查询中的幻觉减少 38%；V7 还报告称，使用 GPT-5.6 Luna 时每份文档成本比 GPT-5.4 mini 低 78%，而在其最难的图查询集合上，GPT-6 Astra 的准确率为 89%，GPT-5.6 Sol 为 78%。HERB 论文确认了企业数据基准的背景和 39,190 个材料组成的语料池，但没有找到 V7 的运行配置、绝对分数或独立复现。这些是公司发布的客户案例结果，并非知识图谱普遍收益的实证证明。

主张与证据

  • 声称 — OpenAI 将 V7 Go 的 Context Graph 描述为从企业文档中提取实体、关系和事实、保留证据来源引用并处理图查询的系统；上下文不足时可回退到文档搜索。
  • 声称 — OpenAI 报告称，V7 的纯检索系统比 HERB 官方基线高 69%，并将无法回答查询中的幻觉减少 38%；所检查的案例未提供 V7 专属运行配置或绝对分数。
  • 声称 — V7 报告称，使用 GPT-5.6 Luna 时每份文档成本比 GPT-5.4 mini 低 78%；在 V7 最难的图查询等级中，GPT-6 Astra 准确率为 89%，GPT-5.6 Sol 为 78%。
  • NOT_ESTABLISHED — 这些报告结果并不能证明图谱记忆普遍提升不同供应商、数据集或客户部署中的智能体准确率、成本或工作流表现。

最强基线

对于 HERB，OpenAI 称 V7 将纯检索系统与该基准的官方基线比较，但文章没有指出基线的确切实现，也没有给出 V7 绝对结果。单文档成本的比较模型是 GPT-5.4 mini；超难图查询集合的比较系统是 GPT-5.6 Sol。这些不是针对全部报告结果的一项统一匹配评估。

最重要的限制

  • OpenAI 文章中所有 V7 结果数字均为客户案例声明；未找到独立复现或客户侧审计。
  • 文章未提供 V7 的 HERB 绝对分数、测试划分、查询数量、检索配置、基线版本、不确定性估计或运行日志。
  • 成本对比为每份文档低 78%，比较对象是 GPT-5.4 mini；文章未说明 token 数、延迟、质量目标、批处理、缓存或工作流条件，因此无法据此推广到每个成功任务的成本。
  • GPT-6 Astra 的图查询结果使用 V7 私有测试集；文章未给出问题数量、难度校准、评分标准或多次运行的方差。
  • HERB 已发表的基准采用合成企业数据；其结果本身不能证明真实客户部署中的质量、隐私表现或经济影响。
  • 系统说明和产品页面均由供应商撰写，未在匹配协议下将来源关联图谱与其他持久记忆或检索架构进行比较。

仍然未知的部分

  • 未检查到对 V7 在 HERB 上的检索结果或无法回答查询减少 38% 的独立复现。
  • 成本和图查询对比缺少分母及设置，无法比较每个成功工作流的成本或不同模型间的准确率。
  • 没有客户侧评估衡量图谱是否改善来源引用准确性、过期事实处理、安全权限或已部署工作流中的人工审查负担。

FCMO 视角

企业智能体需要能够跨会话保留并追溯到文档的上下文，而较大的上下文窗口和重复搜索可能使工作流成本上升且变得脆弱。V7 的 Context Graph 是一种将持久上下文与来源关联、并以文档检索作为后备的具体产品实现；其客户案例报告了检索和单文档成本方面的大幅收益。现有数字缺少方法细节和独立核验，无法证明其具有普遍优势。值得研究的问题是：这种架构能否在保留出处、权限控制和更正处理能力的同时，降低正确完成工作流的成本。
