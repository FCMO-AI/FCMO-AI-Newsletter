Deep Noir 报告自动化激活 steering 及依赖任务的注入风险

Deep Noir 预印本结合 Logit Lens 时间分析和因果头级归因来搜索激活 steering 参数。作者报告称，在选定的 1B–9B 研究模型上，垃圾邮件和情感分类均有提升，包括所述设置中 1B 垃圾邮件分类提高 +16.7 个百分点、SST-2 提高 +13.1 个百分点。作者还报告称，在某些模型/任务设置中，steering 幅度增加与 prompt injection 成功率上升相关。论文自身结果显示架构和任务依赖性：在一项 7B 结果中 steering 降低了注入易受攻击性；在针对情感任务调整的攻击中，三种模型有两种方向相反。这些是作者报告的发现，并非独立复现，也不是已部署 agent 遭受攻击的证据。

真正发生了什么变化

Deep Noir 预印本结合 Logit Lens 时间分析和因果头级归因来搜索激活 steering 参数。作者报告称，在选定的 1B–9B 研究模型上，垃圾邮件和情感分类均有提升，包括所述设置中 1B 垃圾邮件分类提高 +16.7 个百分点、SST-2 提高 +13.1 个百分点。作者还报告称，在某些模型/任务设置中，steering 幅度增加与 prompt injection 成功率上升相关。论文自身结果显示架构和任务依赖性：在一项 7B 结果中 steering 降低了注入易受攻击性；在针对情感任务调整的攻击中，三种模型有两种方向相反。这些是作者报告的发现，并非独立复现，也不是已部署 agent 遭受攻击的证据。

主张与证据

  • 声称 — 作者报告称，Deep Noir 将 Logit Lens 收敛分析与因果头级归因结合起来，用于发现激活 steering 参数。在所述设置中，1B 模型的 SMS 垃圾邮件分类提升 16.7 个百分点（±4.7，39 次运行）；四种 7–9B 架构提升 +21–42 个百分点；1B 设置下 SST-2 情感分类提升 +13.1 个百分点。
  • 声称 — 在论文的 prompt injection 评估中，所测 OLMo 和 Gemma 设置下，steering 幅度增加时注入成功率没有下降。作者报告称，OLMo 从零 steering 时的 0.34 升至 4×M* 时的 1.0，Gemma 从 0.25 升至 0.99。
  • 声称 — 安全影响并非一致：论文报告称，steering 将 7B Mistral 的注入易受攻击率从 97.5% 降至 61.1%，而针对情感任务调整的攻击在三种模型中的两种上方向相反。因此，证据支持的是依赖任务和架构的风险，而非易受攻击性普遍上升。

最强基线

论文将 Deep Noir 与基础分类器、随机搜索以及未使用头屏蔽的 RepE steering 比较。作者报告称，在所述 SST-2 folds 上 RepE 与基线相同而 Deep Noir 有提升；研究团队未核查统计分析或重跑比较。

最重要的限制

  • 所有结果来自一篇 preprint，尚未独立复现；查看的来源中没有代码工件。
  • 评估使用最高 9B 的选定研究模型分类器，以及少量垃圾邮件、情感和注入 benchmark；并未证明已部署 agent 的安全或失陷结果。
  • 论文报告的效果依赖架构和任务：跨任务攻击结果在三种模型中的两种上方向反转，且 steering 降低了 7B Mistral 的注入易受攻击性。随幅度单调上升的结果仅适用于所测 OLMo/Gemma 设置。
  • 作者使用了自定义 steering、一致性和攻击指标；其独立有效性以及向其他模型、prompt 和部署控制的迁移仍未知。
  • 1B MMLU 基线接近随机水平，因此部分遏制能力变化较嘈杂；不应将论文所述比较以外的统计或实际显著性视为已确立。
  • 论文的安全结果并未在不同任务和架构间保持单调：针对情感任务调整的攻击在三种模型中的两种上呈相反方向，且 7B Mistral 结果显示 steering 后注入易受攻击性降低。这意味着摘要中更宽泛的攻击面表述应限于具体测试设置。

仍然未知的部分

  • 激活 steering、跨任务结果及 prompt injection 结果尚未经过独立复现；查看的论文中未找到作者关联的代码工件。
  • 尚未测量小型研究模型分类器向请求路由或授权 agent 操作的系统迁移效果。

FCMO 视角

基于机制可解释性的激活 steering 或可自动化原本需要手动选择层和幅度的干预。同一干预也会改变分类器对 prompt injection 的响应，因此应同时测量准确率提升和攻击行为。预印本报告了这两方面效果，但其小型模型分类环境和跨任务混合结果尚不能证明可迁移到已部署 agent。
