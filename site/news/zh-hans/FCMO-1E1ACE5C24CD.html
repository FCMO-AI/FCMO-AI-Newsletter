Air Security 报告称四款编程代理存在插件 SHA 固定值检出校验缺失

Air Security 17 日（九月）发布的披露介绍了 Plugin4Shell：如果编程代理不验证检出后的 HEAD，Git 检出歧义据称可能绕过插件提交固定值。作者称他们针对 Claude Code、Codex、GitHub Copilot 和 Gemini CLI 制作了可用概念验证，并称 Claude Code 2.1.179 和 Codex 0.146.0 已修复、披露时 Copilot 尚无已发布修复，且 Google 不会修复已弃用的 Gemini CLI。披露提供了技术细节，但其中有关漏洞利用和产品状态的说法仍属第一方陈述，本次未独立复现；Air Security 在代理供应链安全领域也有商业利益。现有材料未证明真实世界中的利用情况或受影响用户规模。

真正发生了什么变化

Air Security 17 日（九月）发布的披露介绍了 Plugin4Shell：如果编程代理不验证检出后的 HEAD，Git 检出歧义据称可能绕过插件提交固定值。作者称他们针对 Claude Code、Codex、GitHub Copilot 和 Gemini CLI 制作了可用概念验证，并称 Claude Code 2.1.179 和 Codex 0.146.0 已修复、披露时 Copilot 尚无已发布修复，且 Google 不会修复已弃用的 Gemini CLI。披露提供了技术细节，但其中有关漏洞利用和产品状态的说法仍属第一方陈述，本次未独立复现；Air Security 在代理供应链安全领域也有商业利益。现有材料未证明真实世界中的利用情况或受影响用户规模。

主张与证据

  • 已证实 — Air Security 于 2026-09-17 发布了有日期的技术披露，并称其研究团队针对 Claude Code、Codex、GitHub Copilot 和 Gemini CLI 制作了可用概念验证。这证明的是报告所述内容，并非对漏洞利用的独立确认。
  • 声称 — Air Security 报告称，所列代理未验证 Git 检出是否到达固定提交；报告描述了影响 Claude Code、Codex 和 Copilot 的 SHA 名称分支/引用解析路径，以及影响 Gemini CLI 的 FETCH_HEAD 名称解析路径。
  • 声称 — 报告称 Claude Code 2.1.179 和 Codex 0.146.0 已包含修复，披露时 GitHub Copilot 尚无已发布修复，Google 也不会修复已弃用的 Gemini CLI。本次激活未通过厂商公告独立核实这些状态。

最强基线

报告直接指出的控制是在检出后校验实际解析的 HEAD 是否等于请求固定的提交；具体产品修复需检查厂商制品。
