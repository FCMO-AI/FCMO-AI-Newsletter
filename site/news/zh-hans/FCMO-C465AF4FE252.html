Google Home MCP 在早期访问阶段向 AI 客户端开放设备状态查询与控制工具

Google Home 的早期访问 MCP 服务器可让兼容的 AI 客户端连接真实智能家居的数据和操作。Google 开发文档列出了发现家庭与设备、读取当前状态和历史事件、执行设备控制命令等工具。文档提醒，连接真实家庭意味着代理能够控制设备；同时说明了速率限制和敏感操作保护，例如禁止解锁门，并要求客户端在执行工具前获得许可。使用需要 Google Home Premium Advanced 订阅和项目审批；截至 21 日更新页面，创建自动化功能尚未开放。这些是文档所述的产品能力和防护措施，并非对其执行效果或实际使用情况的独立验证。

真正发生了什么变化

Google Home 的早期访问 MCP 服务器可让兼容的 AI 客户端连接真实智能家居的数据和操作。Google 开发文档列出了发现家庭与设备、读取当前状态和历史事件、执行设备控制命令等工具。文档提醒，连接真实家庭意味着代理能够控制设备；同时说明了速率限制和敏感操作保护，例如禁止解锁门，并要求客户端在执行工具前获得许可。使用需要 Google Home Premium Advanced 订阅和项目审批；截至 21 日更新页面，创建自动化功能尚未开放。这些是文档所述的产品能力和防护措施，并非对其执行效果或实际使用情况的独立验证。

主张与证据

  • 声称 — Google 文档介绍了一项早期访问的 Home MCP 服务，兼容 AI 客户端可借此发现家庭与设备、查询当前状态和历史记录，并发出参数化设备控制操作。
  • 声称 — Google 提醒，连接真实家庭后，代理可以控制设备。文档提到速率限制和敏感操作保护（例如禁止解锁门），并要求客户端授予工具执行权限。
  • 已证实 — Google 开发页面将 Home MCP 标为早期访问，要求 Premium Advanced 订阅和项目审批；页面注明截至 2026-09-21 更新时尚不支持创建自动化。

最强基线

Google 文档介绍了常规 Home API 访问方式及 MCP 中间层。未发现与直接 API 集成或其他家庭控制代理的对照评估。

最重要的限制

  • 本记录描述文档中的产品功能，不代表已测得的代理能力或现实部署结果。
  • Google 警告，连接真实家庭的代理可能产生意外行为；其文档仍将用户审查与撤销权限作为安全控制的一部分。

仍然未知的部分

  • 尚无独立测试证实敏感操作限制和用户授权控制能在不同工具及客户端中得到执行。
  • 早期访问文档未说明部署规模、可靠性或家庭使用影响。

FCMO 视角

这项集成为通用代理控制家庭实体设备提供了具体通道。实际边界取决于工具接口、授权方式和服务器施加的操作限制，因此需要验证防护措施及其执行情况，而不能仅凭 MCP 标签判断安全性。
