证据

  • 声称 — STeP-PO 将基于观测的逐步质量检查、反事实步骤重要性和语义步骤树结合起来，在交通信号策略优化期间向推理 token 分配过程及结果优势。
  • 声称 — 使用 Qwen2.5-3B 在一个合成流量上训练，并于 CityFlow 对济南和杭州的五个真实流量数据集零样本评估时，作者报告 ProcessLight 在比较方法的大多数指标上取得最佳结果。
  • 声称 — 在Jinan1和Hangzhou1消融实验中，作者报告 STeP-PO 平均行程时间为 289.34 秒和 314.99 秒；仅使用结果奖励时为 305.74 秒和 334.25 秒。五个种子、Holm 校正后，90 次比较中有 81 次显著支持该方法。
  • 声称 — 论文附录报告了使用 Qwen3-8B、Qwen3-32B 和 Llama3-8B 作为底座，以及使用 Qwen3-Plus 作为替代教师时的结果；结果因数据集和指标而异，因此这些测试不能确立普遍的扩展规律。
  • 声称 — 作者报告，生成参考判断使用 DeepSeek-V4-Pro 云 API 调用 3k 次，输入 7.07M token、输出 1.70M token，费用为 $9.1；步骤重要性预计算使用 Qwen2.5-3B 调用 21k 次，输入 57.81M token，在单张 RTX PRO 6000 上耗时 1.5 GPU 小时，费用为 $1.2。这是两个数据构建阶段的报告成本，不是训练、推理或部署的总成本。
