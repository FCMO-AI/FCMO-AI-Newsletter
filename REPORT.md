# Studio live publication

The real GitHub publishing path is implemented on `c5/studio-live`, integrated
with current v4 main, the existing protected PR/Pages contract and LKG recovery.
A real local bare-remote journey publishes an essay and curated edition; the
remote commit builds all three edition routes. No external push or deployment
was performed and no host service was installed.

See [REPORT-STUDIO-LIVE.md](REPORT-STUDIO-LIVE.md) for exact commits, red-first
proof, final test/build results, missing specification/credential/browser
boundaries, and host activation, dry-run and reversal commands.

Resumen: implementación y prueba Git local completas; la aceptación live depende
de la especificación accesible, credenciales/protecciones reales y navegador.
