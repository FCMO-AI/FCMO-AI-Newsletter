Mechanism: The paper describes a tensor-network contraction method and derives an asymptotic subexponential bound for exact #k-SAT counting. 3. Heads of Security reports learned attention gates that improve prompt-injection robustness in two open-weight models

Desk: evaluation_science Evidence: A · credible_unconfirmed · active · importance 6/10 (Major) Importance rationale: If independently confirmed, a lightweight architectural defense that materially increases adaptive attack cost while preserving measured utility could change security design choices for open-weight agents. The score reflects that consequence if true; evidence is one author-reported preprint on two models and bounded attack/utility evaluations.

What changed: The preprint introduces Heads of Security (HoS), which learns small per-head attention gates to separate trusted instructions from untrusted content while allowing the model to reason over that content. On Llama-3.3-70B-Instruct and GPT-OSS-20B, the authors report lower adaptive RL-Hammer attack success against HoS than against an undefended base model or SecAlign++, with means over five runs on 100 held-out InjecAgent goals where available. The official project page shows a mixed utility picture: Llama AgentDyn utility is 18.3% for HoS versus 33.7% for the base model, despite lower reported attack success, while Llama AgentDojo utility is 58.5% versus 53.7%. These remain author-reported results in two open-weight model settings, not independent replication or a deployment-safety result. A checksum-matched PyPI 0.1.0 source distribution uploaded October 8 contains package code, tests and demos for both model families; this activation inspected it but did not execute it, and PyPI reports no build provenance. Why it matters: Prompt injection remains a barrier to tool-using agents. If the reported gains replicate, a small architectural intervention could improve the security–utility trade-off without full-model fine-tuning. The authors’ own project table also shows that the trade-off varies by benchmark, including lower Llama AgentDyn utility under HoS; trust labels are externally supplied, so this is one defense primitive rather than an end-to-end security system.

Demonstrated: The arXiv v1 preprint and its stated method/results are publicly available; its reported performance has not been independently established in this activation.

Claimed: The authors report that learned per-head attention gates reduce adaptive prompt-injection attack success on Llama-3.3-70B-Instruct and GPT-OSS-20B while retaining utility on selected capability and agent benchmarks. On 100 held-out InjecAgent goals, their strongest displayed RL-Hammer attacks reached up to 10.0% ASR against HoS on GPT-OSS-20B (versus 85.2% for SecAlign and 97.2% for the undefended model) and 1.2% against HoS on Llama-3.3-70B (versus 81.6% for SecAlign and 99.4% undefended); where available, these are means over five runs. The official project table also reports uneven utility trade-offs: Llama AgentDyn utility is 18.3% with HoS versus 33.7% base alongside 1.4% ASR, while Llama AgentDojo utility is 58.5% versus 53.7% base alongside 0.9% ASR.

Mechanism: Adds learned per-head, per-channel bias terms to attention logits so each head can reduce attention to tokens assigned to untrusted sources while retaining access for other heads. It trains only 46,080 gate scalars for Llama-3.3-70B and 18,432 for GPT-OSS-20B, according to the paper.

Strongest baseline: SecAlign++ (finetuning-based) and ASIDE (architectural instruction/data separation), plus each undefended base model.

Regime: Llama-3.3-70B-Instruct and GPT-OSS-20B; RL-Hammer black-box adaptive attacks on InjecAgent with 100 held-out goals; additional white-box Claudini and static agent prompt-injection benchmarks.; the official project table reports benchmark-specific utility trade-offs, including lower Llama AgentDyn utility with HoS despite lower ASR.

Limitations: All performance figures are from one arXiv preprint and were not independently reproduced in this activation.; The authors state instruction-data separation is not end-to-end: the system does not decide which sources are trusted, and tasks may legitimately require following external instructions.; Results cover two open-weight model families and specific datasets, attack budgets, prompts, channels and scoring rules; no production deployment or broad transfer is established.; The attacker can adapt after deployment and no finite evaluation establishes security.; The authors’ project table reports an AgentDyn clean-utility trade-off for Llama-3.3-70B: 18.3% for HoS versus 33.7% for the base model, despite a lower reported attack-success rate; utility varies by benchmark.; The linked GitHub repository URL returned 404 during this check, but PyPI distributes a source package version 0.1.0 uploaded October 8, 2026. Its checksum-matched source archive contains package modules and tests; it was inspected without execution. PyPI reports no build provenance, and package availability does not establish test results or reproduce the paper evaluation.

Open evidence gaps: No independent reproduction of HoS training, RL-Hammer or Claudini results was obtained. A PyPI 0.1.0 source distribution is available and its published checksum matched, but its tests were not run and the exact revision-pinned evaluation protocol has not been independently reproduced.; The evaluation does not establish robustness in deployed agents, across trust-boundary assignments, broader tools or adaptive attacker budgets.

Sources: https://arxiv.org/html/2610.37657 · https://huggingface.co/imperial-cpg/hos-gpt-oss-20b · https://imperial-aisp.github.io/heads_of_security/ · https://pypi.org/project/heads-of-security/0.1.0/

Evidence Acredible_unconfirmedImpact 5/10 · Notableactive

Zhang, Wen, Li and Chen introduce PORTAL, a controller for choosing among fixed image-classification interventions, selecting inputs to label, and stopping when additional feedback cannot change the choice or its expected value is below its cost. Agents & Memory

Preprint reports predictable failures in rarity- and relevance-based memory for LLM group decisions

Evidence Acredible_unconfirmedImpact 5/10 · Notableactive

The arXiv preprint introduces CrossProfile, a diagnostic with 60 main templates and 480 ownership variants that keeps fact wording fixed while varying which agents hold supporting, decoy and irrelevant information. Across Qwen2.5-7B, Llama-3.1-8B and exploratory hosted DeepSeek runs, the authors report that rarity-first and relevance-first memory heuristics can reverse performance depending on who holds decoy evidence. The study uses constructed tasks and a mechanically defined answer key; it does not estimate failure rates in deployed teams.
