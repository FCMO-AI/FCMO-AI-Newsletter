## Why this pilot exists

The universal Proof Spine hypothesis must survive a project whose truth law is materially unlike Newsletter. Synthetic fixtures are useful for regression, but they do not prove that a real project can export its own existing authority surface through the universal receipt boundary without duplicating or weakening local law.

CMPCT v0.30 is a strong discriminator because its active convergence branch already owns a strict, multi-receipt release lock. The experiment therefore wraps that existing local authority rather than reimplementing CMPCT thresholds inside Agent Hub.

## What this field result proves

This run provides direct evidence for one universal-interface claim:

> **A real non-Newsletter FCMO project can translate its existing project-owned truth/release machinery into the same evidence-only Proof Spine receipt boundary without transferring release authority to Spine.**

It also demonstrates the desired authority direction:

```text
CMPCT local release law
        ↓ observes / exports
thin CMPCT adapter
        ↓ EVIDENCE_ONLY
universal receipt
        ↓ may later be evaluated
Proof Spine contract/core
```

The arrow does not reverse. Proof Spine did not tell CMPCT whether v0.30 was releasable; CMPCT's strict lock did.

## What this field result does NOT prove

It does not prove:

- CMPCT v0.30 is releasable;
- Proof Spine's generic/federation engine is correct at current Agent Hub exact HEAD;
- Proof Spine has caught a real consequential error that CMPCT's own machinery would otherwise have let through;
- adapter maintenance cost or false-block rate is acceptable at ecosystem scale;
- universal FCMO adoption should be promoted;
- a Hub proof contract should replace CMPCT release law.
